# Блок 1. Один верный вариант

## 1

Бинарное отношение $R$ на паре множеств $A$ и $B$ — это:

- ( ) подмножество пересечения $A \cap B$
- ( ) подмножество объединения $A \cup B$
- ( ) множество всех функций из $A$ в $B$
- (x) произвольное подмножество декартова произведения $A \times B$

Пояснение:
**Ответ:** произвольное подмножество $A \times B$.

> **Слайды 11 и 14.** «Б/отношение R на A × B — это R ⊆ A × B».

$R$ — любое подмножество декартова произведения, включая пустое и само $A \times B$.

**Почему не подходят остальные**

- Подмножество $A \cup B$ или $A \cap B$ состоит из элементов, а отношение — из пар.
- Множество всех функций из $A$ в $B$ — это множество, элементы которого функции. Отношением, то есть подмножеством $A \times B$, является каждая отдельная функция, а не их множество.


## 2

$|A| = m$, $|B| = n$. Сколько всего различных бинарных отношений между $A$ и $B$?

- ( ) $m \cdot n$
- ( ) $2^{m + n}$
- ( ) $m^n$
- (x) $2^{m \cdot n}$

Пояснение:
**Ответ:** $2^{m \cdot n}$.

> **Слайд 19.** «Все возможные отношения на A и B формируют булеан A × B. То есть всего 2^|A×B| возможных отношений».

$|A \times B| = m \cdot n$, отношение — любое подмножество $A \times B$, поэтому отношений $2^{m \cdot n}$.

$m \cdot n$ — число пар, а не число отношений.


## 3

$A$ и $B$ непустые. В каком случае $A \times B = B \times A$?

- ( ) только если $A \subseteq B$
- (x) только если $A = B$
- ( ) для любых двух непустых множеств
- ( ) ни при каких условиях

Пояснение:
**Ответ:** только если $A = B$.

> **Слайд 5.** «A × B ≠ B × A, за исключением: A = B = {1,2}».

Порядок элементов в паре важен: $(a, b) \ne (b, a)$ при $a \ne b$. Если $a \in A \setminus B$, то пара $(a, b)$ лежит в $A \times B$, но не в $B \times A$. Поэтому для непустых множеств произведения совпадают только при $A = B$.


## 4

$R$ — отношение на $A$. На главной диагонали матрицы $M_R$ стоят только единицы. Каким свойством обладает $R$?

- ( ) транзитивностью
- ( ) антирефлексивностью
- ( ) симметричностью
- (x) рефлексивностью

Пояснение:
**Ответ:** рефлексивностью.

> **Слайд 54.** «Матрица, в которой на главной диагонали находятся единицы» — признак рефлексивного отношения.

Единица на пересечении $i$-й строки и $i$-го столбца означает $a_i R a_i$. Если так для всех $i$, отношение рефлексивно.


## 5

$R \subseteq A^2$. Что означает петля у вершины $a$ на графе $R$?

- ( ) $R$ транзитивно
- ( ) элемент $a$ не связан ни с каким другим элементом
- (x) $(a, a) \in R$
- ( ) элемент $a$ находится в отношении со всеми элементами $A$

Пояснение:
**Ответ:** $(a, a) \in R$.

> **Слайд 34.** «Петля на графе — это пара вида (a, a) ∈ R».

Петля — дуга, которая выходит из вершины $a$ и приходит в неё же. О других дугах и свойствах всего отношения она ничего не говорит.


## 6

Как связаны матрицы $M_R$ и $M_{R^{-1}}$?

- ( ) $M_{R^{-1}}$ получается заменой 0 на 1 и 1 на 0
- ( ) матрицы всегда совпадают
- ( ) $M_{R^{-1}} = (M_R)^2$
- (x) $M_{R^{-1}} = (M_R)^T$, то есть транспонированная $M_R$

Пояснение:
**Ответ:** $M_{R^{-1}} = (M_R)^T$.

> **Слайд 46.** «Существует bR⁻¹a тогда и только тогда, когда существует aRb».

Переход от пары $(a, b)$ к $(b, a)$ в матрице меняет местами строку и столбец, то есть транспонирует матрицу.

Замена 0 на 1 даёт матрицу дополнения $A^2 \setminus R$, а не обратного отношения.


## 7

$\operatorname{Dom}(R)$ — это:

- ( ) множество всех элементов $A \times B$
- ( ) пересечение множеств $A$ и $B$
- (x) множество всех первых координат пар из $R$
- ( ) множество всех вторых координат пар из $R$

Пояснение:
**Ответ:** множество всех первых координат пар из $R$.

> **Слайд 43.** «Dom(R) — область определения отношения R — множество всех первых координат упорядоченных пар из R».

Множество вторых координат — область значений $\operatorname{Im}(R)$ (слайд 44).


## 8

Как $\operatorname{Im}(R)$ связана с обратным отношением $R^{-1}$?

- (x) $\operatorname{Im}(R) = \operatorname{Dom}(R^{-1})$
- ( ) никак не связана
- ( ) $\operatorname{Im}(R) = \operatorname{Im}(R^{-1})$
- ( ) $\operatorname{Im}(R) = A \setminus \operatorname{Dom}(R^{-1})$

Пояснение:
**Ответ:** $\operatorname{Im}(R) = \operatorname{Dom}(R^{-1})$.

> **Слайд 49.** «Для R⁻¹: Dom(R⁻¹) = Im(R)».

Пары $R^{-1}$ — это пары $R$, записанные в обратном порядке. Поэтому первые координаты пар из $R^{-1}$ — это вторые координаты пар из $R$.


## 9

Какое условие задаёт симметричность отношения $R$ на $A$?

- ( ) $\exists a, b \in A: (aRb \land bRa)$
- (x) $\forall a, b \in A: (aRb \Rightarrow bRa)$
- ( ) $\forall a, b \in A: (aRb \Rightarrow \forall b\ (aRb))$
- ( ) $\forall a, b \in A: (aRb \land bRa \Rightarrow a = b)$

Пояснение:
**Ответ:** $\forall a, b \in A: (aRb \Rightarrow bRa)$.

> **Слайд 62.** «R — симметрично, если для ∀a, b ∈ A: aRb ⇒ bRa».

**Почему не подходят остальные**

- **А:** $\exists$ вместо $\forall$ — это существование хотя бы одной пары, связанной в обе стороны, а не определение симметричности.
- **Г:** это антисимметричность (слайд 65).
- **В:** бессмысленная запись: $b$ связан квантором дважды.


## 10

Какое утверждение о связи асимметричности и антисимметричности верно?

- (x) всякое асимметричное отношение антисимметрично и антирефлексивно
- ( ) всякое антисимметричное отношение асимметрично
- ( ) асимметричность допускает петли на графе
- ( ) это синонимы одного и того же свойства

Пояснение:
**Ответ:** всякое асимметричное отношение антисимметрично и антирефлексивно.

> **Слайды 66 и 70.** «{асимметричные} ⊂ {антисимметричные}».

Асимметричность запрещает одновременно $aRb$ и $bRa$ для любых $a, b$, в том числе при $a = b$. Поэтому петель нет: отношение антирефлексивно (слайд 71).

Обратное неверно: $\{(1, 1)\}$ антисимметрично, но не асимметрично из-за петли.


## 11

Отношение $R$ на $A$ называется несимметричным, если:

- ( ) на графе нет ориентированных дуг
- (x) есть пары $(a, b)$ с $aRb \land bRa$ и есть пары $(c, d)$ с $cRd \land \lnot(dRc)$
- ( ) матрица отношения симметрична относительно главной диагонали
- ( ) ни для одной пары не выполняется $aRb \Rightarrow bRa$

Пояснение:
**Ответ:** есть пары, связанные в обе стороны, и есть пары, связанные только в одну.

> **Слайд 74.** «R — несимметрично, если существуют a, b, c, d ∈ A: aRb ∧ bRa и cRd ∧ ¬(dRc)».

Это промежуточный случай между симметричностью и асимметричностью: не все пары симметричны и не все несимметричны. Симметричная матрица — признак симметричного отношения.


## 12

Какое условие задаёт транзитивность отношения $R$ на $A$?

- (x) $\forall a, b, c \in A: (aRb \land bRc \Rightarrow aRc)$
- ( ) $\forall a, b \in A: (aRb \Rightarrow bRa)$
- ( ) $\forall a, b, c \in A: (aRb \Rightarrow bRc \land aRc)$
- ( ) $\forall a, b, c \in A: (aRb \land aRc \Rightarrow bRc)$

Пояснение:
**Ответ:** $\forall a, b, c \in A: (aRb \land bRc \Rightarrow aRc)$.

> **Слайд 77.** «R — транзитивно, если для ∀a, b, c ∈ A: (aRb) ∧ (bRc) ⇒ (aRc)».

На графе: путь из двух дуг $a \to b \to c$ требует замыкающую дугу $a \to c$.

Второй вариант — симметричность. В последнем цепочки нет: из $a$ выходят две дуги, в $b$ и в $c$.


## 13

Верно ли, что любое асимметричное отношение антирефлексивно?

- ( ) нет, асимметричное отношение всегда рефлексивно
- ( ) нет, оно может быть нерефлексивным
- (x) да, это всегда так
- ( ) зависит от мощности множества $A$

Пояснение:
**Ответ:** да.

> **Слайд 71.** «Любое асимметричное отношение — антирефлексивно».

Пусть $aRa$. Асимметричность при $b = a$ даёт $aRa \Rightarrow \lnot(aRa)$ — противоречие. Значит, петель нет, и отношение антирефлексивно.


## 14

На рисунке — граф отношения $R$ на $\{1, 2, 3, 4\}$. Какое утверждение о рефлексивности $R$ верно?

![Граф на четырёх вершинах: петли у всех вершин, дуги из 1 в 2, из 2 в 3, из 4 в 1](q14.svg)

- ( ) $R$ нерефлексивно
- (x) $R$ рефлексивно
- ( ) $R$ антирефлексивно
- ( ) нет правильного ответа

Пояснение:
**Ответ:** $R$ рефлексивно.

> **Слайд 53.** «R — рефлексивно, если для ∀a ∈ A: (aRa)».

У каждой из четырёх вершин есть петля, значит, $aRa$ для всех $a$. Антирефлексивность и нерефлексивность с рефлексивностью несовместимы (слайд 59). Дуги между разными вершинами на рефлексивность не влияют.


## 15

На рисунке — матрица отношения $R$ на $\{1, 2, 3\}$. Какая из матриц — $M_{R^{-1}}$?

![Матрица M_R: строка 1 — 1 1 0, строка 2 — 0 0 1, строка 3 — 0 0 1](q15.svg)

- ( ) ![А](q15_А.svg)
- ( ) ![Б](q15_Б.svg)
- (x) ![В](q15_В.svg)
- ( ) ![Г](q15_Г.svg)

Пояснение:
**Ответ:** В.

> **Слайд 46.** $M_{R^{-1}}$ получается транспонированием $M_R$.

Транспонирование — замена строк столбцами:

$$
M_R = \begin{pmatrix} 1 & 1 & 0 \\ 0 & 0 & 1 \\ 0 & 0 & 1 \end{pmatrix}
\qquad
M_{R^{-1}} = \begin{pmatrix} 1 & 0 & 0 \\ 1 & 0 & 0 \\ 0 & 1 & 1 \end{pmatrix}
$$

**Почему не подходят остальные**

- **А:** это сама $M_R$.
- **Б:** нули и единицы заменены друг на друга. Это матрица дополнения, а не обратного отношения.
- **Г:** это $R \circ R$, «квадрат» отношения.


## 16

На рисунке — граф отношения $R$ на $\{a, b, c, d\}$. Какой вывод о транзитивности верен?

![Граф на вершинах a, b, c, d: дуги из a в b, из b в c, из b в d, из a в d](q16.svg)

- (x) $R$ нетранзитивно, так как нет дуги $(a, c)$
- ( ) $R$ антитранзитивно
- ( ) недостаточно данных
- ( ) $R$ транзитивно

Пояснение:
**Ответ:** $R$ нетранзитивно.

> **Слайд 80.** «Треугольник дуг: (1,2) и (2,3) ⇒ (1,3)».

Проверяем цепочки из двух дуг:

| Цепочка | Замыкающая дуга | Тройка |
|---|---|---|
| $a \to b \to c$ | $(a, c)$ нет | антитранзитивная |
| $a \to b \to d$ | $(a, d)$ есть | транзитивная |

Есть и транзитивная, и антитранзитивная тройка, поэтому $R$ не транзитивно и не антитранзитивно. Это и есть нетранзитивность (слайд 93).


# Блок 2. Краткий ответ

## 17

$A = \{1, 2, 3\}$, $B = \{a, b, c, d\}$. $|P(A \times B)| = ?$

Формат: число.
Ответ: 4096

Пояснение:
**Ответ:** 4096.

> **Слайд 19.** $|A \times B| = |A| \cdot |B|$.
>
> **Слайд 23.** «Мощность булеана множества A вычисляется по формуле 2^|A|».

1. $|A \times B| = 3 \cdot 4 = 12$.
2. $|P(A \times B)| = 2^{12} = 4096$.


## 18

$R = \{(1, 2), (1, 4), (3, 2), (5, 6)\}$. $\operatorname{Dom}(R) = ?$

Формат: множество в фигурных скобках, элементы через запятую.
Ответ: {1, 3, 5}

Пояснение:
**Ответ:** $\{1, 3, 5\}$.

> **Слайд 43.** $\operatorname{Dom}(R)$ — множество первых координат пар из $R$.

Первые элементы пар: 1, 1, 3, 5. Без повторов: $\{1, 3, 5\}$.


## 19

$R = \{(1, 2), (1, 4), (3, 2), (5, 6)\}$. $\operatorname{Im}(R) = ?$

Формат: множество в фигурных скобках, элементы через запятую.
Ответ: {2, 4, 6}

Пояснение:
**Ответ:** $\{2, 4, 6\}$.

> **Слайд 44.** $\operatorname{Im}(R)$ — множество вторых координат пар из $R$.

Вторые элементы пар: 2, 4, 2, 6. Без повторов: $\{2, 4, 6\}$.


## 20

$R = \{(a, 1), (b, 2), (c, 2)\}$. $R^{-1} = ?$

Формат: множество пар в фигурных скобках, пары в круглых скобках через запятую. Например: {(1, x), (2, y)}
Ответ: {(1, a), (2, b), (2, c)}

Пояснение:
**Ответ:** $R^{-1} = \{(1, a), (2, b), (2, c)\}$.

> **Слайд 46.** $R^{-1} = \{(x, y) \mid (y, x) \in R\}$.

Каждая пара меняет порядок: $(a, 1) \to (1, a)$, $(b, 2) \to (2, b)$, $(c, 2) \to (2, c)$. Порядок пар в записи не важен, это множество.


## 21

$A = \{1, 2, 3\}$, $R = A \times A$. $|R| = ?$

Формат: число.
Ответ: 9

Пояснение:
**Ответ:** 9.

$R = A \times A$ — полное отношение, все возможные пары: $|A \times A| = 3 \cdot 3 = 9$.

Не путайте с числом всех отношений на $A$: их $2^9 = 512$ (слайд 19).


## 22

$A = \{1, 2, 3, 4\}$, $R = \{(a, b) \mid a \text{ делит } b\}$. $|R| = ?$

Формат: число.
Ответ: 8

Пояснение:
**Ответ:** 8.

Перебираем пары:

| $a$ | Пары | Сколько |
|---|---|---|
| 1 | $(1, 1)$, $(1, 2)$, $(1, 3)$, $(1, 4)$ | 4 |
| 2 | $(2, 2)$, $(2, 4)$ | 2 |
| 3 | $(3, 3)$ | 1 |
| 4 | $(4, 4)$ | 1 |

$4 + 2 + 1 + 1 = 8$. Пары $(a, a)$ входят: любое число делит само себя. Без них осталось бы 4 пары.


## 23

Сколько существует различных рефлексивных отношений на множестве из 3 элементов?

Формат: число.
Ответ: 64

Пояснение:
**Ответ:** 64.

> **Слайд 54.** Рефлексивность: на главной диагонали матрицы только единицы.

1. В матрице $3 \times 3$ девять клеток.
2. Три диагональные клетки обязаны быть единицами.
3. Остальные $9 - 3 = 6$ клеток — 0 или 1 независимо: $2^6 = 64$.


## 24

Сколько существует различных симметричных отношений на множестве из 3 элементов?

Формат: число.
Ответ: 64

Пояснение:
**Ответ:** 64.

> **Слайд 62.** Симметричность: матрица симметрична относительно главной диагонали.

1. Отношение на трёх элементах задаётся матрицей $3 \times 3$ из нулей и единиц.
2. Симметричность означает $M_R = (M_R)^T$: клетки $(i, j)$ и $(j, i)$ совпадают.
3. Свободно выбираются 3 клетки диагонали и 3 клетки над ней, клетки под диагональю повторяют верхние.
4. $2^6 = 64$.


## 25

$A = \{1, 2\}$. Сколько существует антирефлексивных отношений на $A$?

Формат: число.
Ответ: 4

Пояснение:
**Ответ:** 4.

> **Слайд 57.** Антирефлексивность: на главной диагонали только нули.

Матрица $2 \times 2$: две диагональные клетки обязаны быть нулями, свободны две клетки вне диагонали: $2^2 = 4$.


## 26

$R = \{(1, 2), (2, 3)\}$. Какую пару нужно добавить к $R$, чтобы отношение стало транзитивным?

Формат: пара в круглых скобках через запятую. Например: (5, 6)
Ответ: (1, 3)

Пояснение:
**Ответ:** $(1, 3)$.

> **Слайд 77.** $(aRb) \land (bRc) \Rightarrow (aRc)$.

В $R$ есть $(1, 2)$ и $(2, 3)$, значит, нужна $(1, 3)$. Других цепочек из двух пар нет. После добавления $(1, 3)$ новых цепочек не появляется: из 3 пар не выходит.


## 27

$A = \{1, 2, 3, 4, 5\}$, $R = \{(a, b) \in A^2 \mid a + b = 6\}$. $|\operatorname{Dom}(R)| = ?$

Формат: число.
Ответ: 5

Пояснение:
**Ответ:** 5.

1. Пары с суммой 6: $(1, 5)$, $(2, 4)$, $(3, 3)$, $(4, 2)$, $(5, 1)$.
2. Первые координаты: $\{1, 2, 3, 4, 5\}$, то есть всё $A$.
3. $|\operatorname{Dom}(R)| = 5$.


## 28

$R$ — антирефлексивное отношение на множестве из $n$ элементов. Сколько единиц на главной диагонали $M_R$?

Формат: число.
Ответ: 0

Пояснение:
**Ответ:** 0.

> **Слайд 56.** Антирефлексивность: $\forall a \in A: \lnot(aRa)$.

Ни одна пара $(a, a)$ не входит в $R$, а именно им соответствуют диагональные клетки. Все они равны 0.


## 29

На рисунке — граф отношения на $\{1, 2, 3\}$. Сколько на нём рёбер (двунаправленных дуг)?

![Граф на вершинах 1, 2, 3: дуги 1 в 2 и 2 в 1, дуга из 2 в 3, петля у 3](q29.svg)

Формат: число.
Ответ: 1

Пояснение:
**Ответ:** 1.

> **Слайд 34.** «Ребро — это дуга туда и обратно, а значит, две пары вида (a, b), (b, a) ∈ R».

- Пары $(1, 2)$ и $(2, 1)$ вместе образуют одно ребро.
- Дуга $(2, 3)$ обратной не имеет, это не ребро.
- Петля $(3, 3)$ — не ребро.

## 32

Какие равенства верны для любых множеств $A$, $B$, $C$?

- [x] $A \times (B \setminus C) = (A \times B) \setminus (A \times C)$
- [x] $A \times (B \cup C) = (A \times B) \cup (A \times C)$
- [x] $A \times (B \cap C) = (A \times B) \cap (A \times C)$
- [ ] $A \times B = B \times A$

Пояснение:
**Ответ:** первые три.

> **Слайд 8.** «3. Дистрибутивность: A × (B ∩ C) = (A × B) ∩ (A × C); A × (B ∪ C) = (A × B) ∪ (A × C); A × (B \ C) = (A × B) \ (A × C)».

Последнее неверно: по слайду 5 «A × B ≠ B × A, за исключением A = B», декартово произведение не коммутативно.


## 33

Какие отношения на $\mathbb{N}$ рефлексивны?

- [x] $aRb \Leftrightarrow a \le b$
- [x] $aRb \Leftrightarrow a$ делит $b$
- [ ] $aRb \Leftrightarrow a < b$
- [x] $aRb \Leftrightarrow a = b$

Пояснение:
**Ответ:** $a \le b$, $a$ делит $b$, $a = b$.

> **Слайд 53.** «R — рефлексивно, если для ∀a ∈ A: (aRa)».

- $a \le a$ верно для любого $a$.
- $a$ делит $a$: $a = a \cdot 1$.
- $a = a$ верно.
- $a < a$ неверно: строгое неравенство, рефлексивность нарушена.


## 34

$A = \varnothing$, $R = \varnothing$. Какие свойства есть у $R$?

- [x] рефлексивность
- [x] асимметричность
- [x] антирефлексивность
- [x] симметричность

Пояснение:
**Ответ:** все четыре.

На пустом множестве утверждения с $\forall$ истинны: элементов, на которых их нужно проверять, нет.

- $\forall a \in \varnothing: aRa$ — рефлексивно.
- $\forall a \in \varnothing: \lnot(aRa)$ — антирефлексивно.
- $\forall a, b \in \varnothing: aRb \Rightarrow bRa$ — симметрично.
- $\forall a, b \in \varnothing: aRb \Rightarrow \lnot(bRa)$ — асимметрично.

> **Слайд 59.** Для непустого $A$ рефлексивность, антирефлексивность и нерефлексивность делят отношения на непересекающиеся группы. На пустом множестве они пересекаются, потому что проверять нечего.


## 35

Какие отношения симметричны?

- [x] параллельность прямых на плоскости
- [ ] $a \le b$ на множестве чисел
- [x] «быть однокурсником» на множестве студентов
- [ ] «быть родителем» на множестве людей

Пояснение:
**Ответ:** параллельность и «быть однокурсником».

> **Слайд 62.** «R — симметрично, если для ∀a, b ∈ A: aRb ⇒ bRa».

- Если $a \parallel b$, то $b \parallel a$.
- Если $a$ — однокурсник $b$, то $b$ — однокурсник $a$.
- Если $a$ — родитель $b$, то $b$ не родитель $a$.
- $1 \le 2$, но $2 \le 1$ неверно.


## 36

Какие свойства обязательны для любого асимметричного отношения?

- [ ] транзитивность
- [x] антирефлексивность
- [ ] рефлексивность
- [x] антисимметричность

Пояснение:
**Ответ:** антирефлексивность и антисимметричность.

> **Слайд 71.** «Любое асимметричное отношение — антирефлексивно».
>
> **Слайд 66.** «{асимметричные} ⊂ {антисимметричные}».

- **Транзитивность** не обязательна: $R = \{(1, 2), (2, 3)\}$ асимметрично, но $(1, 3) \notin R$.
- **Рефлексивность** не обязательна. Более того, на непустом множестве асимметричное отношение рефлексивным быть не может: оно антирефлексивно.


## 37

Какие отношения на множестве чисел транзитивны?

- [x] $aRb \Leftrightarrow a \le b$
- [x] $aRb \Leftrightarrow a = b$
- [ ] $aRb \Leftrightarrow a + b = 10$
- [x] $aRb \Leftrightarrow a < b$

Пояснение:
**Ответ:** $a \le b$, $a = b$, $a < b$.

> **Слайд 77.** «R — транзитивно, если для ∀a, b, c ∈ A: (aRb) ∧ (bRc) ⇒ (aRc)».

- $a \le b$ и $b \le c$ дают $a \le c$.
- $a = b$ и $b = c$ дают $a = c$.
- $a < b$ и $b < c$ дают $a < c$.
- $a + b = 10$ не транзитивно: $2 + 8 = 10$ и $8 + 2 = 10$, но $2 + 2 \ne 10$.


## 38

$R \subseteq A \times B$. Какие утверждения верны?

- [x] $\operatorname{Dom}(R) \subseteq A$
- [x] $\operatorname{Im}(R) \subseteq B$
- [x] $\operatorname{Im}(R^{-1}) = \operatorname{Dom}(R)$
- [x] $\operatorname{Dom}(R^{-1}) = \operatorname{Im}(R)$

Пояснение:
**Ответ:** все четыре.

- Первые два — по определению (слайды 43–44): первые координаты пар из $A$, вторые из $B$.
- Вторые два — свойства обратного отношения (слайд 49): при переходе к $R^{-1}$ координаты меняются местами.


## 39

Какие свойства матрицы $M_R$ соответствуют симметричному отношению?

- [x] $M_R = M_{R^{-1}}$
- [ ] на главной диагонали только единицы
- [x] $M_R$ симметрична относительно главной диагонали: $M_R = (M_R)^T$
- [ ] на главной диагонали только нули

Пояснение:
**Ответ:** $M_R = M_{R^{-1}}$ и $M_R = (M_R)^T$.

> **Слайд 62.** «Матрица, симметричная относительно главной диагонали».

- $M_{R^{-1}} = (M_R)^T$, поэтому $M_R = M_{R^{-1}}$ — та же симметричность другими словами.
- Единицы на диагонали — признак рефлексивности (слайд 54).
- Нули на диагонали — признак антирефлексивности (слайд 57).


## 40

$A = \{1, 2, 3\}$, $R = \{(1, 1), (2, 2), (3, 3)\}$. Какими свойствами обладает $R$?

- [x] рефлексивностью
- [x] симметричностью
- [x] транзитивностью
- [x] антисимметричностью

Пояснение:
**Ответ:** всеми четырьмя.

- **Рефлексивность:** все петли $(1, 1)$, $(2, 2)$, $(3, 3)$ есть.
- **Симметричность:** для пары $(a, a)$ обратная пара — она сама.
- **Антисимметричность:** если $aRb$ и $bRa$, то $a = b$, других пар нет.
- **Транзитивность:** из $(a, a)$ и $(a, a)$ следует $(a, a)$.

Симметричность и антисимметричность одновременно возможны, когда в отношении нет пар $(a, b)$ с $a \ne b$.


## 41

Какими свойствами обладает отношение $a < b$ на $\mathbb{R}$?

- [x] транзитивностью
- [x] антирефлексивностью
- [ ] рефлексивностью
- [x] асимметричностью

Пояснение:
**Ответ:** транзитивностью, антирефлексивностью, асимметричностью.

- $a < a$ неверно: антирефлексивно, а значит, не рефлексивно.
- $a < b \Rightarrow \lnot(b < a)$: асимметрично.
- $a < b$ и $b < c$ дают $a < c$: транзитивно.


## 42

На рисунке — граф отношения $R$ на $\{1, 2, 3\}$. Какими свойствами обладает $R$?

![Граф на вершинах 1, 2, 3: петли у всех, дуги 1 в 2 и 2 в 1, из 2 в 3, из 1 в 3](q42.svg)

- [x] транзитивностью
- [ ] антисимметричностью
- [x] рефлексивностью
- [ ] симметричностью

Пояснение:
**Ответ:** транзитивностью и рефлексивностью.

По графу $R = \{(1, 1), (2, 2), (3, 3), (1, 2), (2, 1), (2, 3), (1, 3)\}$.

- **Рефлексивность:** у каждой вершины есть петля.
- **Транзитивность:** цепочки $(1, 2), (2, 3)$ дают $(1, 3)$; $(2, 1), (1, 3)$ дают $(2, 3)$; $(1, 2), (2, 1)$ дают $(1, 1)$; $(2, 1), (1, 2)$ дают $(2, 2)$. Все нужные пары есть, цепочки с петлями ничего нового не дают.
- **Не симметрично:** есть $(2, 3)$, нет $(3, 2)$.
- **Не антисимметрично:** есть $(1, 2)$ и $(2, 1)$ при $1 \ne 2$.


## 43

На рисунке — граф отношения $R$ на $\{1, 2, 3\}$. Какие утверждения верны?

![Граф на вершинах 1, 2, 3: дуги из 1 в 2 и из 2 в 3, петель нет](q43.svg)

- [x] $R$ антирефлексивно
- [x] $R$ асимметрично
- [ ] $R$ транзитивно
- [x] $R$ антитранзитивно

Пояснение:
**Ответ:** антирефлексивно, асимметрично, антитранзитивно.

По графу $R = \{(1, 2), (2, 3)\}$.

- **Антирефлексивно:** петель нет.
- **Асимметрично:** нет пар, связанных в обе стороны.
- **Не транзитивно:** есть $(1, 2)$ и $(2, 3)$, нет $(1, 3)$.
- **Антитранзитивно:** цепочка из двух дуг одна, $1 \to 2 \to 3$, и замыкающей дуги $(1, 3)$ нет. Транзитивных троек нет совсем, поэтому отношение не нетранзитивно, а именно антитранзитивно.


## 44

На рисунке — граф отношения $R$ на $\{1, 2, 3\}$. Каких пар не хватает, чтобы $R$ стало транзитивным?

![Граф на вершинах 1, 2, 3: дуги из 1 в 2, из 2 в 3, петля у 3](q44.svg)

- [ ] $(2, 1)$
- [x] $(1, 3)$
- [ ] $(3, 1)$
- [ ] $(1, 1)$

Пояснение:
**Ответ:** только $(1, 3)$.

По графу $R = \{(1, 2), (2, 3), (3, 3)\}$.

- Цепочка $(1, 2), (2, 3)$ требует $(1, 3)$, её нет.
- Цепочка $(2, 3), (3, 3)$ требует $(2, 3)$, она есть.
- После добавления $(1, 3)$ появится цепочка $(1, 3), (3, 3)$, она требует $(1, 3)$, и это уже выполнено.

$(3, 1)$, $(2, 1)$ и $(1, 1)$ ни из одной цепочки не следуют.

- [x] симметричностью

## 46

Какие утверждения об асимметричных и антисимметричных отношениях верны?

- [x] в антисимметричном отношении разрешены петли $(a, a)$
- [x] в асимметричном отношении $aRb \Rightarrow \lnot(bRa)$ для любых $a, b$
- [x] в асимметричном отношении петли $(a, a)$ запрещены
- [x] в асимметричном отношении разрешены дуги между разными элементами, но запрещены рёбра

Пояснение:
**Ответ:** все четыре.

> **Слайды 65–70.** Определения асимметричности и антисимметричности.

- **Б** — определение асимметричности.
- **В:** при $b = a$ получаем $aRa \Rightarrow \lnot(aRa)$, противоречие. Петель нет.
- **А:** для антисимметричности $aRa \land aRa \Rightarrow a = a$ — истинно, петли разрешены.
- **Г:** асимметричность разрешает дугу $a \to b$, но запрещает обратную, а ребро — это дуги в обе стороны.

Главное отличие — диагональ: асимметричное отношение запрещает петли, антисимметричное разрешает.


## 47

Какие комбинации свойств невозможны для одного отношения на непустом множестве?

- [ ] антисимметричность и транзитивность
- [x] симметричность и асимметричность, если в отношении есть хотя бы одна пара
- [ ] рефлексивность и транзитивность
- [x] рефлексивность и антирефлексивность

Пояснение:
**Ответ:** симметричность с асимметричностью и рефлексивность с антирефлексивностью.

- **Рефлексивно и антирефлексивно:** первое требует $aRa$ для всех $a$, второе запрещает $aRa$ для всех $a$. На непустом множестве невозможно.
- **Симметрично и асимметрично:** если $aRb$, симметричность требует $bRa$, асимметричность запрещает. Невозможно при хотя бы одной паре.
- **Рефлексивно и транзитивно** — возможно, например равенство.
- **Антисимметрично и транзитивно** — возможно, например $a \le b$.
