# Блок 1. Один верный вариант

## 1

Как определяется энтропия Шеннона дискретного источника с распределением вероятностей $P = (p_1, \dots, p_n)$?

- ( ) $H(X) = \sum_{i=1}^n p_i^2$
- (x) $H(X) = -\sum_{i=1}^n p_i \log_2 p_i$
- ( ) $H(X) = \log_2 \sum_{i=1}^n \frac{1}{p_i}$
- ( ) $H(X) = \prod_{i=1}^n p_i$

Пояснение:
**Ответ:** $H(X) = -\sum p_i \log_2 p_i$.

Энтропия Шеннона представляет собой математическое ожидание собственной информации символов: $H(X) = \mathbb{E}[I(x)] = \sum p_i (-\log_2 p_i) = -\sum p_i \log_2 p_i$.


## 2

При каком распределении вероятностей $n$ символов энтропия дискретного источника достигает своего абсолютного максимума?

- ( ) При геометрическом распределении
- ( ) Когда один символ имеет вероятность 0.99
- (x) При равномерном распределении: $p_1 = p_2 = \dots = p_n = \frac{1}{n}$
- ( ) При распределении Пуассона

Пояснение:
**Ответ:** При равномерном распределении $p_i = \frac{1}{n}$.

Максимальная неопределенность наступает тогда, когда все исходы равновероятны. В этом случае энтропия равна $H_{\max} = \log_2 n$ (формула Хартли).


## 3

В чем заключается условие Фано для схемы алфавитного кодирования?

- ( ) Все кодовые слова должны иметь одинаковую длину
- ( ) Сумма длин всех кодовых слов должна быть степенью двойки
- (x) Никакое кодовое слово не должно являться префиксом (началом) другого кодового слова
- ( ) Каждое кодовое слово обязано заканчиваться единицей

Пояснение:
**Ответ:** Никакое кодовое слово не является префиксом другого кодового слова.

Условие Фано определяет префиксный код. Оно позволяет однозначно декодировать сообщение на лету (мгновенно), без задержек и заглядывания вперед.


## 4

Какое неравенство связывает длины кодовых слов $\ell_i$ в $d$-ичном алфавите для существования префиксного (и однозначно декодируемого) кода?

- ( ) Неравенство Коши–Буняковского
- (x) Неравенство Крафта–Макмиллана: $\sum_{i=1}^n d^{-\ell_i} \le 1$
- ( ) Неравенство Маркова
- ( ) Неравенство Чебышёва

Пояснение:
**Ответ:** Неравенство Крафта–Макмиллана $\sum d^{-\ell_i} \le 1$.

Теорема Крафта–Макмиллана устанавливает необходимое и достаточное условие существования разделимого кода: сумма $d^{-\ell_i}$ по всем кодовым словам не превосходит 1.


## 5

Что утверждает первая теорема Шеннона для дискретного канала без шума?

- ( ) Любой код можно сжать до нуля бит
- (x) Средняя длина кодового слова $L$ любого однозначно декодируемого двоичного кода не может быть меньше энтропии источника: $L \ge H(X)$
- ( ) Энтропия источника всегда равна числу символов алфавита
- ( ) Вероятность ошибки при передаче равна 0.5

Пояснение:
**Ответ:** $L \ge H(X)$.

Теорема Шеннона устанавливает фундаментальный теоретический предел сжатия: средняя длина кода не может быть меньше энтропии источника. При этом всегда существует префиксный код, для которого $H(X) \le L < H(X) + 1$.


## 6

Как устроен алгоритм построения дерева Хаффмана?

- ( ) Символы делятся сверху вниз на две равные половины
- (x) Снизу вверх жадно объединяются два узла с наименьшими суммарными вероятностями
- ( ) Кодовые слова выбираются случайным образом
- ( ) Символы кодируются в порядке их следования в тексте

Пояснение:
**Ответ:** Снизу вверх объединяются два узла с наименьшими вероятностями.

Алгоритм Хаффмана — восходящий жадный алгоритм: на каждом шаге берутся два поддерева с минимальным весом, объединяются новым родительским узлом с суммарным весом, пока не останется один корень. Доказано, что код Хаффмана оптимален среди всех посимвольных кодов.


## 7

Чему равна собственная информация $I(a)$ события, вероятность которого равна $p = \frac{1}{8}$?

- ( ) 1 бит
- ( ) 2 бита
- (x) 3 бита
- ( ) 8 бит

Пояснение:
**Ответ:** 3 бита.

$I(a) = \log_2 \frac{1}{p} = \log_2 \frac{1}{1/8} = \log_2 8 = 3$ бита.


## 8

В чем главное преимущество арифметического кодирования перед кодированием Хаффмана?

- ( ) Оно не требует знания вероятностей символов
- ( ) Оно работает только со строками фиксированной длины
- (x) Оно способно выделять на символ дробное число бит (меньше 1 бита), кодируя все сообщение целиком в виде одного числа из $[0, 1)$
- ( ) Оно полностью устраняет шум в канале связи

Пояснение:
**Ответ:** Выделяет дробное число бит на символ, кодируя сообщение в интервал $[0, 1)$.

Код Хаффмана привязан к целому числу бит на символ (минимум 1 бит), даже если энтропия символа близка к 0 (например, $p = 0.999$). Арифметическое кодирование сопоставляет всей строке точку (подынтервал) в отрезке $[0, 1)$ и достигает сжатия, сколь угодно близкого к энтропии Шеннона.


## 9

Дан двоичный код: $c(a) = 0$, $c(b) = 01$, $c(c) = 11$. Является ли он префиксным?

- ( ) Да, так как все слова различны
- (x) Нет, так как кодовое слово $c(a) = 0$ является префиксом слова $c(b) = 01$
- ( ) Да, так как длины слов не превышают 2
- ( ) Нет, так как отсутствует слово 10

Пояснение:
**Ответ:** Нет, слово `0` является префиксом слова `01`.

Нарушено условие Фано: кодовое слово символа $a$ совпадает с начальной частью кодового слова символа $b$. При чтении бита `0` декодер не может мгновенно решить, завершился ли символ $a$ или продолжается символ $b$.


## 10

Чему равна энтропия честной монеты с двумя равновероятными исходами ($p_1 = p_2 = 0.5$)?

- ( ) 0 бит
- ( ) 0.5 бит
- (x) 1 бит
- ( ) 2 бита

Пояснение:
**Ответ:** 1 бит.

$H(X) = -(0.5 \log_2 0.5 + 0.5 \log_2 0.5) = - (0.5 \cdot (-1) + 0.5 \cdot (-1)) = 1$ бит. Один бит — это мера неопределенности выбора между двумя равновероятными событиями.


# Блок 2. Краткий ответ

## 11

Источник порождает 4 равновероятных символа ($p_1 = p_2 = p_3 = p_4 = 0.25$). Вычислите энтропию источника $H(X)$ в битах.

Ответ: 2
Формат: целое число

Пояснение:
**Ответ:** 2.

По формуле Хартли для $n = 4$ равновероятных символов:
$H(X) = \log_2 4 = 2$ бита.


## 12

Проверьте неравенство Крафта для длин двоичных кодовых слов: $\ell = (1, 2, 3, 3)$. Вычислите сумму $\sum 2^{-\ell_i}$. Если сумма равна 1, запишите в ответе 1.

Ответ: 1
Формат: целое число

Пояснение:
**Ответ:** 1.

$\sum 2^{-\ell_i} = 2^{-1} + 2^{-2} + 2^{-3} + 2^{-3} = \frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{1}{8} = \frac{4 + 2 + 1 + 1}{8} = \frac{8}{8} = 1$.
Сумма в точности равна 1 (код полный).


## 13

В алфавите из 3 символов заданы вероятности $p_1 = 0.5, p_2 = 0.25, p_3 = 0.25$ и длины кодовых слов Хаффмана: $\ell_1 = 1, \ell_2 = 2, \ell_3 = 2$. Найдите среднюю длину кодового слова $L$ (умноженную на 10 для целого ответа или запишите десятичную дробь). Введите точное значение средней длины $L$ (например, 1.5).

Ответ: 1.5
Формат: число

Пояснение:
**Ответ:** 1.5.

$L = \sum p_i \ell_i = 0.5 \cdot 1 + 0.25 \cdot 2 + 0.25 \cdot 2 = 0.5 + 0.5 + 0.5 = 1.5$ бит/символ.
Заметим, что энтропия источника: $H(X) = - (0.5 \log_2 0.5 + 2 \cdot 0.25 \log_2 0.25) = - (0.5 \cdot (-1) + 0.5 \cdot (-2)) = 0.5 + 1.0 = 1.5$ бит. Избыточность кода равна 0.


## 14

Какова глубина листа с наименьшей вероятностью в дереве Хаффмана для источника с вероятностями $0.7, 0.15, 0.15$?

Ответ: 2
Формат: целое число

Пояснение:
**Ответ:** 2.

Два узла с вероятностями $0.15$ и $0.15$ объединяются первыми, образуя поддерево веса $0.30$. Затем этот узел объединяется с узлом $0.70$ в корень веса $1.00$. Символы с вероятностью $0.15$ получают кодовые слова длины 2 (глубина 2), а символ с $0.70$ — длины 1.


## 15

Сколько бит необходимо для равномерного кодирования каждого из 32 различных символов алфавита?

Ответ: 5
Формат: целое число

Пояснение:
**Ответ:** 5.

Длина равномерного двоичного кода равна $\lceil \log_2 32 \rceil = 5$ бит, так как $2^5 = 32$.


## 16

Чему равна энтропия детерминированного источника, в котором вероятность одного события равна 1, а всех остальных — 0?

Ответ: 0
Формат: целое число

Пояснение:
**Ответ:** 0.

$H(X) = - (1 \log_2 1 + 0) = - (1 \cdot 0) = 0$ бит. В полностью детерминированной системе нет неопределенности, появление известного заранее символа не несет новой информации.


# Блок 3. Несколько верных вариантов

## 17

Какие из следующих наборов двоичных кодовых слов удовлетворяют условию Фано (являются префиксными кодами)?

- [x] $\{0, 10, 110, 111\}$
- [ ] $\{0, 01, 011, 0111\}$
- [x] $\{00, 01, 10, 11\}$
- [ ] $\{1, 10, 100\}$
- [x] $\{00, 01, 1\}$

Пояснение:
**Ответ:** $\{0, 10, 110, 111\}$; $\{00, 01, 10, 11\}$; $\{00, 01, 1\}$.

В наборе $\{0, 01, \dots\}$ слово `0` является префиксом остальных. В наборе $\{1, 10, 100\}$ слово `1` — префикс `10`. В остальных трех наборах ни одно слово не начинается с другого.


## 18

Какие свойства справедливы для информационной энтропии Шеннона $H(X)$?

- [x] $H(X) \ge 0$ (неотрицательность)
- [x] $H(X) = 0$ тогда и только тогда, когда одно событие достоверно
- [x] $H(X) \le \log_2 n$, где $n$ — мощность алфавита
- [ ] Энтропия может принимать отрицательные значения для малых вероятностей
- [x] Для независимых случайных величин $X$ и $Y$ выполнено $H(X, Y) = H(X) + H(Y)$ (аддитивность)

Пояснение:
**Ответ:** Неотрицательность; равенство 0 при достоверности; ограничение сверху $\log_2 n$; аддитивность для независимых величин.

Дискретная энтропия Шеннона строго неотрицательна, так как все $p_i \in [0, 1] \implies \log_2 p_i \le 0 \implies -\sum p_i \log_2 p_i \ge 0$.


## 19

Какие утверждения об алгоритме Хаффмана верны?

- [x] Код Хаффмана всегда является префиксным
- [x] Код Хаффмана гарантирует минимальную среднюю длину кодового слова среди всех посимвольных однозначно декодируемых кодов
- [x] Более вероятные символы получают более короткие кодовые слова
- [ ] Дерево Хаффмана всегда строится сверху вниз
- [x] Два наименее вероятных символа в оптимальном коде имеют одинаковую максимальную длину

Пояснение:
**Ответ:** Префиксный код; минимальная средняя длина; частые символы короче; наименее вероятные символы имеют одинаковую максимальную длину.

Дерево Хаффмана строится снизу вверх (bottom-up жадное объединение). Сверху вниз строится код Шеннона–Фано.


## 20

Для каких из перечисленных наборов длин двоичных кодовых слов выполнено неравенство Крафта $\sum 2^{-\ell_i} \le 1$?

- [x] $\ell = (2, 2, 2, 2)$
- [x] $\ell = (1, 2, 3, 3)$
- [ ] $\ell = (1, 1, 2)$
- [x] $\ell = (2, 3, 3, 3, 3)$
- [ ] $\ell = (1, 2, 2, 2)$

Пояснение:
**Ответ:** $(2, 2, 2, 2)$; $(1, 2, 3, 3)$; $(2, 3, 3, 3, 3)$.

- $(2, 2, 2, 2)$: $4 \times 1/4 = 1 \le 1$.
- $(1, 2, 3, 3)$: $1/2 + 1/4 + 1/8 + 1/8 = 1 \le 1$.
- $(1, 1, 2)$: $1/2 + 1/2 + 1/4 = 1.25 > 1$ (не существует!).
- $(2, 3, 3, 3, 3)$: $1/4 + 4 \times 1/8 = 3/4 \le 1$.
- $(1, 2, 2, 2)$: $1/2 + 3/4 = 1.25 > 1$.


## 21

Какие утверждения об арифметическом кодировании верны?

- [x] Все сообщение целиком кодируется в виде одного подотрезка внутри $[0, 1)$
- [x] Каждому символу соответствует уменьшение текущего отрезка пропорционально его вероятности
- [x] Длина итогового двоичного числа определяется шириной финального интервала
- [ ] Арифметическое кодирование является посимвольным префиксным кодом
- [x] Оно позволяет преодолеть ограничение в 1 бит на символ для высоковероятных событий

Пояснение:
**Ответ:** Кодирование в $[0, 1)$; сужение пропорционально вероятности; длина по ширине интервала; преодолевает барьер 1 бит/символ.

Арифметический код не является посимвольным префиксным кодом, так как он не сопоставляет каждому отдельному символу фиксированное кодовое слово из битов.


## 22

Какие параметры влияют на избыточность $R = L - H(X)$ кода?

- [x] Распределение вероятностей символов
- [x] Длины назначенных кодовых слов $\ell_i$
- [x] Степень приближения длин $\ell_i$ к идеальным значениям $\log_2 \frac{1}{p_i}$
- [ ] Скорость вращения жесткого диска
- [ ] Начертание шрифта символов

Пояснение:
**Ответ:** Распределение вероятностей; длины кодовых слов; близость длин к $-\log_2 p_i$.

Избыточность $R = 0$ достигается в том и только том случае, когда все вероятности являются отрицательными степенями двойки: $p_i = 2^{-\ell_i}$ (диадические вероятности).
