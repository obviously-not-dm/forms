# Блок 1. Один верный вариант

## 1

Какая формула пропозициональной логики называется тавтологией (общезначимой формулой, $\models \varphi$)?

- ( ) Формула, истинная хотя бы при одной интерпретации
- (x) Формула, принимающая значение «Истина» при любой возможной интерпретации переменных
- ( ) Формула, не содержащая отрицаний
- ( ) Формула, ложная на всех наборах

Пояснение:
**Ответ:** Формула, истинная при любой интерпретации.

Тавтология истинна независимо от истинностных значений входящих в неё элементарных высказываний. Классический пример: закон исключенного третьего $P \lor \neg P$.


## 2

Что означает утверждение о пустой истине (vacuous truth) для импликации $P \implies Q$?

- ( ) Если следствие $Q$ истинно, то посылка $P$ обязана быть истинной
- (x) Если посылка $P$ ложна, импликация истинна независимо от истинности следствия $Q$ ($0 \implies Q \equiv 1$)
- ( ) Импликация ложна, если в ней нет кванторов
- ( ) Формула не имеет смысла

Пояснение:
**Ответ:** Если посылка $P$ ложна, импликация тождественно истинна.

По таблице истинности импликации $\text{Ложь} \implies \text{что угодно}$ всегда дает $\text{Истину}$. Например, утверждение «Все элементы пустого множества положительны» истинно в силу отсутствия элементов, нарушающих условие.


## 3

Чем семантическое следование $\Gamma \models \varphi$ отличается от синтаксического вывода $\Gamma \vdash \varphi$?

- ( ) Семантическое следование строится по правилам грамматики, а синтаксический вывод использует таблицы
- (x) $\Gamma \models \varphi$ означает, что в любой модели, где истинны все формулы $\Gamma$, истинна и $\varphi$; а $\Gamma \vdash \varphi$ означает существование формального дедуктивного вывода по аксиомам и правилам
- ( ) Между ними нет никакой разницы
- ( ) Синтаксический вывод применим только к числам

Пояснение:
**Ответ:** $\Gamma \models \varphi$ оперирует истинностными оценками (моделями), а $\Gamma \vdash \varphi$ — формальными цепочками символьных преобразований.

Семантика отвечает на вопрос об истинности в мирах/интерпретациях, а синтаксис — на вопрос о механической выводимости по заданным правилам (например, Modus Ponens).


## 4

Как формулируется закон отрицания квантора всеобщности $\neg(\forall x \, P(x))$?

- ( ) $\forall x \, \neg P(x)$
- (x) $\exists x \, \neg P(x)$
- ( ) $\exists x \, P(x)$
- ( ) $\neg(\exists x \, P(x))$

Пояснение:
**Ответ:** $\exists x \, \neg P(x)$.

Утверждение «Не все объекты обладают свойством $P$» логически эквивалентно утверждению «Существует хотя бы один объект, не обладающий свойством $P$».


## 5

Что такое предварённая нормальная форма (ПНФ) формулы логики предикатов?

- ( ) Формула, в которой все кванторы устранены
- (x) Формула, в которой все кванторы вынесены в начало, а матрица содержит только бескванторные логические связки
- ( ) Формула, содержащая только конъюнкции
- ( ) Полином Жегалкина от предикатов

Пояснение:
**Ответ:** Все кванторы вынесены в начало формулы: $Q_1 x_1 \dots Q_k x_k \, M(x_1, \dots, x_k)$.

В ПНФ кванторная приставка находится строго в начале формулы, а область действия всех кванторов распространяется на всю оставшуюся бескванторную матрицу $M$.


## 6

В формуле $\forall x \, \exists y \, P(x, y)$ проводится сколемизация. Чем заменяется переменная $y$?

- ( ) Константой Сколема $c$
- (x) Функцией Сколема от переменной $x$: $y \leftarrow f(x)$
- ( ) Переменной $x$
- ( ) Логическим нулем

Пояснение:
**Ответ:** Функцией Сколема $f(x)$.

Поскольку квантор существования $\exists y$ находится в области действия универсального квантора $\forall x$, значение $y$ может зависеть от выбора $x$. Поэтому $y$ заменяется новой функциональной переменной $f(x)$, давая $\forall x \, P(x, f(x))$.


## 7

Какое соотношение истинности связывает исходную формулу предикатов и её форму Сколема?

- ( ) Они строго логически эквивалентны
- (x) Они равновыполнимы (исходная формула выполнима тогда и только тогда, когда выполнима её форма Сколема)
- ( ) Форма Сколема всегда ложна
- ( ) Форма Сколема содержит больше кванторов

Пояснение:
**Ответ:** Они равновыполнимы (equisatisfiable).

Сколемизация не сохраняет тождественную эквивалентность на всех интерпретациях, поскольку вводит новые функциональные символы, отсутствовавшие в исходном языке. Однако формула имеет модель тогда и только тогда, когда модель имеет её форма Сколема.


## 8

Что является результатом применения правила резолюции к двум дизъюнктам $P \lor Q$ и $\neg P \lor R$?

- ( ) $P \lor R$
- ( ) $Q \land R$
- (x) $Q \lor R$
- ( ) Пустой дизъюнкт

Пояснение:
**Ответ:** $Q \lor R$.

Правило резолюции (вырезание контрарной пары): из посылок $A \lor L$ и $B \lor \neg L$ выводится резольвента $A \lor B$. Здесь $L = P$, поэтому из $Q \lor P$ и $R \lor \neg P$ получаем $Q \lor R$.


## 9

К какому выводу приводит получение пустого дизъюнкта ($\square$) в методе резолюций Робинсона?

- ( ) Формула выполнима
- (x) Множество дизъюнктов противоречиво (невыполнимо), что доказывает истинность исходного утверждения
- ( ) Произошла ошибка алгоритма
- ( ) Необходимо добавить новые кванторы

Пояснение:
**Ответ:** Множество дизъюнктов противоречиво, утверждение доказано.

Доказательство в методе резолюций ведется от противного: отрицание доказываемой цели добавляется к посылкам. Получение пустого дизъюнкта (контрарной пары без остатка, например $P$ и $\neg P$) означает обнаружение логического противоречия, что завершает доказательство.


## 10

Что выполняет алгоритм унификации в логике предикатов первого порядка?

- ( ) Преобразует предикаты в формулы теории множеств
- (x) Находит наиболее общий унификатор (подстановку термов вместо переменных), делающий два литерала тождественно совпадающими
- ( ) Вычисляет значение истинности формулы
- ( ) Удаляет все скобки

Пояснение:
**Ответ:** Находит наиболее общий унификатор (MGU), делающий два выражения идентичными.

Унификация находит минимально специализированную подстановку термов вместо переменных, позволяющую сопоставить предикаты (например, $P(x, f(a))$ и $P(b, y)$ унифицируются подстановкой $\{x \leftarrow b, y \leftarrow f(a)\}$).


# Блок 2. Краткий ответ

## 11

Сколько различных интерпретаций (строк в таблице истинности) существует для формулы логики высказываний, содержащей 4 пропозициональные переменные?

Ответ: 16
Формат: целое число

Пояснение:
**Ответ:** 16.

Каждая из 4 переменных может принимать одно из 2 значений ($0$ или $1$). Число интерпретаций равно $2^4 = 16$.


## 12

Даны посылки: $A \implies B$ и $A$. По классическому правилу вывода *Modus Ponens*, какое высказывание синтаксически выводимо? Запишите имя выводимой переменной латинской буквой.

Ответ: B
Формат: текст

Пояснение:
**Ответ:** B.

Правило Modus Ponens: $\frac{A, \; A \implies B}{B}$. Из истинности посылки $A$ и правила $A \implies B$ следует истинность $B$.


## 13

В формуле $\exists x \, P(x)$ квантор существования находится вне области действия универсальных кванторов. Сколькими аргументами обладает символ Сколема, заменяющий переменную $x$?

Ответ: 0
Формат: целое число

Пояснение:
**Ответ:** 0.

Если перед $\exists x$ нет ни одного квантора всеобщности $\forall$, переменная $x$ заменяется константой Сколема $c$ (функцией с 0 аргументов).


## 14

Сколько контрарных пар литералов содержится в дизъюнктах $C_1 = P \lor Q$ и $C_2 = \neg P \lor \neg Q$?

Ответ: 2
Формат: целое число

Пояснение:
**Ответ:** 2.

Контрарные пары: $(P, \neg P)$ и $(Q, \neg Q)$. Всего 2 пары.


## 15

Чему равно значение истинности предикатной формулы $\forall x \in \mathbb{N} \; (x \ge 0)$? Запишите 1 для истины или 0 для лжи.

Ответ: 1
Формат: целое число

Пояснение:
**Ответ:** 1.

Все натуральные числа неотрицательны, поэтому предикат истинен для любого элемента предметной области.


## 16

Какое число резольвент первого порядка можно непосредственно получить из пары дизъюнктов $A \lor B$ и $\neg A \lor B$?

Ответ: 1
Формат: целое число

Пояснение:
**Ответ:** 1.

Единственная контрарная пара — это $(A, \neg A)$. Резольвента: $B \lor B = B$. Получается ровно один дизъюнкт.


# Блок 3. Несколько верных вариантов

## 17

Какие из следующих формул логики высказываний являются тавтологиями?

- [x] $P \lor \neg P$ (закон исключенного третьего)
- [x] $\neg(P \land \neg P)$ (закон противоречия)
- [x] $P \implies (Q \implies P)$ (аксиома утверждения консеквента)
- [ ] $P \implies \neg P$
- [x] $(P \implies Q) \iff (\neg Q \implies \neg P)$ (закон контрапозиции)

Пояснение:
**Ответ:** Закон исключенного третьего; закон противоречия; $P \implies (Q \implies P)$; закон контрапозиции.

Формула $P \implies \neg P$ эквивалентна $\neg P$ и не является тавтологией (она ложна при $P = 1$).


## 18

Какие утверждения о кванторах в логике предикатов являются верными?

- [x] $\neg(\exists x \, P(x)) \equiv \forall x \, \neg P(x)$
- [x] $\forall x \, (P(x) \land Q(x)) \equiv (\forall x \, P(x)) \land (\forall x \, Q(x))$
- [x] $\exists x \, (P(x) \lor Q(x)) \equiv (\exists x \, P(x)) \lor (\exists x \, Q(x))$
- [ ] $\forall x \, (P(x) \lor Q(x)) \equiv (\forall x \, P(x)) \lor (\forall x \, Q(x))$
- [x] Из $\forall x \, P(x)$ семантически следует $\exists x \, P(x)$ при непустой предметной области

Пояснение:
**Ответ:** Отрицание существования; дистрибутивность $\forall$ по $\land$; дистрибутивность $\exists$ по $\lor$; следствие $\forall \implies \exists$ на непустой области.

Квантор всеобщности НЕ дистрибутивен относительно дизъюнкции: например, для четных и нечетных чисел верно $\forall x \, (\mathrm{Even}(x) \lor \mathrm{Odd}(x))$, но неверно $(\forall x \, \mathrm{Even}(x)) \lor (\forall x \, \mathrm{Odd}(x))$.


## 19

Какие этапы входят в алгоритм приведения формулы предикатов к предварённой нормальной форме (ПНФ)?

- [x] Выражение связок $\implies$ и $\iff$ через $\neg, \lor, \land$
- [x] Продвижение отрицания непосредственно к предикатам
- [x] Переименование связанных переменных во избежание коллизий имен
- [x] Вынесение кванторов в начало формулы
- [ ] Замена всех предикатов константами 0 и 1

Пояснение:
**Ответ:** Исключение импликаций; пронос отрицаний; переименование связанных переменных; вынесение кванторов в префикс.

Замена предикатов константами уничтожает предикатную структуру высказывания и не является частью построения ПНФ.


## 20

Какие свойства справедливы для метода резолюций Джона Робинсона?

- [x] Метод резолюций обладает свойством полноты опровержения (refutation completeness)
- [x] Доказательство ведется добавлением отрицания целевого утверждения к посылкам
- [x] Формулы предварительно преобразуются в конъюнктивную нормальную форму дизъюнктов
- [ ] Метод требует обязательного перебора всех интерпретаций
- [x] Метод лежит в основе языка логического программирования Prolog

Пояснение:
**Ответ:** Полнота опровержения; доказательство от противного; клозовая КНФ; основа языка Prolog.

Метод резолюций является чисто синтаксическим методом и не строит таблицы истинности, что позволяет применять его в бесконечных предметных областях логики предикатов.


## 21

Даны дизъюнкты $C_1 = P(x) \lor Q(x)$ и $C_2 = \neg P(a) \lor R(y)$. Какая унификация и резольвента допустимы?

- [x] Унификатор подстановки: $\{x \leftarrow a\}$
- [x] Резольвента: $Q(a) \lor R(y)$
- [ ] Унификатор: $\{y \leftarrow x\}$
- [ ] Резольвента: $\square$
- [x] Литералы $P(x)$ и $\neg P(a)$ образуют контрарную пару при $x = a$

Пояснение:
**Ответ:** Унификатор $\{x \leftarrow a\}$; резольвента $Q(a) \lor R(y)$; контрарная пара при $x = a$.

Подстановка $x \leftarrow a$ делает атомы $P(x)$ и $P(a)$ тождественными. Вырезая $P(a)$ и $\neg P(a)$, получаем $Q(a) \lor R(y)$.


## 22

Какие правила логического вывода являются общезначимыми правилами дедукции?

- [x] *Modus Ponens*: из $A$ и $A \implies B$ следует $B$
- [x] *Modus Tollens*: из $\neg B$ и $A \implies B$ следует $\neg A$
- [x] Правило силлогизма (транзитивность импликации): из $A \implies B$ и $B \implies C$ следует $A \implies C$
- [ ] Утверждение консеквента: из $B$ и $A \implies B$ следует $A$
- [x] Правило резолюции: из $A \lor B$ и $\neg A \lor C$ следует $B \lor C$

Пояснение:
**Ответ:** Modus Ponens; Modus Tollens; транзитивность импликации; правило резолюции.

Утверждение консеквента (Affirming the consequent) — классическая логическая ошибка (софизм): из того, что идет дождь, асфальт мокрый, но из мокрого асфальта дождь не следует (его могли полить).
