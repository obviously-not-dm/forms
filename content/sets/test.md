# Блок 1. Один верный вариант

## 1

Какое утверждение о $\varnothing$ верно?

- ( ) $\varnothing$ — множество, содержащее один элемент, и $|\varnothing| = 1$
- ( ) $\varnothing \notin A$ для любого множества $A$
- (x) $\varnothing$ — множество, не содержащее ни одного элемента, и $|\varnothing| = 0$
- ( ) $\varnothing = \{\varnothing\}$

Пояснение:
**Ответ:** $\varnothing$ не содержит ни одного элемента, $|\varnothing| = 0$.

**Почему не подходят остальные**

- $\varnothing \ne \{\varnothing\}$: справа множество из одного элемента, и этот элемент — $\varnothing$.
- «$\varnothing \notin A$ для любого $A$» неверно: например, $\varnothing \in \{\varnothing\}$.

Не путайте: $\varnothing \subseteq A$ верно для любого $A$, а $\varnothing \in A$ — не всегда.


## 2

Какое утверждение о равенстве двух множеств $A$ и $B$ верно?

- ( ) $A = B \Leftrightarrow A \cap B = \varnothing$
- ( ) $A = B \Leftrightarrow |A| = |B|$
- ( ) $A = B \Leftrightarrow A \subseteq B$ или $B \subseteq A$
- (x) $A = B \Leftrightarrow A \subseteq B$ и $B \subseteq A$

Пояснение:
**Ответ:** $A = B \Leftrightarrow A \subseteq B$ и $B \subseteq A$.

Множества равны, если каждое содержится в другом.

**Почему не подходят остальные**

- «Или»: $\{1\} \subseteq \{1, 2\}$, но множества не равны.
- Равенство мощностей не означает равенства множеств: $|\{1\}| = |\{2\}|$.
- $A \cap B = \varnothing$ означает, что у множеств нет общих элементов.


## 3

Даны записи $A = \{1, 1, 3, 3, 2\}$ и $B = \{1, 2, 3\}$. Какое утверждение верно?

- ( ) $A \ne B$, так как в $A$ есть повторяющиеся элементы
- ( ) $A = B$, но $|A| = 5 \ne |B| = 3$
- ( ) $A \ne B$, так как порядок элементов разный
- (x) $A = B$ и $|A| = |B| = 3$, так как все элементы множества уникальны

Пояснение:
**Ответ:** $A = B$ и $|A| = |B| = 3$.

В множестве нет порядка и повторов. Запись $\{1, 1, 3, 3, 2\}$ задаёт то же множество $\{1, 2, 3\}$, поэтому $A = B$ и $|A| = 3$. Повторы и порядок записи ни на что не влияют.


## 4

Для чего используются диаграммы Эйлера–Венна?

- ( ) Для строгого доказательства равенств между множествами
- (x) Для графического изображения отношений между множествами
- ( ) Для вычисления мощности декартова произведения
- ( ) Для перечисления всех элементов множества

Пояснение:
**Ответ:** для графического изображения отношений между множествами.

Диаграмма наглядно показывает пересечения, объединения и включения. Строгим доказательством она не является: доказывают через определения или законы алгебры множеств. Мощности и перечисление элементов — не её задача.


## 5

Какое утверждение об $A \cup B$ верно для любых множеств $A$ и $B$?

- ( ) $A \cup B$ содержит только общие элементы $A$ и $B$
- (x) $A \subseteq A \cup B$ и $|A| \le |A \cup B|$
- ( ) $A \cup B = A \cap B$, если $A \cap B \ne \varnothing$
- ( ) $A \subset A \cup B$ и $|A| < |A \cup B|$

Пояснение:
**Ответ:** $A \subseteq A \cup B$ и $|A| \le |A \cup B|$.

Любой элемент $A$ лежит в $A \cup B$, поэтому $A \subseteq A \cup B$. Отсюда $|A| \le |A \cup B|$.

**Почему не подходят остальные**

- Строгого неравенства может не быть: если $B \subseteq A$, то $A \cup B = A$.
- Общие элементы — это пересечение, а не объединение.
- $A \cup B = A \cap B$ только при $A = B$, пересечение тут ни при чём.


## 6

Дано $C = \{1, 2, \{1, 2, 4\}, 3\}$. Какое утверждение верно?

- (x) $\{1, 2, 4\} \in C$, но $\{1, 2, 4\} \not\subset C$
- ( ) $\{1, 2, 4\} \notin C$, но $\{1, 2, 4\} \subset C$
- ( ) $\{1, 2, 4\} \in C$, и при этом $\{1, 2, 4\} \subset C$
- ( ) $\{1, 2, 4\} \notin C$, и $\{1, 2, 4\} \not\subset C$

Пояснение:
**Ответ:** $\{1, 2, 4\} \in C$, но $\{1, 2, 4\} \not\subset C$.

- $\{1, 2, 4\}$ — один из четырёх элементов $C$, поэтому $\{1, 2, 4\} \in C$.
- Подмножеством $C$ оно не является: $4 \notin C$. Элементы $C$ — это 1, 2, 3 и само множество $\{1, 2, 4\}$.


## 7

Какое утверждение о декартовом произведении $A \times B$ верно?

- ( ) $A \times B = \{a, b \mid a \in A \text{ и } b \in B\}$
- ( ) $A \times B = B \times A$ для любых $A$ и $B$
- (x) $A \times B = \{(a, b) \mid a \in A \text{ и } b \in B\}$, и $|A \times B| = |A| \cdot |B|$ для конечных $A$ и $B$
- ( ) $A \times B = \{(a, b) \mid a \in B \text{ и } b \in A\}$

Пояснение:
**Ответ:** $A \times B = \{(a, b) \mid a \in A \text{ и } b \in B\}$, $|A \times B| = |A| \cdot |B|$.

Элементы декартова произведения — упорядоченные пары: первая координата из $A$, вторая из $B$. Каждый из $|A|$ элементов стоит в паре с каждым из $|B|$ элементов.

**Почему не подходят остальные**

- В общем случае $A \times B \ne B \times A$: $(1, a) \ne (a, 1)$.
- Запись $\{a, b \mid \ldots\}$ — это не пары.
- В последнем варианте первая координата взята из $B$, а вторая из $A$: это $B \times A$.


## 8

Какое утверждение о разности $A \setminus B$ верно?

- ( ) $A \setminus B = B \setminus A$, операция коммутативна
- (x) $A \setminus B = \{x \mid x \in A \text{ и } x \notin B\}$, и $A \setminus B \ne B \setminus A$ в общем случае
- ( ) $A \setminus B = \{x \mid x \in A \text{ или } x \notin B\}$
- ( ) $A \setminus B = A \cap B$

Пояснение:
**Ответ:** $A \setminus B = \{x \mid x \in A \text{ и } x \notin B\}$, операция не коммутативна.

Разность — элементы $A$, которых нет в $B$. Пример некоммутативности: $\{1, 2\} \setminus \{2\} = \{1\}$, а $\{2\} \setminus \{1, 2\} = \varnothing$.

«$x \in A$ или $x \notin B$» задаёт другое множество. $A \cap B$ — общие элементы.


## 9

«________ — это совокупность объектов произвольной природы, которые рассматриваются как единое целое». Какое слово пропущено?

- ( ) Булеан
- ( ) Подмножество
- ( ) Кортеж
- (x) Множество

Пояснение:
**Ответ:** множество.

Это определение множества из лекции.

- Подмножество — часть данного множества.
- Булеан — множество всех подмножеств.
- Кортеж — упорядоченный набор.


## 10

«________ — это множество всех подмножеств множества $A$». Какое слово пропущено?

- ( ) Разность
- ( ) Универсум
- ( ) Дополнение
- (x) Булеан

Пояснение:
**Ответ:** булеан.

$P(A)$ — булеан, множество всех подмножеств $A$. Универсум — множество, в котором рассматриваются все остальные. Дополнение и разность — операции над множествами.


## 11

Верно ли записано определение равенства множеств на кванторах?

$$\forall x: x \in A \Leftrightarrow x \in B$$

- ( ) Нет, должно быть $\forall x: x \in A \cup B$
- (x) Да, это верная запись
- ( ) Нет, должно быть $\exists x: x \in A \Leftrightarrow x \in B$
- ( ) Нет, должно быть $\forall x: x \in A \land x \in B$

Пояснение:
**Ответ:** да, запись верная.

$A = B$ означает, что любой $x$ лежит в $A$ тогда и только тогда, когда он лежит в $B$.

**Почему не подходят остальные**

- С $\land$ получилось бы «каждый $x$ лежит и в $A$, и в $B$», а это неверно.
- С $\exists$ достаточно одного совпадающего элемента, этого мало.
- $\forall x: x \in A \cup B$ говорит только о том, что $A \cup B$ — это всё, и ничего о равенстве.


## 12

Известно, что $A = B$. Даны утверждения.

1. $A \subseteq B$
2. $B \subseteq A$

- ( ) Только 1
- (x) Оба
- ( ) Только 2
- ( ) Ни одного

Пояснение:
**Ответ:** оба.

Если $A = B$, то каждое из множеств содержится в другом: $A \subseteq B$ и $B \subseteq A$. Это и есть определение равенства из задания 2.


## 13

Даны утверждения для любых множеств $A$ и $B$.

1. $A \setminus B = B \setminus A$
2. $A \mathbin{\Delta} B = B \mathbin{\Delta} A$

- (x) Только 2
- ( ) Ни одного
- ( ) Только 1
- ( ) Оба

Пояснение:
**Ответ:** только 2.

- Симметрическая разность коммутативна: $A \mathbin{\Delta} B = (A \setminus B) \cup (B \setminus A)$, и эта запись не меняется при перестановке $A$ и $B$.
- Разность не коммутативна: при $A = \{1\}$, $B = \varnothing$ получаем $A \setminus B = \{1\}$, $B \setminus A = \varnothing$.


## 14

На диаграмме Эйлера–Венна закрашена некоторая область. Какое выражение соответствует этой области?

![Два круга A и B в прямоугольнике U, закрашена часть круга B вне круга A](q14.svg)

- (x) $B \setminus A$
- ( ) $A \setminus B$
- ( ) $A \cap B$
- ( ) $A \cup B$

Пояснение:
**Ответ:** $B \setminus A$.

Закрашена часть круга $B$, которая не лежит в $A$.

- $A \setminus B$ — часть $A$ вне $B$, «полумесяц» с другой стороны.
- $A \cap B$ — только общая «линза».
- $A \cup B$ — оба круга целиком.


## 15

На диаграмме Эйлера–Венна закрашена некоторая область. Какое выражение соответствует этой области?

![Два круга A и B в прямоугольнике U, закрашены оба круга без общей части](q15.svg)

- ( ) $B \setminus A$
- ( ) $A \cap B$
- ( ) $A \setminus B$
- (x) $A \mathbin{\Delta} B$

Пояснение:
**Ответ:** $A \mathbin{\Delta} B$.

Закрашены оба круга без общей части, то есть $(A \setminus B) \cup (B \setminus A) = A \mathbin{\Delta} B$.

- $A \setminus B$ и $B \setminus A$ — только один из «полумесяцев».
- $A \cap B$ — как раз незакрашенная «линза».


## 16

На диаграмме Эйлера–Венна закрашена некоторая область. Какое выражение соответствует этой области?

![Три круга A, B, C в прямоугольнике U, закрашена часть общей области A и B вне круга C](q16.svg)

- (x) $(A \cap B) \setminus C$
- ( ) $(A \cap B) \cap C$
- ( ) $(A \cup B) \setminus C$
- ( ) $(A \cap B) \cup C$

Пояснение:
**Ответ:** $(A \cap B) \setminus C$.

Закрашена общая часть $A$ и $B$ без той её части, что лежит в $C$.

- $(A \cap B) \cap C$ — центр, где пересекаются все три круга.
- $(A \cup B) \setminus C$ — всё, что в $A$ или $B$, но вне $C$.
- $(A \cap B) \cup C$ — весь круг $C$ вместе с линзой $A \cap B$.


# Блок 2. Краткий ответ

## 17

$A = \{1, 2\}$. $P(A) = ?$

Формат: множество в фигурных скобках, его элементы тоже в фигурных скобках, пустое множество: {}. Например: {{}, {5}}
Ответ: {{}, {1}, {2}, {1, 2}}

Пояснение:
**Ответ:** $P(A) = \{\varnothing, \{1\}, \{2\}, \{1, 2\}\}$.

Булеан — все подмножества $A$. У $A = \{1, 2\}$ их четыре: пустое, $\{1\}$, $\{2\}$ и $\{1, 2\}$.

Проверка: $|P(A)| = 2^{|A|} = 2^2 = 4$. Частая ошибка — забыть пустое множество или само $A$.


## 18

$A = \{1, 2, 3, 4\}$, $B = \{3, 4, 5, 6\}$. $A \cap B = ?$

Формат: множество в фигурных скобках, элементы через запятую.
Ответ: {3, 4}

Пояснение:
**Ответ:** $\{3, 4\}$.

Пересечение — элементы, которые есть в обоих множествах: 3 и 4.


## 19

$A = \{a, \{b, c\}, d, \{a, \{b, \{c\}, d\}, e\}, e\}$. $|A| = ?$

Формат: число.
Ответ: 5

Пояснение:
**Ответ:** 5.

Считаем только элементы верхнего уровня:

1. $a$
2. $\{b, c\}$
3. $d$
4. $\{a, \{b, \{c\}, d\}, e\}$
5. $e$

Вложенное множество — один элемент, сколько бы внутри него ни было.


## 20

$X = \{1, \{2, 3\}\}$, $Y = \{a, b, c\}$. $|X \times Y| = ?$

Формат: число.
Ответ: 6

Пояснение:
**Ответ:** 6.

$|X| = 2$: элементы $X$ — это 1 и $\{2, 3\}$. $|Y| = 3$. Значит, $|X \times Y| = 2 \cdot 3 = 6$.

Частая ошибка — считать $\{2, 3\}$ за два элемента.


## 21

$A = \{1, 2, 3, 4, 5\}$, $B = \{2, 4, 5, 6, 7\}$. $A \setminus B = ?$

Формат: множество в фигурных скобках, элементы через запятую.
Ответ: {1, 3}

Пояснение:
**Ответ:** $\{1, 3\}$.

Из $A$ убираем всё, что есть в $B$, то есть 2, 4 и 5. Остаются 1 и 3.


## 22

Сколько подмножеств у множества из 3 элементов?

Формат: число.
Ответ: 8

Пояснение:
**Ответ:** 8.

У множества из $n$ элементов $2^n$ подмножеств, считая пустое и само множество: $2^3 = 8$.


## 23

$A = \{1, 2, 3, 4, 5\}$, $B = \{3, 4, 5, 6, 7\}$. $A \mathbin{\Delta} B = ?$

Формат: множество в фигурных скобках, элементы через запятую.
Ответ: {1, 2, 6, 7}

Пояснение:
**Ответ:** $\{1, 2, 6, 7\}$.

$A \mathbin{\Delta} B$ — элементы, которые лежат ровно в одном из множеств.

- Только в $A$: 1 и 2.
- Только в $B$: 6 и 7.
- Общие 3, 4, 5 не входят.


## 24

$|P(A)| = 32$. $|A| = ?$

Формат: число.
Ответ: 5

Пояснение:
**Ответ:** 5.

$|P(A)| = 2^{|A|} = 32 = 2^5$, значит, $|A| = 5$.


## 25

Квантор единственности записывается как $\exists!$: «существует единственный». Символ единственности — восклицательный знак.


## 26

**Ответ:** 6.

$|A \times B| = |A| \cdot |B| = 2 \cdot 3 = 6$.


## 27

$|A \times B \times C| = 2 \cdot 2 \cdot 1 = 4$. Элементы — тройки: $(1, x, a)$, $(1, y, a)$, $(2, x, a)$, $(2, y, a)$.

## 29

$R = \{(1, a), (2, b)\}$. Является ли $R$ бинарным отношением между $A = \{1, 2\}$ и $B = \{a, b\}$?

Формат: да или нет.
Ответ: да

Пояснение:
**Ответ:** да.

Бинарное отношение между $A$ и $B$ — любое подмножество $A \times B$. Обе пары, $(1, a)$ и $(2, b)$, лежат в $A \times B$, значит, $R \subseteq A \times B$ и $R$ — отношение.


## 30

$A = \{1, 2, 3\}$, $B = \{3, 4, 5\}$, $C = \{2, 3\}$. $(A \setminus B) \cap C = ?$

Формат: множество в фигурных скобках, элементы через запятую.
Ответ: {2}

Пояснение:
**Ответ:** $\{2\}$.

1. $A \setminus B = \{1, 2\}$: 3 есть в $B$.
2. $\{1, 2\} \cap \{2, 3\} = \{2\}$.


## 31

$U = \{1, 2, 3, 4, 5, 6\}$, $A = \{1, 3, 5\}$. $|\overline{A}| = ?$

Формат: число.
Ответ: 3

Пояснение:
**Ответ:** 3.

$\overline{A} = U \setminus A = \{2, 4, 6\}$, поэтому $|\overline{A}| = 3$. Другой способ: $|U| - |A| = 6 - 3 = 3$.


# Блок 3. Несколько верных вариантов

## 32

Какие множества — подмножества $M = \{1, 2, 3, 4\}$?

- [x] $\varnothing$
- [ ] $\{1, 2, 5\}$
- [x] $\{1, 2, 3\}$
- [ ] $\{1, 2, \{3, 4\}\}$

Пояснение:
**Ответ:** $\varnothing$ и $\{1, 2, 3\}$.

- $\{1, 2, 3\}$: все его элементы есть в $M$.
- $\varnothing$ — подмножество любого множества.
- $\{1, 2, 5\}$ — нет: $5 \notin M$.
- $\{1, 2, \{3, 4\}\}$ — нет: $\{3, 4\}$ как элемент в $M$ не входит, там есть только 3 и 4 по отдельности.


## 33

$A = \{1, 2, 3, 4\}$, $B = \{2, 4, 5\}$. Какие числа — элементы $A \setminus B$?

- [ ] 2
- [x] 3
- [ ] 5
- [ ] 4
- [x] 1

Пояснение:
**Ответ:** 1 и 3.

$A \setminus B$ — элементы $A$, которых нет в $B$. 2 и 4 лежат в $B$, а 5 вообще не принадлежит $A$.


## 34

Какие равенства верны для любых множеств $A$, $B$?

- [ ] $A \cap B = B \cup A$
- [x] $A \cap B = B \cap A$
- [ ] $A \cup B = B \cap A$
- [x] $A \cup B = B \cup A$

Пояснение:
**Ответ:** $A \cap B = B \cap A$ и $A \cup B = B \cup A$.

Пересечение и объединение коммутативны. Два других равенства неверны: при $A = \{1\}$, $B = \{2\}$ объединение равно $\{1, 2\}$, а пересечение $\varnothing$.


## 35

Какие равенства верны для любого множества $A$?

- [x] $A \cup \varnothing = A$
- [ ] $A \cup \varnothing = \varnothing$
- [ ] $A \cap \varnothing = A$
- [x] $A \cap \varnothing = \varnothing$

Пояснение:
**Ответ:** $A \cup \varnothing = A$ и $A \cap \varnothing = \varnothing$.

- С пустым множеством у $A$ нет общих элементов, поэтому $A \cap \varnothing = \varnothing$.
- Объединение ничего не добавляет к $A$, поэтому $A \cup \varnothing = A$.

Два других равенства верны только при $A = \varnothing$.


## 36

Какие утверждения верны для любых множеств $A$ и $B$?

- [ ] $A \cap B = A \cup B$
- [ ] $A \subseteq B$
- [ ] $A \setminus B = B \setminus A$
- [x] $A \mathbin{\Delta} B = B \mathbin{\Delta} A$

Пояснение:
**Ответ:** только $A \mathbin{\Delta} B = B \mathbin{\Delta} A$.

Симметрическая разность коммутативна. Остальное неверно:

- $A \subseteq B$ не выполняется при $A = \{1\}$, $B = \varnothing$;
- $A \cap B = A \cup B$ выполняется только при $A = B$;
- разность не коммутативна.


## 37

Какие из равенств — законы де Моргана?

- [x] $\overline{A \cup B} = \overline{A} \cap \overline{B}$
- [x] $\overline{A \cap B} = \overline{A} \cup \overline{B}$
- [ ] $\overline{A \cup B} = \overline{A} \cup \overline{B}$
- [ ] $\overline{A \cap B} = \overline{A} \cap \overline{B}$

Пояснение:
**Ответ:** первые два.

Законы де Моргана: дополнение объединения — пересечение дополнений, дополнение пересечения — объединение дополнений. В неверных вариантах знак операции не поменялся на противоположный.


## 38

Какие равенства верны для любых $A$, $B$?

- [x] $A \cap (A \cup B) = A$
- [x] $A \cup (A \cap B) = A$
- [ ] $A \cap (A \cup B) = B$
- [ ] $A \cup (A \cap B) = B$

Пояснение:
**Ответ:** первые два, это законы поглощения.

- $A \cap B \subseteq A$, поэтому объединение с $A$ даёт $A$.
- $A \subseteq A \cup B$, поэтому пересечение с $A$ даёт $A$.

С $B$ в правой части равенства неверны: при $A = \{1\}$, $B = \varnothing$ получаем $\{1\} \ne \varnothing$.


## 39

Что верно про мощность конечных множеств?

- [x] $|A \cup B| = |A| + |B| - |A \cap B|$
- [x] $|A \setminus B| \le |A|$
- [x] $|A \cap B| \le |A|$
- [x] $|P(A)| = 2^{|A|}$

Пояснение:
**Ответ:** все четыре.

- Формула включений-исключений: при сложении $|A|$ и $|B|$ общие элементы посчитаны дважды, поэтому вычитаем $|A \cap B|$.
- $A \setminus B$ и $A \cap B$ — подмножества $A$, поэтому их мощность не больше $|A|$.
- $|P(A)| = 2^{|A|}$: каждый элемент либо входит в подмножество, либо нет.


## 40

Какие утверждения верны для любых множеств $A$, $B$?

- [ ] $A \setminus B = B \setminus A$
- [x] Нет правильного ответа
- [ ] $A \subseteq B$
- [ ] $A \cap B = A \cup B$

Пояснение:
**Ответ:** нет правильного ответа.

Ни одно утверждение не верно для любых $A$ и $B$:

- $A \subseteq B$ и $A \setminus B = B \setminus A$ ломаются при $A = \{1\}$, $B = \varnothing$;
- $A \cap B = A \cup B$ выполняется только при $A = B$.


## 41

Известно, что $A \subseteq B$. Даны утверждения.

1. $A \cap B = A$
2. $A \cup B = B$

- (x) Оба
- ( ) Только 1
- ( ) Только 2
- ( ) Ни одного

Пояснение:
**Ответ:** оба.

Если $A \subseteq B$, то все элементы $A$ лежат в $B$.

- Общая часть — это само $A$: $A \cap B = A$.
- Объединение ничего не добавляет к $B$: $A \cup B = B$.


## 42

На диаграмме Эйлера–Венна закрашена некоторая область. Какие выражения ей соответствуют?

![Три круга A, B, C в прямоугольнике U, закрашены три лепестка попарных пересечений и центр](q42.svg)

- [ ] $A \cup B \cup C$
- [x] $(A \cap B) \cup (B \cap C) \cup (A \cap C)$
- [ ] $A \mathbin{\Delta} B \mathbin{\Delta} C$
- [ ] $A \cap B \cap C$

Пояснение:
**Ответ:** только $(A \cap B) \cup (B \cap C) \cup (A \cap C)$.

Закрашено всё, что лежит хотя бы в двух кругах: три «лепестка» и центр.

- $A \cup B \cup C$ — все три круга целиком, включая внешние части.
- $A \cap B \cap C$ — только центр.
- $A \mathbin{\Delta} B \mathbin{\Delta} C$ — элементы ровно из одного или сразу из всех трёх множеств: внешние части и центр, а лепестки не закрашены.


## 43

На диаграмме Эйлера–Венна закрашена некоторая область. Какие выражения ей соответствуют?

![Три круга A, B, C в прямоугольнике U, закрашены три внешние части и центр, лепестки не закрашены](q43.svg)

- [ ] $(A \cup B \cup C) \setminus (A \cap B \cap C)$
- [ ] $A \cup B \cup C$
- [x] $A \mathbin{\Delta} B \mathbin{\Delta} C$
- [ ] $(A \cap B) \cup (B \cap C) \cup (A \cap C)$

Пояснение:
**Ответ:** только $A \mathbin{\Delta} B \mathbin{\Delta} C$.

$A \mathbin{\Delta} B \mathbin{\Delta} C$ — элементы, которые лежат ровно в одном или сразу во всех трёх множествах: три внешние части и центр. «Лепестки», где элемент лежит ровно в двух множествах, не закрашены.

- $(A \cup B \cup C) \setminus (A \cap B \cap C)$ — все круги без центра: здесь наоборот, лепестки закрашены, а центра нет.
- $A \cup B \cup C$ — все три круга целиком.
- $(A \cap B) \cup (B \cap C) \cup (A \cap C)$ — лепестки и центр.


## 44

Какие свойства верны для любых множеств $A$, $B$, $C$?

- [x] $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$
- [x] $A \mathbin{\Delta} B = (A \setminus B) \cup (B \setminus A)$
- [x] $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$
- [x] $\overline{A \cap B} = \overline{A} \cup \overline{B}$

Пояснение:
**Ответ:** все четыре.

- Первое и третье — законы дистрибутивности.
- Второе — определение симметрической разности.
- Четвёртое — закон де Моргана.


## 45

Какие утверждения о мощности верны для конечных множеств?

- [x] $|P(A)| = 2^{|A|}$
- [x] $|A \times B| = |A| \cdot |B|$
- [x] $|A \cup B| = |A| + |B| - |A \cap B|$
- [x] $|A \setminus B| \le |A|$

Пояснение:
**Ответ:** все четыре.

- $|A \times B| = |A| \cdot |B|$: каждый элемент $A$ в паре с каждым элементом $B$.
- $|A \setminus B| \le |A|$, потому что $A \setminus B \subseteq A$.
- $|P(A)| = 2^{|A|}$: каждый элемент либо входит в подмножество, либо нет.
- $|A \cup B| = |A| + |B| - |A \cap B|$: общие элементы посчитаны дважды.


## 46

На диаграмме $A \subseteq B \subseteq C$, закрашена некоторая область. Какие выражения ей соответствуют?

![Три вложенных круга: A внутри B, B внутри C. Закрашены кольцо между B и C и круг A](q46.svg)

- [ ] $C \setminus B$
- [ ] $(C \setminus B) \cup (B \setminus A)$
- [ ] $A \setminus C$
- [x] $(C \setminus B) \cup A$

Пояснение:
**Ответ:** только $(C \setminus B) \cup A$.

Закрашены внешнее кольцо между $C$ и $B$ и внутренний круг $A$.

- $C \setminus B$ — только кольцо, без $A$.
- $(C \setminus B) \cup (B \setminus A)$ — всё $C$, кроме $A$, то есть $C \setminus A$.
- $A \setminus C$ пусто, потому что $A \subseteq C$.


## 47

Какая из диаграмм соответствует выражению $A \mathbin{\Delta} (B \cup C)$?

- (x) ![А](q47_А.svg)
- ( ) ![Б](q47_Б.svg)
- ( ) ![В](q47_В.svg)
- ( ) ![Г](q47_Г.svg)

Пояснение:
**Ответ:** А.

$A \mathbin{\Delta} (B \cup C)$ — элементы, которые лежат ровно в одном из множеств: в $A$ или в $B \cup C$.

- Закрашены часть $A$ вне $B$ и $C$ и все части $B$ и $C$ вне $A$.
- Не закрашено всё, где $A$ пересекается с $B$ или $C$, включая центр.

**Почему не подходят остальные**

- **Б:** закрашены лепестки, центра нет. Это $(A \cup B \cup C) \setminus (A \cap B \cap C)$.
- **В:** закрашены внешние части и центр, лепестков нет. Это $A \mathbin{\Delta} B \mathbin{\Delta} C$.
- **Г:** закрашено всё $B \cup C$ вне $A$, а часть $A$ вне $B$ и $C$ не закрашена. Это $(B \cup C) \setminus A$.
