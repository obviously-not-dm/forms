# Блок 1. Один верный вариант

## 1

В каком базисе строится полином Жегалкина?

- ( ) $\{\land, \lor, \neg\}$
- ( ) $\{\mid\}$ (штрих Шеффера)
- (x) $\{\oplus, \land, 1\}$ (сложение по модулю 2, конъюнкция и константа 1)
- ( ) $\{\lor, \oplus\}$

Пояснение:
**Ответ:** $\{\oplus, \land, 1\}$.

Алгебра Жегалкина — это кольцо многочленов над полем $\mathbb{F}_2 = \mathrm{GF}(2)$, в котором операциями служат сложение по модулю 2 ($\oplus$) и логическое умножение ($\land$), а также нейтральные элементы 0 и 1.


## 2

Как выражается операция логического отрицания $\overline{x}$ в алгебре Жегалкина?

- ( ) $x \oplus 0$
- (x) $x \oplus 1$
- ( ) $x \land 1$
- ( ) $x \oplus x$

Пояснение:
**Ответ:** $x \oplus 1$.

Проверим для обоих значений:
- при $x = 0$: $0 \oplus 1 = 1 = \overline{0}$;
- при $x = 1$: $1 \oplus 1 = 0 = \overline{1}$.


## 3

Каков полином Жегалкина для операции дизъюнкции $x \lor y$?

- ( ) $x \oplus y$
- ( ) $x \oplus y \oplus 1$
- (x) $x \oplus y \oplus xy$
- ( ) $xy \oplus 1$

Пояснение:
**Ответ:** $x \oplus y \oplus xy$.

По определению: $x \lor y = \overline{\overline{x} \land \overline{y}} = (x \oplus 1)(y \oplus 1) \oplus 1 = (xy \oplus x \oplus y \oplus 1) \oplus 1 = x \oplus y \oplus xy$.


## 4

Что утверждает фундаментальная теорема Жегалкина?

- ( ) Любая булева функция линейна
- (x) Всякая булева функция единственным образом представляется в виде полинома Жегалкина
- ( ) Полином Жегалкина не может содержать более 3 слагаемых
- ( ) Полином Жегалкина существует только для самодвойственных функций

Пояснение:
**Ответ:** Всякая булева функция единственным образом представляется в виде полинома Жегалкина.

Число различных полиномов Жегалкина от $n$ переменных равно числу подмножеств конъюнкций, то есть $2^{2^n}$. Так как общее число булевых функций также равно $2^{2^n}$, отображение между ними биективно: каждая функция имеет единственный полином Жегалкина.


## 5

Чему равен свободный член $c_0$ полинома Жегалкина функции $f(x_1, \dots, x_n)$?

- ( ) $f(1, 1, \dots, 1)$
- (x) $f(0, 0, \dots, 0)$
- ( ) 1 всегда
- ( ) 0 всегда

Пояснение:
**Ответ:** $f(0, 0, \dots, 0)$.

При подстановке нулевого набора аргументов ($x_1 = 0, \dots, x_n = 0$) все конъюнкции, содержащие хотя бы одну переменную, обращаются в ноль. Остается только свободный член: $P(0, \dots, 0) = c_0$, следовательно $c_0 = f(0, \dots, 0)$.


## 6

Какая булева функция называется линейной?

- ( ) Функция, график которой является прямой линией
- (x) Функция, полином Жегалкина которой не содержит произведений двух и более переменных (степень полинома $\le 1$)
- ( ) Функция, удовлетворяющая $f(x \lor y) = f(x) \lor f(y)$
- ( ) Тождественная константа 0

Пояснение:
**Ответ:** Функция, полином Жегалкина которой имеет степень не выше 1.

Линейная функция имеет вид $P(x_1, \dots, x_n) = a_0 \oplus a_1 x_1 \oplus \dots \oplus a_n x_n$, где все $a_i \in \{0, 1\}$. В ней отсутствуют нелинейные члены (произведения $x_i x_j$).


## 7

Какова степень полинома Жегалкина для функции конъюнкции трех переменных $f(x, y, z) = x \land y \land z$?

- ( ) 1
- ( ) 2
- (x) 3
- ( ) 0

Пояснение:
**Ответ:** 3.

Полином Жегалкина конъюнкции равен самому произведению: $P(x, y, z) = xyz$. Единственный моном содержит 3 переменные, поэтому степень полинома равна 3.


## 8

В методе треугольника Паскаля (преобразования Мёбиуса) для построения полинома Жегалкина каждый элемент следующего столбца вычисляется как:

- ( ) Произведение двух соседних элементов
- (x) Сумма по модулю 2 двух соседних элементов предыдущего столбца
- ( ) Логическое ИЛИ двух элементов
- ( ) Разность элементов

Пояснение:
**Ответ:** Сумма по модулю 2 двух соседних элементов предыдущего столбца.

Формула шага треугольника: $T[i, j] = T[i, j-1] \oplus T[i+1, j-1]$. Верхняя строка получившегося треугольника дает вектор коэффициентов полинома Жегалкина.


## 9

Какие логические операции формируют выходы полусумматора (Half Adder) для двух входных бит $A$ и $B$?

- ( ) Сумма $S = A \land B$, перенос $C = A \lor B$
- (x) Сумма $S = A \oplus B$, перенос $C = A \land B$
- ( ) Сумма $S = A \lor B$, перенос $C = A \oplus B$
- ( ) Сумма $S = \overline{A \oplus B}$, перенос $C = A \land B$

Пояснение:
**Ответ:** $S = A \oplus B$ и $C = A \land B$.

При сложении двух бит: $0+0=00_2$, $0+1=01_2$, $1+0=01_2$, $1+1=10_2$. Младший бит суммы $S$ реализуется операцией XOR ($A \oplus B$), а бит переноса в старший разряд $C$ (Carry) равен 1 только при $1+1$, то есть реализуется конъюнкцией $A \land B$.


## 10

Каково булево выражение для выхода суммы $S$ полного одноразрядного сумматора (Full Adder) с тремя входами $A, B, C_{in}$?

- ( ) $S = A \lor B \lor C_{in}$
- ( ) $S = AB \lor BC_{in} \lor AC_{in}$
- (x) $S = A \oplus B \oplus C_{in}$
- ( ) $S = A \land B \land C_{in}$

Пояснение:
**Ответ:** $S = A \oplus B \oplus C_{in}$.

Бит суммы равен 1, если нечетное число слагаемых равно 1 (1 или 3 единицы). Это в точности задается трехместной операцией сложения по модулю 2: $S = A \oplus B \oplus C_{in}$.


# Блок 2. Краткий ответ

## 11

Упростите в алгебре Жегалкина выражение $x \oplus x \oplus x \oplus 1$. При каком значении $x$ оно равно 1: при 0 или при 1? В ответе укажите результат упрощения выражения при $x = 0$.

Ответ: 1
Формат: целое число

Пояснение:
**Ответ:** 1.

Так как $x \oplus x = 0$, получаем $(x \oplus x) \oplus x \oplus 1 = 0 \oplus x \oplus 1 = x \oplus 1 = \overline{x}$.
При $x = 0$: $0 \oplus 1 = 1$.


## 12

Найдите свободный член $c_0$ полинома Жегалкина функции эквивалентности $f(x, y) = x \sim y$.

Ответ: 1
Формат: целое число

Пояснение:
**Ответ:** 1.

Свободный член равен значению функции на нулевом наборе: $c_0 = f(0, 0) = (0 \sim 0) = 1$.
Действительно, полином эквивалентности равен $x \oplus y \oplus 1$.


## 13

Сколько линейных булевых функций существует от $n = 3$ переменных?

Ответ: 16
Формат: целое число

Пояснение:
**Ответ:** 16.

Линейный полином от $n$ переменных имеет вид $c_0 \oplus c_1 x_1 \oplus \dots \oplus c_n x_n$.
Число коэффициентов равно $n + 1$. Каждый коэффициент может принимать 2 значения ($0$ или $1$).
Всего линейных функций: $2^{n+1} = 2^{3+1} = 2^4 = 16$.


## 14

Сколько слагаемых (мономов, включая возможную константу 1) содержит полином Жегалкина для функции импликации $x \implies y$?

Ответ: 3
Формат: целое число

Пояснение:
**Ответ:** 3.

Полином импликации: $x \implies y = xy \oplus x \oplus 1$. Он содержит 3 слагаемых ($xy$, $x$, $1$).


## 15

Вычислите значение полинома Жегалкина $P(x, y, z) = xy \oplus z \oplus 1$ на наборе $(x=1, y=1, z=1)$.

Ответ: 1
Формат: целое число

Пояснение:
**Ответ:** 1.

Подставляем: $P(1, 1, 1) = (1 \cdot 1) \oplus 1 \oplus 1 = 1 \oplus 1 \oplus 1 = 0 \oplus 1 = 1$.


## 16

Какова максимальная степень монома в полиноме Жегалкина от $n = 4$ переменных?

Ответ: 4
Формат: целое число

Пояснение:
**Ответ:** 4.

Максимальный моном содержит произведение всех переменных без повторов: $x_1 x_2 x_3 x_4$. Его степень равна числу переменных $n = 4$.


# Блок 3. Несколько верных вариантов

## 17

Какие из перечисленных булевых функций являются линейными?

- [x] $f(x, y) = x \oplus y$
- [x] $f(x, y) = x \oplus y \oplus 1$ (эквивалентность)
- [ ] $f(x, y) = x \lor y$
- [ ] $f(x, y) = x \land y$
- [x] $f(x, y) = x \oplus 1$ (инверсия $\overline{x}$)

Пояснение:
**Ответ:** $x \oplus y$; $x \oplus y \oplus 1$; $x \oplus 1$.

Полиномы указанных функций содержат только слагаемые степени $\le 1$. В полиномах дизъюнкции ($x \oplus y \oplus xy$) и конъюнкции ($xy$) присутствует нелинейный член $xy$ степени 2.


## 18

Какие свойства справедливы в алгебре Жегалкина над полем $\mathbb{F}_2$?

- [x] Нилпотентность сложения: $x \oplus x = 0$
- [x] Идемпотентность умножения: $x \cdot x = x$
- [x] Дистрибутивность умножения относительно сложения: $x(y \oplus z) = xy \oplus xz$
- [ ] Дистрибутивность сложения относительно умножения: $x \oplus yz = (x \oplus y)(x \oplus z)$
- [x] Каждый элемент поля является противоположным самому себе: $-x = x$

Пояснение:
**Ответ:** $x \oplus x = 0$; $x \cdot x = x$; $x(y \oplus z) = xy \oplus xz$; $-x = x$.

В отличие от классической булевой алгебры с дизъюнкцией и конъюнкцией, в кольце $\mathbb{F}_2$ сложение НЕ дистрибутивно относительно умножения (как и в обычной школьной арифметике).


## 19

Какие методы позволяют найти коэффициенты полинома Жегалкина?

- [x] Метод эквивалентных преобразований формулы
- [x] Метод треугольника Паскаля (преобразование Мёбиуса)
- [x] Метод решения системы линейных уравнений (неопределенных коэффициентов)
- [ ] Алгоритм Дейкстры
- [x] Разложение функции по формуле Шеннона с приведением по модулю 2

Пояснение:
**Ответ:** Эквивалентные преобразования; треугольник Паскаля; метод неопределенных коэффициентов; разложение Шеннона с приведением по mod 2.

Алгоритм Дейкстры предназначен для поиска кратчайших путей во взвешенных графах и не применяется для построения полиномов Жегалкина.


## 20

Какие утверждения о полном сумматоре (Full Adder) верны?

- [x] Полный сумматор имеет три двоичных входа ($A, B, C_{in}$)
- [x] Полный сумматор формирует два двоичных выхода: бит суммы $S$ и бит переноса $C_{out}$
- [x] Полный сумматор может быть построен из двух полусумматоров и одного логического элемента ИЛИ
- [ ] Выход суммы равен 1 тогда и только тогда, когда все три входа равны 1
- [x] Выход переноса $C_{out} = AB \lor BC_{in} \lor AC_{in}$ (функция большинства)

Пояснение:
**Ответ:** 3 входа; 2 выхода ($S$ и $C_{out}$); построение из 2 полусумматоров и OR; формула переноса большинства.

Выход суммы $S = A \oplus B \oplus C_{in}$ равен 1 не только при трех единицах, но и когда ровно одна из переменных равна 1 (например, $1+0+0 = 1$).


## 21

Дана функция $f(x, y) = xy \oplus x$. Какие утверждения о ней верны?

- [x] На нулевом наборе $(0, 0)$ функция равна 0
- [x] На наборе $(1, 0)$ функция равна 1
- [x] Функция равна операции коимпликации (запрета по $y$): $x \land \overline{y}$
- [ ] Функция является линейной
- [x] Степень полинома Жегалкина равна 2

Пояснение:
**Ответ:** $f(0,0) = 0$; $f(1,0) = 1$; равна $x \overline{y}$; степень полинома равна 2.

$xy \oplus x = x(y \oplus 1) = x \overline{y}$. Присутствует моном $xy$, поэтому функция нелинейна (степень 2).


## 22

Какие из следующих утверждений о числе слагаемых в полиноме Жегалкина верны?

- [x] Полином тождественного нуля $f \equiv 0$ не содержит ни одного слагаемого (равен 0)
- [x] Полином тождественной единицы $f \equiv 1$ состоит из единственного слагаемого 1
- [x] Максимальное число слагаемых в полиноме от $n$ переменных равно $2^n$
- [ ] Число слагаемых обязано быть нечетным
- [x] Если функция принимает значение 1 на нечетном числе наборов, то моном старшей степени $x_1 x_2 \dots x_n$ обязательно входит в полином

Пояснение:
**Ответ:** Нуль не содержит слагаемых; единица состоит из константы 1; максимум $2^n$ слагаемых; старший моном входит при нечетном весе функции.

Коэффициент при старшем мономе равен $c_{1\dots1} = \bigoplus_{\tilde{\alpha}} f(\tilde{\alpha})$. Эта сумма по модулю 2 равна 1 тогда и только тогда, когда число единиц в таблице истинности нечетно.
