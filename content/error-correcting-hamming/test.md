# Блок 1. Один верный вариант

## 1

Чему равно расстояние Хэмминга между двоичными векторами $x = (1, 0, 1, 1, 0)$ и $y = (1, 1, 1, 0, 0)$?

- ( ) 1
- (x) 2
- ( ) 3
- ( ) 4

Пояснение:
**Ответ:** 2.

Расстояние Хэмминга равно числу позиций, в которых векторы различаются. Сравниваем координаты:
1. $1 = 1$ (совпадают);
2. $0 \ne 1$ (различие);
3. $1 = 1$ (совпадают);
4. $1 \ne 0$ (различие);
5. $0 = 0$ (совпадают).
Всего 2 различия: $d(x, y) = 2$.


## 2

Каково минимальное кодовое расстояние $d_{\min}$, необходимое для гарантированного обнаружения до $e$ ошибок в кодовом слове?

- ( ) $d_{\min} \ge e$
- (x) $d_{\min} \ge e + 1$
- ( ) $d_{\min} \ge 2e + 1$
- ( ) $d_{\min} \ge 2e$

Пояснение:
**Ответ:** $d_{\min} \ge e + 1$.

Если в кодовом слове произошло от 1 до $e$ искажений, а минимальное расстояние между разрешенными словами не менее $e + 1$, то искаженный вектор не сможет совпасть ни с одним другим разрешенным кодовым словом и гарантированно будет распознан как ошибочный.


## 3

Каково условие на кодовое расстояние $d_{\min}$ для гарантированного исправления $t$ ошибок?

- ( ) $d_{\min} \ge t + 1$
- ( ) $d_{\min} \ge 2t$
- (x) $d_{\min} \ge 2t + 1$
- ( ) $d_{\min} \ge 3t$

Пояснение:
**Ответ:** $d_{\min} \ge 2t + 1$.

При $d_{\min} \ge 2t + 1$ сферы Хэмминга радиуса $t$ с центрами в разрешенных кодовых словах попарно не пересекаются. Любой вектор с не более чем $t$ ошибками находится строго ближе к исходному кодовому слову, чем к любому другому.


## 4

Каково минимальное кодовое расстояние классического кода Хэмминга $(7, 4)$?

- ( ) 1
- ( ) 2
- (x) 3
- ( ) 4

Пояснение:
**Ответ:** 3.

Код Хэмминга $(7, 4)$ имеет $d_{\min} = 3$. По формуле $d_{\min} \ge 2t + 1$ при $t = 1$ получаем $3 \ge 2(1) + 1$, что позволяет коду исправлять любую одиночную ошибку.


## 5

На каких позициях в кодовом слове Хэмминга размещаются проверочные (контрольные) биты?

- ( ) В самом начале (позиции 1, 2, 3)
- ( ) В самом конце (позиции 5, 6, 7)
- (x) На позициях, номера которых являются степенями двойки ($1, 2, 4, 8, \dots$)
- ( ) На нечетных позициях

Пояснение:
**Ответ:** На позициях — степенях двойки.

Контрольные биты размещаются на позициях $2^0 = 1, 2^1 = 2, 2^2 = 4, \dots$, так как в их двоичной записи присутствует ровно одна единица. Это позволяет битам синдрома независимо указывать разряды двоичной записи номера ошибочного бита.


## 6

Какое фундаментальное свойство связывает порождающую матрицу $G$ и проверочную матрицу $H$ линейного блокового кода?

- ( ) $G = H$
- ( ) $G + H = I$
- (x) $G \cdot H^T = \mathbf{0} \pmod 2$
- ( ) $\det(G) = \det(H)$

Пояснение:
**Ответ:** $G \cdot H^T = \mathbf{0} \pmod 2$.

Строки матрицы $G$ являются кодовыми словами. По определению проверочной матрицы, вектор $c$ является кодовым тогда и только тогда, когда $c H^T = \mathbf{0}$. Следовательно, для всех строк матрицы $G$ выполнено $G H^T = \mathbf{0}$.


## 7

От чего зависит вектор синдрома $S = y \cdot H^T$, вычисленный на приемной стороне для принятого вектора $y = c \oplus e$?

- ( ) Только от переданного сообщения $c$
- (x) Исключительно от вектора ошибки $e$
- ( ) От длины канала связи
- ( ) От начального состояния генератора случайных чисел

Пояснение:
**Ответ:** Исключительно от вектора ошибки $e$.

$S = y H^T = (c \oplus e) H^T = c H^T \oplus e H^T = \mathbf{0} \oplus e H^T = e H^T$. Синдром полностью автономен от информационных данных и зависит только от конфигурации возникших ошибок.


## 8

В коде Хэмминга $(7, 4)$ вектор синдрома оказался равен $S = (s_3, s_2, s_1) = (1, 1, 0)_2$. В каком бите кодового слова произошла ошибка?

- ( ) Ошибок нет
- ( ) В 3-м бите
- (x) В 6-м бите
- ( ) В 7-м бите

Пояснение:
**Ответ:** В 6-м бите.

В классическом коде Хэмминга двоичный код синдрома $(s_3 s_2 s_1)_2$ в точности равен номеру ошибочной позиции.
$(1, 1, 0)_2 = 1 \cdot 4 + 1 \cdot 2 + 0 \cdot 1 = 6$. Следовательно, искажен 6-й бит.


## 9

Что означает аббревиатура SECDED в контексте расширенного кода Хэмминга $(8, 4)$?

- ( ) Secure Encryption and Cryptographic Data Encoding Device
- (x) Single Error Correction, Double Error Detection (исправление одиночных ошибок, обнаружение двойных)
- ( ) Serial Error Control and Dynamic Error Decoding
- ( ) Synchronous Ethernet Communication Protocol

Пояснение:
**Ответ:** Single Error Correction, Double Error Detection.

Добавление 8-го общего бита четности увеличивает минимальное кодовое расстояние с 3 до 4. Это позволяет коду одновременно исправлять любую одиночную ошибку ($2 \cdot 1 + 1 \le 4$) и надежно обнаруживать двойные ошибки ($e = 2 \implies 2 + 1 \le 4$).


## 10

Что называется весом Хэмминга двоичного вектора?

- ( ) Его длина в битах
- (x) Количество единиц среди его координат
- ( ) Число нулей в векторе
- ( ) Десятичный эквивалент числа

Пояснение:
**Ответ:** Количество единиц среди его координат.

Вес Хэмминга $w(x)$ — это число ненулевых компонент вектора: $w(x) = |\{i \mid x_i = 1\}|$.


# Блок 2. Краткий ответ

## 11

Вычислите вес Хэмминга двоичного вектора $v = (1, 0, 1, 1, 0, 1, 0, 1)$.

Ответ: 5
Формат: целое число

Пояснение:
**Ответ:** 5.

Вектор содержит единицы на позициях 1, 3, 4, 6, 8. Всего 5 единиц, поэтому $w(v) = 5$.


## 12

Код имеет минимальное кодовое расстояние $d_{\min} = 5$. Какое максимальное число ошибок $t$ он способен гарантированно исправить?

Ответ: 2
Формат: целое число

Пояснение:
**Ответ:** 2.

По формуле исправления ошибок: $d_{\min} \ge 2t + 1 \implies 2t + 1 \le 5 \implies 2t \le 4 \implies t \le 2$.


## 13

Сколько проверочных (контрольных) бит $r$ содержится в блоке кода Хэмминга $(7, 4)$?

Ответ: 3
Формат: целое число

Пояснение:
**Ответ:** 3.

Параметры кода $(n, k)$: длина блока $n = 7$, число информационных бит $k = 4$. Число проверочных разрядов: $r = n - k = 7 - 4 = 3$.


## 14

Каково минимальное кодовое расстояние $d_{\min}$ расширенного кода Хэмминга $(8, 4)$ с общим битом четности?

Ответ: 4
Формат: целое число

Пояснение:
**Ответ:** 4.

Добавление общего бита четности к коду с нечетным расстоянием $d_{\min} = 3$ увеличивает минимальный вес кодовых слов до четного значения, то есть $d_{\min} = 4$.


## 15

Сколько кодовых слов содержит линейный блоковый код $(7, 4)$?

Ответ: 16
Формат: целое число

Пояснение:
**Ответ:** 16.

Код имеет $k = 4$ информационных разряда. Каждому из $2^k = 2^4 = 16$ информационных векторов соответствует ровно одно кодовое слово длины 7.


## 16

Код обнаруживает все ошибки кратности до $e = 3$ включительно. Каково минимально возможное кодовое расстояние $d_{\min}$ этого кода?

Ответ: 4
Формат: целое число

Пояснение:
**Ответ:** 4.

Условие обнаружения: $d_{\min} \ge e + 1$. При $e = 3$ получаем $d_{\min} \ge 3 + 1 = 4$.


# Блок 3. Несколько верных вариантов

## 17

Какие аксиомы метрического пространства выполняет расстояние Хэмминга $d(x, y)$?

- [x] Неотрицательность и невырожденность: $d(x, y) \ge 0$, причём $d(x, y) = 0 \iff x = y$
- [x] Симметричность: $d(x, y) = d(y, x)$
- [x] Неравенство треугольника: $d(x, z) \le d(x, y) + d(y, z)$
- [ ] Антисимметричность: $d(x, y) = -d(y, x)$
- [x] Инвариантность относительно сдвига: $d(x \oplus z, y \oplus z) = d(x, y)$

Пояснение:
**Ответ:** Неотрицательность; симметричность; неравенство треугольника; инвариантность к сдвигу.

Расстояние Хэмминга является строгой математической метрикой на векторном пространстве $\mathbb{F}_2^n$. Антисимметричность метрикам не свойственна.


## 18

Какие свойства характерны для совершенных (плотно упакованных) кодов?

- [x] Сферы радиуса $t$ вокруг кодовых слов покрывают все пространство $\mathbb{F}_2^n$ без пробелов и пересечений
- [x] В границе Хэмминга достигается точное равенство: $|C| \sum_{i=0}^t \binom{n}{i} = 2^n$
- [x] Любой принятый вектор лежит внутри сферы ровно одного кодового слова
- [ ] Совершенные коды существуют для любого произвольного набора параметров $n, k, t$
- [x] Код Хэмминга $(7, 4)$ является совершенным кодом

Пояснение:
**Ответ:** Сферы покрывают все пространство без зазоров; точное равенство в границе Хэмминга; каждый вектор в сфере одного слова; код Хэмминга (7,4) совершенный.

Совершенные коды — чрезвычайно редкие математические объекты (теорема Тиетявяйнена–ван Линта доказывает, что помимо кодов Хэмминга и кодов Голея нетривиальных совершенных кодов над полями Галуа не существует).


## 19

Какие утверждения о проверочной матрице $H$ линейного кода $(n, k)$ верны?

- [x] Размер матрицы $H$ равен $(n - k) \times n$
- [x] Вектор $c$ является кодовым словом тогда и только тогда, когда $c H^T = \mathbf{0}$
- [x] Столбцы матрицы $H$ для кода с $d_{\min} \ge 3$ попарно различны и ненулевые
- [ ] Матрица $H$ обязана быть квадратной
- [x] Для кода Хэмминга $(7, 4)$ столбцы матрицы $H$ представляют собой все ненулевые двоичные 3-битные векторы

Пояснение:
**Ответ:** Размер $(n-k) \times n$; условие $c H^T = 0$; столбцы попарно различны; столбцы кода Хэмминга — все ненулевые 3-битные векторы.

Число строк проверочной матрицы равно числу проверочных бит $r = n - k$. Поскольку $k > 0$, матрица не является квадратной.


## 20

В каких системах и устройствах широко применяются коды Хэмминга и SECDED?

- [x] В оперативной памяти с коррекцией ошибок (ECC RAM) серверов
- [x] В кэш-памяти процессоров первого, второго и третьего уровней (L1, L2, L3)
- [x] В микросхемах энергонезависимой флеш-памяти (NAND Flash)
- [ ] В аналоговых радиоприемниках прямого усиления
- [x] В контроллерах RAID-массивов и шинах передачи данных PCIe

Пояснение:
**Ответ:** ECC RAM; кэш-память процессоров; NAND Flash; RAID-контроллеры и PCIe.

Аппаратная простота вычисления синдрома на логических элементах XOR позволяет кодам Хэмминга работать на гигагерцовых частотах с минимальной задержкой.


## 21

Даны кодовые слова $c_1 = (0, 0, 0, 0, 0)$ и $c_2 = (1, 1, 1, 1, 1)$ кода с тройным повторением. Какие утверждения о нем верны?

- [x] Минимальное кодовое расстояние $d_{\min} = 5$
- [x] Код способен исправлять до 2 ошибок
- [x] Код способен обнаруживать до 4 ошибок
- [ ] Код исправляет до 3 ошибок
- [x] Декодирование осуществляется простым большинством голосов (мажоритарно)

Пояснение:
**Ответ:** $d_{\min} = 5$; исправление до 2 ошибок; обнаружение до 4 ошибок; мажоритарное декодирование.

$d(c_1, c_2) = 5$. Для исправления: $2t + 1 \le 5 \implies t = 2$. Для обнаружения: $e + 1 \le 5 \implies e = 4$.


## 22

Какие биты участвуют в формировании контрольного бита $p_1$ (позиция 1) в коде Хэмминга $(7, 4)$?

- [x] Позиция 1 ($p_1$)
- [x] Позиция 3 ($d_1$)
- [x] Позиция 5 ($d_2$)
- [x] Позиция 7 ($d_4$)
- [ ] Позиция 2 ($p_2$)

Пояснение:
**Ответ:** Позиции 1, 3, 5, 7.

Контрольный бит $p_1$ отвечает за разряды, в двоичной записи которых младший бит равен 1:
- $1 = 001_2$;
- $3 = 011_2$;
- $5 = 101_2$;
- $7 = 111_2$.
Позиция 2 имеет код $010_2$ (младший бит 0) и проверяется битом $p_2$.
