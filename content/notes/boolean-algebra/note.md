# Булева алгебра: функции, эквивалентности и нормальные формы

Конспект составлен на основе объединённых лекционных курсов дискретной математики **Пермякова А.С.** и **Страдиной М.В.**

---

## 1. Алгебра высказываний и понятие булевой функции

> [!NOTE]
> **Высказыванием (Proposition)** в математической логике называется повествовательное утверждение, о котором можно однозначно сказать, истинно оно ($\mathbf{1}$ или $\mathrm{True}$) или ложно ($\mathbf{0}$ или $\mathrm{False}$).

> [!NOTE]
> **Булевой (логической) функцией** от $n$ переменных называется всюду определенное отображение:
> $$f: \{0, 1\}^n \to \{0, 1\}$$
> Множество $\{0, 1\}^n$ называется $n$-мерным булевым кубом (булевым пространством $B^n$).

### Мощность пространства булевых функций

1. Число различных наборов аргументов (длина вектора значений / число строк в таблице истинности) равно мощности булевого куба:
   $$|B^n| = 2^n$$
2. Поскольку для каждого из $2^n$ наборов функция может принимать одно из двух значений ($0$ или $1$), общее число всевозможных булевых функций от $n$ переменных равно:
   $$N(n) = 2^{2^n}$$

| Число переменных $n$ | Число наборов $2^n$ | Число булевых функций $2^{2^n}$ |
| :---: | :---: | :---: |
| 0 | 1 | $2^1 = 2$ (константы 0 и 1) |
| 1 | 2 | $2^2 = 4$ ($0, x, \neg x, 1$) |
| 2 | 4 | $2^4 = 16$ |
| 3 | 8 | $2^8 = 256$ |
| 4 | 16 | $2^{16} = 65\,536$ |

## 2. Полная классификация 16 бинарных булевых функций ($n = 2$)

Каждая функция от двух переменных $(x, y)$ однозначно задаётся 4-битным вектором значений $(f(0,0), f(0,1), f(1,0), f(1,1))$:

| Номер $i$ | Вектор значений | Название операции | Обозначение | Формульное выражение |
| :---: | :---: | :--- | :---: | :--- |
| **0** | `0000` | Константа 0 (Тождественный ноль) | $0$ | $0$ |
| **1** | `0001` | Конъюнкция (Логическое И, AND) | $x \land y, \; x \cdot y$ | $x \land y$ |
| **2** | `0010` | Коимпликация (Запрет по $y$) | $x \not\implies y$ | $x \land \overline{y}$ |
| **3** | `0011` | Селектор первой переменной | $x$ | $x$ |
| **4** | `0100` | Обратная коимпликация (Запрет по $x$) | $y \not\implies x$ | $\overline{x} \land y$ |
| **5** | `0101` | Селектор второй переменной | $y$ | $y$ |
| **6** | `0110` | Сложение по модулю 2 (XOR) | $x \oplus y$ | $(x \land \overline{y}) \lor (\overline{x} \land y)$ |
| **7** | `0111` | Дизъюнкция (Логическое ИЛИ, OR) | $x \lor y, \; x + y$ | $x \lor y$ |
| **8** | `1000` | Стрелка Пирса (ИЛИ-НЕ, NOR) | $x \downarrow y$ | $\overline{x \lor y} = \overline{x} \land \overline{y}$ |
| **9** | `1001` | Эквивалентность (Равносильность, XNOR) | $x \sim y, \; x \equiv y$ | $(x \land y) \lor (\overline{x} \land \overline{y})$ |
| **10** | `1010` | Инверсия второй переменной | $\overline{y}$ | $\neg y$ |
| **11** | `1011` | Обратная импликация | $x \impliedby y$ | $x \lor \overline{y}$ |
| **12** | `1100` | Инверсия первой переменной | $\overline{x}$ | $\neg x$ |
| **13** | `1101` | Импликация (Следование) | $x \implies y$ | $\overline{x} \lor y$ |
| **14** | `1110` | Штрих Шеффера (И-НЕ, NAND) | $x \mid y$ | $\overline{x \land y} = \overline{x} \lor \overline{y}$ |
| **15** | `1111` | Константа 1 (Тождественная единица) | $1$ | $1$ |

## 3. Существенные и фиктивные переменные

В лекциях Пермякова А.С. и Страдиной М.В. детально разбирается вопрос зависимости функций от своих аргументов:

> [!NOTE]
> Переменная $x_i$ называется **существенной переменной** булевой функции $f(x_1, \dots, x_i, \dots, x_n)$, если существуют два таких набора аргументов, различающихся только значением этой переменной $x_i$, на которых значения функции различны:
> $$\exists \alpha_1, \dots, \alpha_{i-1}, \alpha_{i+1}, \dots, \alpha_n \in \{0, 1\}:$$
> $$f(\alpha_1, \dots, 0, \dots, \alpha_n) \ne f(\alpha_1, \dots, 1, \dots, \alpha_n)$$
> Если такого набора не существует (то есть при любых значениях остальных аргументов изменение $x_i$ не меняет результат), переменная $x_i$ называется **фиктивной (dummy / немой)**.

Две функции считаются **равными**, если они принимают одинаковые значения при удалении или добавлении любого числа фиктивных переменных.

## 4. Разложение Шеннона (Shannon Expansion)

Фундаментальная теорема Клода Шеннона (1938) позволяет разложить любую булеву функцию по одной или нескольким переменным.

> [!IMPORTANT]
> **Теорема о разложении Шеннона по переменной $x_i$:**
> Для любой булевой функции $f(x_1, \dots, x_n)$ справедливо тождество:
> $$f(x_1, \dots, x_n) = \left( \overline{x_i} \land f(x_1, \dots, 0, \dots, x_n) \right) \lor \left( x_i \land f(x_1, \dots, 1, \dots, x_n) \right)$$
> Двойственное разложение:
> $$f(x_1, \dots, x_n) = \left( x_i \lor f(x_1, \dots, 0, \dots, x_n) \right) \land \left( \overline{x_i} \lor f(x_1, \dots, 1, \dots, x_n) \right)$$

Разложение Шеннона лежит в основе синтеза логических схем, бинарных решающих диаграмм (BDD) и мультиплексорной логики (MUX).

## 5. Законы двойственности и двойственные функции

> [!NOTE]
> Функция $f^*(x_1, \dots, x_n)$, определяемая равенством:
> $$f^*(x_1, \dots, x_n) = \overline{f(\overline{x_1}, \overline{x_2}, \dots, \overline{x_n})}$$
> называется **двойственной** к функции $f$.

### Свойства двойственности:
1. **Инволютивность:** $(f^*)^* = f$.
2. **Таблица двойственной функции:** вектор значений двойственной функции получается реверсом вектора значений исходной функции с одновременным побитовым инвертированием:
   $$\vec{\alpha}^* = \overline{\mathrm{reverse}(\vec{\alpha})}$$
3. **Взаимно-двойственные пары базовых операций:**
   - $(0)^* = 1, \quad (1)^* = 0$
   - $(x \land y)^* = x \lor y, \quad (x \lor y)^* = x \land y$
   - $(x \oplus y)^* = x \sim y, \quad (x \sim y)^* = x \oplus y$
   - $(x \mid y)^* = x \downarrow y, \quad (x \downarrow y)^* = x \mid y$
   - $(\overline{x})^* = \overline{x}$

> [!IMPORTANT]
> **Принцип двойственности (Duality Principle):**
> Если верна формула $F(x_1, \dots, x_n) = G(x_1, \dots, x_n)$, то верно и равенство, полученное заменой всех операций на двойственные, а констант 0 и 1 — на 1 и 0 соответственно:
> $$F^*(x_1, \dots, x_n) = G^*(x_1, \dots, x_n)$$

## 6. Совершенные нормальные формы: СДНФ и СКНФ

Любая булева функция (отличная от тождественных констант) может быть однозначно представлена в виде совершенной нормальной формы.

### СДНФ (Совершенная дизъюнктивная нормальная форма)

> [!NOTE]
> - **Минтермом (конституентой единицы)** от $n$ переменных называется конъюнкция всех $n$ переменных, взятых с отрицанием или без него.
>   Для набора $\tilde{\alpha} = (\alpha_1, \dots, \alpha_n)$ минтерм задаётся формулой:
>   $$m_{\tilde{\alpha}}(x_1, \dots, x_n) = x_1^{\alpha_1} \land x_2^{\alpha_2} \land \dots \land x_n^{\alpha_n}$$
>   где $x^1 = x$, $x^0 = \overline{x}$.
> - Минтерм $m_{\tilde{\alpha}}$ обращается в $1$ **ровно на одном** наборе $\tilde{\alpha}$.

**СДНФ** функции $f$ — это дизъюнкция всех минтермов, соответствующих наборам, на которых $f(\tilde{\alpha}) = 1$:
$$f(x_1, \dots, x_n) = \bigvee_{\tilde{\alpha}: f(\tilde{\alpha}) = 1} \left( x_1^{\alpha_1} \land x_2^{\alpha_2} \land \dots \land x_n^{\alpha_n} \right)$$

---

### СКНФ (Совершенная конъюнктивная нормальная форма)

> [!NOTE]
> - **Макстермом (конституентой нуля)** от $n$ переменных называется дизъюнкция всех $n$ переменных, взятых с отрицанием или без него.
>   Для набора $\tilde{\beta} = (\beta_1, \dots, \beta_n)$ макстерм задаётся формулой:
>   $$M_{\tilde{\beta}}(x_1, \dots, x_n) = x_1^{\overline{\beta_1}} \lor x_2^{\overline{\beta_2}} \lor \dots \lor x_n^{\overline{\beta_n}}$$
>   где $x^{\overline{0}} = x$, $x^{\overline{1}} = \overline{x}$.
> - Макстерм $M_{\tilde{\beta}}$ обращается в $0$ **ровно на одном** наборе $\tilde{\beta}$.

**СКНФ** функции $f$ — это конъюнкция всех макстермов, соответствующих наборам, на которых $f(\tilde{\beta}) = 0$:
$$f(x_1, \dots, x_n) = \bigwedge_{\tilde{\beta}: f(\tilde{\beta}) = 0} \left( x_1^{\overline{\beta_1}} \lor x_2^{\overline{\beta_2}} \lor \dots \lor x_n^{\overline{\beta_n}} \right)$$

---

### Пример построения СДНФ и СКНФ

Построим СДНФ и СКНФ для функции голосования большинством (majority) $f(x, y, z)$:

| $x$ | $y$ | $z$ | $f(x,y,z)$ | Тип строки | Слагаемое СДНФ / Множитель СКНФ |
| :---: | :---: | :---: | :---: | :---: | :--- |
| 0 | 0 | 0 | **0** | Нулевая | Макстерм: $(x \lor y \lor z)$ |
| 0 | 0 | 1 | **0** | Нулевая | Макстерм: $(x \lor y \lor \overline{z})$ |
| 0 | 1 | 0 | **0** | Нулевая | Макстерм: $(x \lor \overline{y} \lor z)$ |
| 0 | 1 | 1 | **1** | Единичная | Минтерм: $\overline{x} y z$ |
| 1 | 0 | 0 | **0** | Нулевая | Макстерм: $(\overline{x} \lor y \lor z)$ |
| 1 | 0 | 1 | **1** | Единичная | Минтерм: $x \overline{y} z$ |
| 1 | 1 | 0 | **1** | Единичная | Минтерм: $x y \overline{z}$ |
| 1 | 1 | 1 | **1** | Единичная | Минтерм: $x y z$ |

- **СДНФ:**
  $$f(x, y, z) = (\overline{x} y z) \lor (x \overline{y} z) \lor (x y \overline{z}) \lor (x y z)$$
- **СКНФ:**
  $$f(x, y, z) = (x \lor y \lor z) \land (x \lor y \lor \overline{z}) \land (x \lor \overline{y} \lor z) \land (\overline{x} \lor y \lor z)$$

> [!IMPORTANT]
> **Теорема о существовании и единственности:**
> Для любой булевой функции, отличной от тождественного нуля ($f \not\equiv 0$), существует **единственная** (с точностью до перестановки слагаемых и сомножителей) СДНФ.
> Для любой функции, отличной от тождественной единицы ($f \not\equiv 1$), существует **единственная** СКНФ.
