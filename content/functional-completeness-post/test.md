# Блок 1. Один верный вариант

## 1

Сколько предполных классов существует во множестве всех булевых функций $P_2$ согласно теореме Эмиля Поста?

- ( ) 3
- ( ) 4
- (x) 5
- ( ) Бесконечно много

Пояснение:
**Ответ:** 5.

Теорема Поста (1941) утверждает, что существует ровно пять максимальных замкнутых (предполных) классов: $T_0$ (сохраняющие 0), $T_1$ (сохраняющие 1), $S$ (самодвойственные), $M$ (монотонные) и $L$ (линейные).


## 2

Какому условию удовлетворяет функция $f$, принадлежащая классу $T_0$?

- ( ) $f(x_1, \dots, x_n) = 0$ для всех наборов
- (x) $f(0, 0, \dots, 0) = 0$
- ( ) $f(1, 1, \dots, 1) = 0$
- ( ) $f(\overline{x}) = 0$

Пояснение:
**Ответ:** $f(0, 0, \dots, 0) = 0$.

Класс $T_0$ состоит из всех булевых функций, сохраняющих константу 0, то есть принимающих значение 0 на нулевом наборе аргументов.


## 3

Какое свойство выполняется для самодвойственной функции $f \in S$?

- ( ) $f(0, \dots, 0) = f(1, \dots, 1)$
- (x) $f(\overline{x_1}, \dots, \overline{x_n}) = \overline{f(x_1, \dots, x_n)}$
- ( ) $f(x_1, \dots, x_n) \equiv 1$
- ( ) Степень полинома Жегалкина равна 1

Пояснение:
**Ответ:** $f(\overline{x_1}, \dots, \overline{x_n}) = \overline{f(x_1, \dots, x_n)}$.

Самодвойственная функция совпадает со своей двойственной $f = f^*$. По определению: $f^*(x) = \overline{f(\overline{x})}$, откуда $f(\overline{x}) = \overline{f(x)}$. На противоположных наборах аргументов функция принимает противоположные значения.


## 4

Какая из следующих функций НЕ является монотонной ($f \notin M$)?

- ( ) $f(x, y) = x \land y$
- ( ) $f(x, y) = x \lor y$
- (x) $f(x) = \overline{x}$
- ( ) $f(x, y, z) = x$

Пояснение:
**Ответ:** $f(x) = \overline{x}$.

В монотонной функции при увеличении аргументов значение функции не должно убывать. Для отрицания: набор $0 < 1$, однако $\overline{0} = 1 > \overline{1} = 0$. Значение функции убывает, следовательно, отрицание не монотонно.


## 5

Что называется шефферовой функцией?

- ( ) Функция, полином Жегалкина которой имеет степень 2
- (x) Булева функция, которая сама по себе образует функционально полный базис (не принадлежит ни одному из 5 классов Поста)
- ( ) Функция, равная 1 на всех наборах
- ( ) Самодвойственная линейная функция

Пояснение:
**Ответ:** Булева функция, которая сама по себе образует функционально полный базис.

Шефферова функция удовлетворяет условиям: $f \notin T_0, f \notin T_1, f \notin S, f \notin M, f \notin L$. Любая булева функция может быть выражена только через эту операцию. Примеры: штрих Шеффера $x \mid y$ и стрелка Пирса $x \downarrow y$.


## 6

Каково необходимое и достаточное условие функциональной полноты системы булевых функций $F$ по теореме Поста?

- ( ) Система содержит не менее 5 функций
- ( ) Система содержит операции конъюнкции и дизъюнкции
- (x) Система не содержится целиком ни в одном из пяти предполных классов Поста
- ( ) Все функции системы являются линейными

Пояснение:
**Ответ:** Система не содержится целиком ни в одном из 5 предполных классов Поста.

Критерий Поста: $[F] = P_2 \iff F \not\subseteq T_0, F \not\subseteq T_1, F \not\subseteq S, F \not\subseteq M, F \not\subseteq L$. В таблице Поста в каждом из 5 столбцов должен присутствовать хотя бы один минус.


## 7

Какое максимальное количество функций может содержать минимальный базис булевых функций?

- ( ) 2
- ( ) 3
- (x) 4
- ( ) 5

Пояснение:
**Ответ:** 4.

Каждая функция в базисе должна быть необходима для разрушения хотя бы одного предполного класса. Поскольку если функция разрушает $T_0$ и $T_1$, она может не принадлежать $S$, доказано, что никакой неприводимый базис в $P_2$ не может содержать более 4 функций.


## 8

Почему система функций $\{x \land y, x \lor y\}$ НЕ является функционально полной?

- ( ) Она не содержит констант
- (x) Обе функции принадлежат классам $T_0, T_1$ и $M$
- ( ) Она содержит слишком мало функций
- ( ) Конъюнкция неассоциативна

Пояснение:
**Ответ:** Обе функции лежат в $T_0, T_1$ и $M$.

Для обеих функций: $0 \land 0 = 0 \lor 0 = 0$ (сохраняют 0), $1 \land 1 = 1 \lor 1 = 1$ (сохраняют 1), и обе монотонны. Суперпозицией таких функций невозможно получить, например, отрицание $\overline{x}$.


## 9

К каким из классов Поста принадлежит тождественная константа $0$?

- ( ) $T_0, T_1, S, M, L$
- (x) $T_0, M, L$ (но не $T_1$ и не $S$)
- ( ) Только $T_0$
- ( ) Только $L$

Пояснение:
**Ответ:** $T_0, M, L$.

1. Константа 0 сохраняет 0 ($0 = 0 \implies 0 \in T_0$);
2. Не сохраняет 1 ($0 \ne 1 \implies 0 \notin T_1$);
3. Не самодвойственна ($0^* = 1 \ne 0 \implies 0 \notin S$);
4. Монотонна (константа не убывает $\implies 0 \in M$);
5. Линейна (полином $P = 0$, степень $0 \le 1 \implies 0 \in L$).


## 10

Какая из следующих систем функций образует базис Жегалкина?

- ( ) $\{\lor, \neg\}$
- ( ) $\{\mid\}$
- (x) $\{\oplus, \land, 1\}$
- ( ) $\{x \implies y\}$

Пояснение:
**Ответ:** $\{\oplus, \land, 1\}$.

В базисе Жегалкина операции: сложение по модулю 2 ($\oplus$), конъюнкция ($\land$) и логическая единица (1). Операция $\oplus \notin T_1$, константа $1 \notin T_0$, конъюнкция $\land \notin L$, отрицание $\overline{x} = x \oplus 1 \notin M$, конъюнкция $\land \notin S$. Система полна.


# Блок 2. Краткий ответ

## 11

Сколько функций от 2 переменных принадлежат классу $T_0$ (сохраняющих 0)?

Ответ: 8
Формат: целое число

Пояснение:
**Ответ:** 8.

Вектор значений функции от 2 переменных имеет длину $2^2 = 4$. Первый бит зафиксирован: $f(0, 0) = 0$. Остальные 3 бита могут быть любыми: $2^{4-1} = 2^3 = 8$.


## 12

Сколько самодвойственных функций существует от $n = 3$ переменных?

Ответ: 16
Формат: целое число

Пояснение:
**Ответ:** 16.

Число самодвойственных функций равно $2^{2^{n-1}}$.
Для $n = 3$: $2^{2^{3-1}} = 2^{2^2} = 2^4 = 16$.


## 13

Сколько линейных функций существует от $n = 2$ переменных?

Ответ: 8
Формат: целое число

Пояснение:
**Ответ:** 8.

Число линейных функций от $n$ переменных равно $2^{n+1}$.
Для $n = 2$: $2^{2+1} = 2^3 = 8$.


## 14

Какова минимальная мощность функционально полного базиса в $P_2$?

Ответ: 1
Формат: целое число

Пояснение:
**Ответ:** 1.

Существуют базисы, состоящие из одной-единственной шефферовой функции (штрих Шеффера или стрелка Пирса). Поэтому минимальная мощность равна 1.


## 15

Сколько функций от 1 переменной являются шефферовыми (полными сами по себе)?

Ответ: 0
Формат: целое число

Пояснение:
**Ответ:** 0.

От 1 переменной всего 4 функции: $0, 1, x, \overline{x}$.
- $0 \in T_0$;
- $1 \in T_1$;
- $x \in T_0, T_1, S, M, L$;
- $\overline{x} \in S, L$.
Ни одна функция от 1 переменной не лежит вне всех 5 классов Поста.


## 16

Сколько минусов должно быть в каждом столбце таблицы Поста, чтобы система функций была функционально полной?

Ответ: 1
Формат: целое число

Пояснение:
**Ответ:** 1.

В каждом из пяти столбцов ($T_0, T_1, S, M, L$) должен присутствовать хотя бы один минус. Это гарантирует, что система не содержится целиком ни в одном из пяти предполных классов.


# Блок 3. Несколько верных вариантов

## 17

Какие из перечисленных функций являются шефферовыми (образуют одноэлементный базис)?

- [x] Штрих Шеффера: $x \mid y = \overline{x \land y}$
- [x] Стрелка Пирса: $x \downarrow y = \overline{x \lor y}$
- [ ] Сложение по модулю 2: $x \oplus y$
- [ ] Импликация: $x \implies y$
- [ ] Конъюнкция: $x \land y$

Пояснение:
**Ответ:** Штрих Шеффера и стрелка Пирса.

Обе эти бинарные функции не сохраняют 0 ($0 \mid 0 = 1, 0 \downarrow 0 = 1$), не сохраняют 1 ($1 \mid 1 = 0, 1 \downarrow 1 = 0$), не самодвойственны, не монотонны и нелинейны. Импликация сохраняет 1, а XOR сохраняет 0.


## 18

Какие из следующих систем булевых функций являются функционально полными?

- [x] $\{\land, \neg\}$
- [x] $\{\lor, \neg\}$
- [x] $\{\implies, 0\}$
- [ ] $\{\land, \lor\}$
- [x] $\{\oplus, \land, 1\}$

Пояснение:
**Ответ:** $\{\land, \neg\}$; $\{\lor, \neg\}$; $\{\implies, 0\}$; $\{\oplus, \land, 1\}$.

Система $\{\land, \lor\}$ лежит в $T_0, T_1, M$ и не полна. Система $\{\implies, 0\}$ полна, так как $x \implies 0 = \overline{x}$, а $\{\implies, \neg\}$ порождает все функции ($\overline{x \implies \overline{y}} = x \land y$).


## 19

Какие свойства оператора замыкания $[F]$ выполняются для любых систем булевых функций?

- [x] Экстенсивность: $F \subseteq [F]$
- [x] Идемпотентность: $[[F]] = [F]$
- [x] Монотонность: $F_1 \subseteq F_2 \implies [F_1] \subseteq [F_2]$
- [ ] $[F_1 \cap F_2] = [F_1] \cap [F_2]$ для любых множеств
- [x] Замыкание любого из пяти классов Поста равно самому этому классу: $[T_0] = T_0$

Пояснение:
**Ответ:** Экстенсивность; идемпотентность; монотонность; замкнутость классов Поста.

Оператор замыкания является оператором замыкания Тарского (экстенсивен, идемпотентен, монотонен). Классы Поста замкнуты по определению. Пересечение замыканий не обязательно совпадает с замыканием пересечения.


## 20

Какие утверждения о монотонных функциях ($f \in M$) верны?

- [x] Всякая константная функция монотонна ($0 \in M, 1 \in M$)
- [x] В сокращенной ДНФ монотонной функции нет отрицаний переменных
- [x] Суперпозиция монотонных функций всегда монотонна
- [ ] Отрицание монотонной функции всегда монотонно
- [x] Конъюнкция и дизъюнкция монотонных функций монотонны

Пояснение:
**Ответ:** Константы монотонны; в сокращенной ДНФ нет отрицаний; суперпозиция монотонна; $\land$ и $\lor$ монотонны.

Отрицание $\overline{x}$ не монотонно. Если бы отрицание монотонной функции было монотонно, класс $M$ содержал бы отрицание, что неверно.


## 21

Дана система функций $F = \{x \oplus y, 1\}$. Каким классам Поста принадлежит вся система $F$?

- [ ] $T_0$
- [ ] $T_1$
- [ ] $S$
- [ ] $M$
- [x] $L$

Пояснение:
**Ответ:** Только классу $L$ (линейные).

- $1(0, \dots, 0) = 1 \ne 0 \implies F \not\subseteq T_0$;
- $1 \oplus 1 = 0 \ne 1 \implies F \not\subseteq T_1$;
- $1^* = 0 \ne 1 \implies F \not\subseteq S$;
- $1 \oplus x = \overline{x} \notin M \implies F \not\subseteq M$;
- Обе функции $x \oplus y$ и $1$ являются линейными полиномами (степень $\le 1$), поэтому $F \subseteq L$. Система не полна, так как целиком содержится в классе $L$.


## 22

Какие утверждения о классах Поста верны?

- [x] Ни одна константа не является самодвойственной ($0 \notin S, 1 \notin S$)
- [x] Пересечение всех 5 классов Поста состоит только из функции тождественного селектора $f(x) = x$ (с фиктивными переменными)
- [x] Любая самодвойственная функция принимает значение 1 ровно на половине наборов
- [ ] Класс линейных функций замкнут относительно дизъюнкции
- [x] Число функций в $T_0$ в точности равно числу функций в $T_1$

Пояснение:
**Ответ:** Константы не самодвойственны; пересечение содержит $f(x)=x$; самодвойственная принимает 1 на половине наборов; мощности $T_0$ и $T_1$ равны.

Дизъюнкция двух линейных функций не всегда линейна: $x \lor y = x \oplus y \oplus xy \notin L$. Все остальные утверждения — классические свойства классов Поста.
