# Блок 1. Один верный вариант

## 1

Что называется простой импликантой булевой функции $f$?

- ( ) Любая конъюнкция, входящая в СДНФ функции $f$
- (x) Импликанта функции $f$, никакая собственная часть которой не является импликантой $f$
- ( ) Дизъюнкция всех минтермов
- ( ) Конъюнкция, содержащая все $n$ переменных

Пояснение:
**Ответ:** Импликанта, никакая собственная часть которой не является импликантой $f$.

Простая импликанта — это максимальный по размеру интервал булева куба, целиком лежащий в множестве единиц функции. Удаление из неё хотя бы одной буквы приводит к тому, что полученная конъюнкция перестаёт быть импликантой функции $f$.


## 2

Какое утверждение о ядровой (существенной) простой импликанте является верным?

- ( ) Ядровая импликанта может быть удалена из МДНФ без потери эквивалентности
- (x) Ядровая импликанта обязана входить в любую минимальную ДНФ
- ( ) Ядровая импликанта содержит наибольшее число букв среди всех простых импликант
- ( ) Ядровая импликанта покрывает только один единичный набор

Пояснение:
**Ответ:** Ядровая импликанта обязана входить в любую минимальную ДНФ.

По определению, ядровая импликанта покрывает хотя бы один такой единичный набор (базисную единицу), который не покрывается ни одной другой простой импликантой. Следовательно, без неё невозможно покрыть этот набор, и она обязана присутствовать в любой тупиковой и минимальной ДНФ.


## 3

На каком законе булевой алгебры основана операция склеивания в методе Куайна?

- ( ) $A \lor 0 = A$
- ( ) $A \land (A \lor B) = A$
- (x) $A \cdot x \lor A \cdot \overline{x} = A$
- ( ) $A \oplus A = 0$

Пояснение:
**Ответ:** $A x \lor A \overline{x} = A$.

Операция неполного склеивания выносит общий множитель $A$: $A(x \lor \overline{x}) = A \cdot 1 = A$. В методе Куайна конъюнкция $A$ добавляется к формуле, после чего по закону поглощения $A \lor Ax = A$ более длинные конъюнкции поглощаются.


## 4

Какой код используется для разметки строк и столбцов на картах Карно, чтобы соседние клетки отличались значением ровно одной переменной?

- ( ) Двоичный код с накоплением
- (x) Код Грея
- ( ) Код Хэмминга
- ( ) Прямой двоичный счет

Пояснение:
**Ответ:** Код Грея.

В коде Грея последовательность наборов: `00`, `01`, `11`, `10`. Каждая пара соседних наборов, включая крайние (`10` и `00`), различается ровно в одном бите, что обеспечивает геометрическое соответствие смежных клеток карты Карно и операций склеивания.


## 5

Каких размеров могут быть группы склеивания (прямоугольные блоки из единиц) на карте Карно?

- ( ) Любых целых размеров (2, 3, 5, 6, ...)
- (x) Только степеней двойки: $1, 2, 4, 8, 16, \dots$ ($2^k$)
- ( ) Только квадратных размеров ($1 \times 1, 2 \times 2, 4 \times 4$)
- ( ) Четных чисел

Пояснение:
**Ответ:** Только степеней двойки: $2^k$.

Каждое склеивание по одной переменной объединяет 2 подкуба. Склеивание по $k$ переменным устраняет $k$ букв и объединяет ровно $2^k$ смежных клеток булева куба в один интервал.


## 6

В карте Карно размера $4 \times 4$ для 4 переменных четыре крайних угловых клетки (наборы 0000, 0010, 1000, 1010) содержат единицы. Можно ли объединить их в одну группу склеивания?

- ( ) Нет, так как они находятся в разных углах карты
- ( ) Можно объединить только попарно
- (x) Да, карта Карно торически замкнута, и 4 угла образуют смежную группу из 4 клеток
- ( ) Можно, только если центр карты тоже заполнен единицами

Пояснение:
**Ответ:** Да, 4 угла образуют смежную группу из 4 клеток.

Благодаря торической непрерывности левый край карты склеен с правым, а верхний с нижним. Четыре угла карты представляют интервал $m_0, m_2, m_8, m_{10}$, который склеивается в конъюнкцию $\overline{B}\overline{D}$ ранга 2.


## 7

Что такое сокращенная ДНФ булевой функции?

- ( ) ДНФ, содержащая минимальное число букв
- (x) Дизъюнкция всех простых импликант функции
- ( ) ДНФ, полученная удалением всех констант
- ( ) ДНФ без отрицаний

Пояснение:
**Ответ:** Дизъюнкция всех простых импликант функции.

Сокращенная ДНФ получается после завершения всех возможных операций склеивания и поглощения. Она содержит все простые импликанты функции $f$.


## 8

Что выражает метод Петрика в табличном методе Куайна–Мак-Класки?

- ( ) Построение полинома Жегалкина
- (x) Нахождение всех минимальных покрытий единичных наборов простыми импликантами с помощью КНФ
- ( ) Вычисление спектра Фурье булевой функции
- ( ) Определение фиктивных переменных

Пояснение:
**Ответ:** Нахождение всех минимальных покрытий с помощью булева уравнения в форме КНФ.

Для каждого непокрытого минтерма $m_j$ составляется дизъюнкция покрывающих его простых импликант $(P_{i_1} \lor P_{i_2} \lor \dots)$. Конъюнкция этих условий по всем минтермам дает функцию покрытия. Раскрывая скобки и применяя закон поглощения, получают все тупиковые покрытия.


## 9

Как учитываются неопределенные состояния (don't care conditions, обозначаемые $\times$ или $d$) при минимизации на карте Карно?

- ( ) Они всегда считаются равными 0
- ( ) Они всегда обязаны включаться во все группы
- (x) Их можно принимать равными 1, если это увеличивает размер групп склеивания, либо 0, если они не нужны
- ( ) Из-за них функция не подлежит минимизации

Пояснение:
**Ответ:** Их принимают равными 1, если это выгодно для укрупнения групп, или 0 в противном случае.

Неопределенные состояния соответствуют запрещенным или невозможным входным комбинациям. Разработчик вправе доопределить их оптимальным образом для получения наименьшей площади схемы.


## 10

Чему равен результат склеивания двух минтермов $x\overline{y}z$ и $xyz$?

- ( ) $x$
- ( ) $z$
- (x) $xz$
- ( ) $y$

Пояснение:
**Ответ:** $xz$.

Выносим за скобки общий множитель $xz$:
$x\overline{y}z \lor xyz = xz(\overline{y} \lor y) = xz \cdot 1 = xz$.


# Блок 2. Краткий ответ

## 11

Сколько клеток содержит карта Карно для булевой функции от 4 переменных?

Ответ: 16
Формат: целое число

Пояснение:
**Ответ:** 16.

Число клеток равно мощности булевого куба $2^n = 2^4 = 16$.


## 12

На карте Карно для 4 переменных объединена группа из 8 единичных клеток. Сколько букв (литералов) останется в соответствующей элементарной конъюнкции?

Ответ: 1
Формат: целое число

Пояснение:
**Ответ:** 1.

Каждое удвоение размера группы устраняет ровно 1 переменную. Группа из $2^k = 8 = 2^3$ клеток в 4-мерном пространстве устраняет 3 переменные: $4 - 3 = 1$ переменная.


## 13

Дана булева функция $f(x, y) = x \lor xy$. Найдите число букв в её минимальной ДНФ.

Ответ: 1
Формат: целое число

Пояснение:
**Ответ:** 1.

По закону поглощения $x \lor xy = x$. Формула состоит из единственной буквы $x$.


## 14

Каково максимальное число единиц, которое может покрыть одна простая импликанта на карте Карно от 3 переменных (если функция не равна тождественной единице)?

Ответ: 4
Формат: целое число

Пояснение:
**Ответ:** 4.

Размеры подкубов равны степеням двойки: 1, 2, 4, 8. Если импликанта покрывает 8 клеток, то $f \equiv 1$. Для нетривиальной функции максимальный блок содержит 4 клетки (конъюнкция из 1 буквы).


## 15

Сколько простых импликант имеет функция $f(x, y) = x \oplus y$?

Ответ: 2
Формат: целое число

Пояснение:
**Ответ:** 2.

Функция $x \oplus y$ равна 1 на наборах $(0, 1)$ и $(1, 0)$. Эти клетки диагональны на карте Карно и не склеиваются. Каждая из них образует отдельную простую импликанту: $\overline{x}y$ и $x\overline{y}$. Всего 2 простые импликанты.


## 16

Сколько ядровых импликант содержит функция, если в таблице покрытия Куайна–Мак-Класки 3 столбца имеют ровно по одной отметке $\times$, и все три отметки принадлежат разным строкам?

Ответ: 3
Формат: целое число

Пояснение:
**Ответ:** 3.

Каждый столбец с единственной отметкой $\times$ однозначно выделяет соответствующую строку как ядровую импликанту. Так как отметки принадлежат трем разным строкам, функция имеет не менее 3 ядровых импликант.


# Блок 3. Несколько верных вариантов

## 17

Какие операции используются на этапах метода Куайна для получения сокращенной ДНФ?

- [x] Неполное склеивание: $A x \lor A \overline{x} = A x \lor A \overline{x} \lor A$
- [x] Закон поглощения: $A \lor A B = A$
- [ ] Разложение в ряд Тейлора
- [ ] Метод исключения Гаусса
- [x] Закон идемпотентности: $A \lor A = A$

Пояснение:
**Ответ:** Неполное склеивание; поглощение; идемпотентность для устранения дубликатов.

Метод Куайна основывается исключительно на законах булевой алгебры: склеивании противоположных литералов и поглощении более длинных конъюнкций более короткими.


## 18

Какие свойства карты Карно обеспечивают её эффективность при минимизации вручную?

- [x] Кодирование строк и столбцов кодом Грея
- [x] Возможность визуального объединения соседних клеток в прямоугольные блоки
- [x] Торическая непрерывность (склейка крайних строк и крайних столбцов)
- [ ] Обязательное присутствие осей симметрии третьего порядка
- [x] Быстрое выявление ядровых импликант по изолированным единицам

Пояснение:
**Ответ:** Код Грея; прямоугольные блоки $2^k$; торическая непрерывность; быстрое нахождение ядровых импликант.

Карты Карно представляют собой развертку $n$-мерного гиперкуба. Топологически карта замкнута в тор.


## 19

Какие утверждения о тупиковых и минимальных ДНФ верны?

- [x] Любая минимальная ДНФ является тупиковой
- [ ] Всякая тупиковая ДНФ обязательно является минимальной
- [x] У одной и той же булевой функции может существовать несколько различных минимальных ДНФ
- [x] Все ядровые простые импликанты входят во все тупиковые ДНФ
- [ ] Сокращенная ДНФ всегда содержит меньше слагаемых, чем минимальная ДНФ

Пояснение:
**Ответ:** Любая МДНФ тупиковая; у функции может быть несколько МДНФ; ядровые входят во все тупиковые ДНФ.

Тупиковая ДНФ — это локальный оптимум (нельзя удалить ни одной импликанты). Однако среди нескольких тупиковых ДНФ некоторые могут содержать меньше букв — они и являются минимальными. Сокращенная ДНФ содержит ВСЕ простые импликанты, поэтому слагаемых в ней обычно больше.


## 20

В каких случаях минтермы могут быть объединены в один блок на карте Карно?

- [x] Если они образуют прямоугольник размера $1 \times 2$ или $2 \times 1$
- [x] Если они образуют квадрат $2 \times 2$
- [x] Если они расположены в 4 углах карты $4 \times 4$
- [ ] Если они образуют диагональную цепочку из 3 клеток
- [x] Если они образуют прямоугольник $2 \times 4$ или $4 \times 2$

Пояснение:
**Ответ:** Размеры $1 \times 2, 2 \times 1$; квадрат $2 \times 2$; 4 угла; прямоугольники $2 \times 4$ и $4 \times 2$.

Блоки обязаны быть прямоугольниками со сторонами, являющимися степенями двойки. Диагональные клетки отличаются более чем в одном разряде и не склеиваются напрямую.


## 21

Какие преимущества имеет алгоритм Куайна–Мак-Класки по сравнению с картами Карно?

- [x] Он алгоритмичен и легко программируется на ЭВМ
- [x] Он применим для функций от произвольного числа переменных ($n > 6$)
- [x] Он строго гарантирует нахождение всех простых импликант
- [ ] Он выполняется за постоянное время $O(1)$
- [x] В сочетании с методом Петрика он гарантированно находит абсолютно все МДНФ

Пояснение:
**Ответ:** Легко программируется; применим при $n > 6$; строго находит все простые импликанты; находит все МДНФ.

Карты Карно наглядны для человека только до 4–5 переменных (при $n=6$ требуется трехмерная карта из 4 слоев). Алгоритм Куайна–Мак-Класки работает для любого $n$, хотя задача минимизации в худшем случае NP-трудна.


## 22

Пусть после склеивания получены простые импликанты $P_1 = x\overline{y}$, $P_2 = yz$, $P_3 = xz$. Известно, что $P_1$ и $P_2$ ядровые, а $P_3$ покрывается их объединением. Какие утверждения верны?

- [x] $P_3$ является лишней (неядровой) импликантой
- [x] МДНФ функции равна $x\overline{y} \lor yz$
- [ ] $P_3$ обязана войти в МДНФ
- [x] Формула $x\overline{y} \lor yz \lor xz$ представляет собой сокращенную ДНФ
- [ ] МДНФ содержит 3 конъюнкции

Пояснение:
**Ответ:** $P_3$ лишняя; МДНФ равна $x\overline{y} \lor yz$; исходная формула — сокращенная ДНФ.

Это классический пример правила консенсуса: $x\overline{y} \lor yz \lor xz = x\overline{y} \lor yz$. Импликанта $xz$ (консенсус) поглощается покрытием ядровых импликант.
