# Блок 1. Один верный вариант

## 1

Чему равна сумма степеней всех вершин неориентированного графа, содержащего $m$ рёбер (лемма о рукопожатиях)?

- ( ) $m$
- (x) $2m$
- ( ) $m^2$
- ( ) $m(m - 1) / 2$

Пояснение:
**Ответ:** $2m$.

По лемме о рукопожатиях каждое ребро инцидентно двум вершинам и добавляет ровно $+1$ к степени каждой из них. Поэтому суммарная степень вершин в точности равна удвоенному числу рёбер: $\sum \deg(v) = 2|E| = 2m$.


## 2

Что утверждает фундаментальное следствие из леммы о рукопожатиях?

- ( ) Все вершины графа имеют четную степень
- ( ) Число ребер в графе всегда четно
- (x) Число вершин с нечётной степенью в любом графе всегда чётно
- ( ) В графе не может быть изолированных вершин

Пояснение:
**Ответ:** Число вершин с нечётной степенью всегда чётно.

Если бы нечетных вершин было нечетное количество, их сумма степеней была бы нечетной, а сумма четных степеней всегда четна. Тогда общая сумма степеней была бы нечетной, что противоречит равенству $\sum \deg(v) = 2|E|$.


## 3

Каков критерий двудольности графа согласно теореме Кёнига?

- ( ) Граф не содержит мостов
- (x) Граф не содержит простых циклов нечётной длины
- ( ) Граф является деревом
- ( ) Граф планарен

Пояснение:
**Ответ:** Граф не содержит простых циклов нечётной длины.

Теорема Кёнига: граф является двудольным тогда и только тогда, когда все его циклы имеют четную длину (циклы длины 3, 5, 7, ... отсутствуют). Вершины можно раскрасить в 2 цвета тогда и только тогда, когда при обходе любого цикла чередование цветов не приводит к конфликту.


## 4

Сколько рёбер содержит связное дерево с $n$ вершинами?

- ( ) $n$
- (x) $n - 1$
- ( ) $n + 1$
- ( ) $n(n - 1) / 2$

Пояснение:
**Ответ:** $n - 1$.

Одно из шести эквивалентных определений дерева: дерево — это связный граф с $n$ вершинами и ровно $n - 1$ рёбрами. Каждое добавление ребра без циклов соединяет две компоненты связности.


## 5

Сколько различных помеченных деревьев можно построить на $n$ вершинах согласно формуле Кэли?

- ( ) $n!$
- ( ) $2^n$
- (x) $n^{n - 2}$
- ( ) $(n - 1)!$

Пояснение:
**Ответ:** $n^{n - 2}$.

Формула Кэли (1889 г.) доказывается через биекцию с кодами Прюфера: каждому помеченному дереву на $n$ вершинах взаимно-однозначно соответствует строка длины $n - 2$ из чисел от $1$ до $n$. Количество таких строк равно $n^{n-2}$.


## 6

Что означает элемент $(A^k)_{ij}$ матрицы смежности $A$, возведённой в степень $k$?

- ( ) Кратчайшее расстояние между вершинами $v_i$ и $v_j$
- (x) Количество всевозможных маршрутов длины ровно $k$ между вершинами $v_i$ и $v_j$
- ( ) Число общих соседей вершин
- ( ) Определитель подматрицы

Пояснение:
**Ответ:** Количество маршрутов длины $k$ между $v_i$ и $v_j$.

По правилу матричного умножения $(A^k)_{ij} = \sum_{p_1, \dots, p_{k-1}} a_{i p_1} a_{p_1 p_2} \dots a_{p_{k-1} j}$. Каждое ненулевое произведение единиц соответствует конкретной цепочке ребер длины $k$.


## 7

Каково условие существования эйлерова цикла в связном графе (критерий Эйлера)?

- ( ) Граф не содержит циклов
- (x) Степени всех вершин графа четны
- ( ) Число вершин равно числу рёбер
- ( ) Граф содержит гамильтонов путь

Пояснение:
**Ответ:** Степени всех вершин четны.

Эйлеров цикл проходит по каждому ребру графа ровно один раз. При каждом проходе через вершину расходуется 2 ребра (одно входящее, одно исходящее). Поэтому для замкнутого маршрута степень каждой вершины обязана быть четной.


## 8

Как формулируется формула Эйлера для связного плоского графа с $V$ вершинами, $E$ рёбрами и $F$ гранями (включая внешнюю)?

- ( ) $V + E - F = 2$
- (x) $V - E + F = 2$
- ( ) $V - E - F = 0$
- ( ) $V + F = E$

Пояснение:
**Ответ:** $V - E + F = 2$.

Знаменитая формула Эйлера для плоских графов и выпуклых многогранников связывает число вершин, рёбер и граней: $V - E + F = 2$.


## 9

Какая пара графов является минимальными непланарными графами в теореме Понтрягина–Куратовского?

- ( ) $K_3$ и $K_4$
- ( ) $K_4$ и $K_{2,3}$
- (x) $K_5$ (полный граф на 5 вершинах) и $K_{3,3}$ (полный двудольный «домики и колодцы»)
- ( ) Деревья и циклы

Пояснение:
**Ответ:** $K_5$ и $K_{3,3}$.

Теорема Куратовского (1930): граф планарен тогда и только тогда, когда он не содержит подграфов, гомеоморфных полному графу $K_5$ или полному двудольному графу $K_{3,3}$.


## 10

Какую структуру данных наиболее эффективно использовать в алгоритме Краскала для быстрой проверки ацикличности и объединения компонент связности?

- ( ) Стек
- (x) Система непересекающихся множеств (DSU / Disjoint Set Union)
- ( ) Хеш-таблица
- ( ) Двоичное дерево поиска

Пояснение:
**Ответ:** DSU (Disjoint Set Union).

Алгоритм Краскала сортирует рёбра по весу, а затем объединяет деревья. Структура DSU с эвристиками ранга и сжатия путей выполняет операции Find и Union за время $O(\alpha(V))$, что обеспечивает общую сложность алгоритма $O(E \log E)$.


# Блок 2. Краткий ответ

## 11

Сколько рёбер содержит полный граф $K_6$ на 6 вершинах?

Ответ: 15
Формат: целое число

Пояснение:
**Ответ:** 15.

Число рёбер в полном графе $K_n$ равно $\binom{n}{2} = \frac{n(n - 1)}{2}$.
Для $n = 6$: $\frac{6 \times 5}{2} = 15$.


## 12

Граф содержит 7 вершин, степени которых равны: $2, 3, 3, 4, 4, 5, 5$. Сколько рёбер в этом графе?

Ответ: 13
Формат: целое число

Пояснение:
**Ответ:** 13.

Сумма степеней вершин: $2 + 3 + 3 + 4 + 4 + 5 + 5 = 26$.
По лемме о рукопожатиях: $2 |E| = 26 \implies |E| = 13$.


## 13

Сколько различных помеченных деревьев можно построить на 4 вершинах по формуле Кэли?

Ответ: 16
Формат: целое число

Пояснение:
**Ответ:** 16.

По формуле Кэли $T_n = n^{n - 2}$. Для $n = 4$: $4^{4 - 2} = 4^2 = 16$.


## 14

Связный плоский граф имеет 10 вершин и 15 рёбер. Сколько граней (включая внешнюю) имеет этот граф?

Ответ: 7
Формат: целое число

Пояснение:
**Ответ:** 7.

По формуле Эйлера $V - E + F = 2$.
Подставляем: $10 - 15 + F = 2 \implies -5 + F = 2 \implies F = 7$.


## 15

Сколько нечётных вершин может иметь связный граф, чтобы в нем существовал открытый эйлеров путь (начинающийся и заканчивающийся в разных вершинах)?

Ответ: 2
Формат: целое число

Пояснение:
**Ответ:** 2.

Эйлеров путь существует тогда и только тогда, когда связный граф имеет ровно 2 вершины нечётной степени (они служат началом и концом пути).


## 16

Сколько рёбер необходимо удалить из связного графа с 8 вершинами и 12 рёбрами, чтобы получить остовное дерево?

Ответ: 5
Формат: целое число

Пояснение:
**Ответ:** 5.

Остовное дерево на 8 вершинах обязано содержать ровно $n - 1 = 8 - 1 = 7$ рёбер.
Число удаляемых («лишних») хорд равно цикломатическому числу графа: $\mu = |E| - |V| + 1 = 12 - 8 + 1 = 5$.


# Блок 3. Несколько верных вариантов

## 17

Какие из перечисленных условий являются эквивалентными определениями дерева для графа с $n$ вершинами?

- [x] Связный граф без циклов
- [x] Связный граф, имеющий ровно $n - 1$ рёбер
- [x] Ациклический граф, имеющий ровно $n - 1$ рёбер
- [x] Между любыми двумя вершинами существует единственный простой путь
- [ ] Граф, содержащий хотя бы один эйлеров цикл

Пояснение:
**Ответ:** Связный ациклический; связный с $n-1$ ребрами; ациклический с $n-1$ ребрами; единственный простой путь между любой парой вершин.

Это классические эквивалентные определения дерева. В нетривиальном дереве нет циклов, поэтому в нем в принципе не может быть эйлерова цикла.


## 18

Какие утверждения об алгоритмах поиска минимального остовного дерева (MST) верны?

- [x] Алгоритм Краскала относится к жадным алгоритмам
- [x] Алгоритм Прима строит остовное дерево, последовательно наращивая связное поддерево от начальной вершины
- [x] Если все веса рёбер в графе попарно различны, то минимальный остов единственен
- [ ] Алгоритм Краскала применим только для плоских графов
- [x] Суммарный вес минимального остова не зависит от выбора стартовой вершины в алгоритме Прима

Пояснение:
**Ответ:** Краскал — жадный алгоритм; Прим растит поддерево; при разных весах остов единственен; вес остова не зависит от старта.

Алгоритмы Краскала и Прима применимы к любым связным взвешенным графам, планарность для них не требуется.


## 19

В каких из приведенных случаев связный граф гарантированно содержит эйлеров цикл?

- [x] Полный граф $K_5$ (степени всех вершин равны 4)
- [ ] Полный граф $K_4$ (степени всех вершин равны 3)
- [x] Простой цикл $C_6$ (степени всех вершин равны 2)
- [ ] Полный двудольный граф $K_{2, 3}$
- [x] Полный двудольный граф $K_{4, 4}$ (степени всех вершин равны 4)

Пояснение:
**Ответ:** $K_5$; $C_6$; $K_{4, 4}$.

В графах $K_5$, $C_6$ и $K_{4, 4}$ все вершины имеют четные степени (4, 2 и 4 соответственно). В $K_4$ степени нечетные (3). В $K_{2, 3}$ вершины одной доли имеют степень 3 (нечетная).


## 20

Какие свойства справедливы для планарных графов?

- [x] Граф может быть уложен на плоскости без самопересечения рёбер
- [x] Для связного плоского графа выполняется формула Эйлера $V - E + F = 2$
- [x] Для простого плоского графа с $V \ge 3$ верно неравенство $E \le 3V - 6$
- [x] Любой плоский граф можно правильно раскрасить не более чем в 4 цвета (теорема о 4 красках)
- [ ] Полный граф $K_5$ является планарным

Пояснение:
**Ответ:** Укладка без самопересечений; формула Эйлера; $E \le 3V - 6$; теорема о 4 красках.

$K_5$ не планарен: для него $V = 5, E = 10$, а $3V - 6 = 15 - 6 = 9 < 10$.


## 21

Какие утверждения о гамильтоновых графах верны?

- [x] Гамильтонов цикл проходит через каждую вершину графа ровно по одному разу
- [x] Теорема Дирака: если в простом графе с $n \ge 3$ степень каждой вершины $\deg(v) \ge n/2$, то граф гамильтонов
- [x] Теорема Оре: если для любых несмежных вершин $u, v$ выполнено $\deg(u) + \deg(v) \ge n$, то граф гамильтонов
- [ ] Любой эйлеров граф является гамильтоновым
- [x] Задача проверки гамильтоновости произвольного графа является NP-полной

Пояснение:
**Ответ:** Цикл проходит через все вершины; теорема Дирака; теорема Оре; NP-полнота задачи.

Эйлеровость (обход всех ребер) и гамильтоновость (обход всех вершин) независимы: граф-бабочка («восьмерка» из двух треугольников с общей вершиной) эйлеров, но не содержит гамильтонова цикла (через центральную вершину пришлось бы пройти дважды).


## 22

Какие свойства матрицы смежности $A$ неориентированного графа без петель являются верными?

- [x] Главная диагональ матрицы целиком состоит из нулей ($a_{ii} = 0$)
- [x] Матрица симметрична относительно главной диагонали ($A = A^T$)
- [x] Сумма элементов в $i$-й строке равна степени $i$-й вершины: $\sum_j a_{ij} = \deg(v_i)$
- [ ] Сумма всех элементов матрицы равна числу рёбер $|E|$
- [x] Сумма всех элементов матрицы равна удвоенному числу рёбер $2|E|$

Пояснение:
**Ответ:** Нули на главной диагонали; симметричность; сумма строки равна степени вершины; сумма всех элементов равна $2|E|$.

Поскольку каждое ребро $\{u, v\}$ учитывается дважды (в ячейках $a_{uv}$ и $a_{vu}$), сумма всех элементов матрицы смежности равна $\sum \deg(v) = 2|E|$.
