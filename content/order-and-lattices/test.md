# Блок 1. Один верный вариант

## 1

Какому набору свойств должно удовлетворять бинарное отношение $R$ на множестве $A$, чтобы являться отношением эквивалентности?

- ( ) Рефлексивность, антисимметричность, транзитивность
- (x) Рефлексивность, симметричность, транзитивность
- ( ) Антирефлексивность, асимметричность, транзитивность
- ( ) Симметричность, транзитивность, полнота

Пояснение:
**Ответ:** Рефлексивность, симметричность, транзитивность.

По определению (Пермяков А.С., Страдина М.В.), отношение эквивалентности удовлетворяет трем аксиомам:
1. Рефлексивность: $\forall x \; (x \sim x)$;
2. Симметричность: $\forall x, y \; (x \sim y \implies y \sim x)$;
3. Транзитивность: $\forall x, y, z \; (x \sim y \land y \sim z \implies x \sim z)$.
Рефлексивность, антисимметричность и транзитивность определяют отношение частичного порядка, а антирефлексивность, асимметричность и транзитивность — строгого порядка.


## 2

Пусть $\sim$ — отношение эквивалентности на множестве $A$. Какое утверждение о классах эквивалентности $[a]$ и $[b]$ является верным?

- ( ) Если $a \ne b$, то $[a] \cap [b] = \varnothing$
- ( ) Для любых $a, b \in A$ выполнено $[a] \cup [b] = A$
- (x) $[a] \cap [b] \ne \varnothing \iff [a] = [b]$
- ( ) $[a] = [b] \iff a = b$

Пояснение:
**Ответ:** $[a] \cap [b] \ne \varnothing \iff [a] = [b]$.

Фундаментальное свойство классов эквивалентности: любые два класса либо вообще не пересекаются, либо полностью совпадают. Если существует хотя бы один общий элемент $c \in [a] \cap [b]$, то $c \sim a$ и $c \sim b$, откуда по симметричности и транзитивности $a \sim b$, что влечет $[a] = [b]$.


## 3

Сколько различных отношений эквивалентности можно задать на множестве из 3 элементов?

- ( ) 3
- ( ) 4
- (x) 5
- ( ) 6

Пояснение:
**Ответ:** 5.

Число отношений эквивалентности на $n$-элементном множестве равно числу его разбиений, задаваемому числом Белла $B_n$. Для $n = 3$:
$B_3 = \left\{ \begin{matrix} 3 \\ 1 \end{matrix} \right\} + \left\{ \begin{matrix} 3 \\ 2 \end{matrix} \right\} + \left\{ \begin{matrix} 3 \\ 3 \end{matrix} \right\} = 1 + 3 + 1 = 5$.
Разбиения: $\{\{1, 2, 3\}\}$, $\{\{1\}, \{2, 3\}\}$, $\{\{2\}, \{1, 3\}\}$, $\{\{3\}, \{1, 2\}\}$, $\{\{1\}, \{2\}, \{3\}\}$.


## 4

Чем нестрогий частичный порядок отличается от отношения эквивалентности?

- ( ) Нестрогий порядок антирефлексивен
- ( ) Нестрогий порядок не обладает транзитивностью
- (x) Нестрогий порядок антисимметричен вместо симметричности
- ( ) В нестрогом порядке любые два элемента сравнимы

Пояснение:
**Ответ:** Нестрогий порядок антисимметричен вместо симметричности.

Нестрогий частичный порядок удовлетворяет аксиомам: рефлексивность, антисимметричность ($x \le y \land y \le x \implies x = y$) и транзитивность. В отношении эквивалентности вместо антисимметричности требуется симметричность ($x \sim y \implies y \sim x$).


## 5

Что означает отношение непосредственного покрытия $x \lessdot y$ в частично упорядоченном множестве?

- ( ) $x = y$ или $x < y$
- (x) $x < y$ и не существует такого $z$, что $x < z < y$
- ( ) $x$ и $y$ несравнимы
- ( ) $y$ является наибольшим элементом всего ЧУМ

Пояснение:
**Ответ:** $x < y$ и не существует такого $z$, что $x < z < y$.

Элемент $y$ покрывает $x$ ($x \lessdot y$), если $x$ строго меньше $y$ и между ними нет промежуточных элементов. Именно пары покрытия соединяются отрезками на диаграмме Хассе.


## 6

Какое из следующих утверждений об экстремальных элементах ЧУМ верно?

- ( ) В любом конечном ЧУМ существует единственный минимальный элемент
- ( ) Наибольший элемент может быть не единственным
- (x) Если в ЧУМ существует наименьший элемент, то он является единственным минимальным
- ( ) Максимальный элемент обязан быть больше всех остальных элементов множества

Пояснение:
**Ответ:** Если в ЧУМ существует наименьший элемент, то он является единственным минимальным.

Наименьший элемент $m$ сравним со всеми $x \in P$ и удовлетворяет $\forall x \; (m \le x)$. По антисимметричности наименьший элемент всегда единственен и одновременно является единственным минимальным элементом. Максимальных же элементов может быть несколько (они несравнимы между собой).


## 7

Рассматривается множество делителей числа 12: $D_{12} = \{1, 2, 3, 4, 6, 12\}$ с отношением делимости ($a \mid b$). Что является точной верхней гранью (супремумом $\sup\{4, 6\}$)?

- ( ) 2
- ( ) 6
- (x) 12
- ( ) 24

Пояснение:
**Ответ:** 12.

В алгебре делимости супремумом двух чисел является их наименьшее общее кратное: $\sup(a, b) = \text{НОК}(a, b)$.
$\text{НОК}(4, 6) = 12 \in D_{12}$. Число 2 является точной нижней гранью ($\text{НОД}(4, 6) = 2$).


## 8

Что называется решёткой (lattice) в теории порядка?

- ( ) Линейно упорядоченное множество без петель
- (x) ЧУМ, в котором для любых двух элементов существуют точная нижняя и точная верхняя грани
- ( ) Граф без циклов, имеющий корень
- ( ) Множество, на котором задана биективная функция

Пояснение:
**Ответ:** ЧУМ, в котором для любых двух элементов существуют точная нижняя и точная верхняя грани.

По определению Пермякова и Страдиной, решётка — это частично упорядоченное множество $(L, \le)$, в котором для каждого подмножества из двух элементов $\{a, b\}$ определены операции $a \wedge b = \inf(a, b)$ (meet) и $a \vee b = \sup(a, b)$ (join).


## 9

Какое условие необходимо и достаточно, чтобы решётка $(L, \wedge, \vee)$ называлась булевой?

- ( ) Она линейно упорядочена
- (x) Она дистрибутивна, ограничена (имеет 0 и 1) и каждый элемент имеет дополнение
- ( ) Она содержит не более 8 элементов
- ( ) В ней отсутствуют антицепи

Пояснение:
**Ответ:** Она дистрибутивна, ограничена (имеет 0 и 1) и каждый элемент имеет дополнение.

Булева решётка (булева алгебра) — это дистрибутивная решётка с нулём и единицей, в которой для каждого элемента $x$ существует дополнение $\overline{x}$ такое, что $x \wedge \overline{x} = 0$ и $x \vee \overline{x} = 1$.


## 10

Функция $f: A \to B$ называется инъективной (инъекцией), если:

- ( ) Каждый элемент множества $B$ имеет хотя бы один прообраз
- (x) Различные элементы множества $A$ имеют различные образы: $\forall x_1, x_2 \; (x_1 \ne x_2 \implies f(x_1) \ne f(x_2))$
- ( ) $f(A) = B$
- ( ) $|A| \ge |B|$

Пояснение:
**Ответ:** $\forall x_1, x_2 \; (x_1 \ne x_2 \implies f(x_1) \ne f(x_2))$.

Инъективность означает отсутствие «склеиваний» разных элементов. Условие $f(A) = B$ определяет сюръекцию, а сочетание инъекции и сюръекции дает биекцию.


# Блок 2. Краткий ответ

## 11

Найдите число Белла $B_4$ — количество всевозможных отношений эквивалентности на множестве из 4 элементов.

Ответ: 15
Формат: целое число

Пояснение:
**Ответ:** 15.

$B_4 = \sum_{k=1}^4 \left\{ \begin{matrix} 4 \\ k \end{matrix} \right\} = \left\{ \begin{matrix} 4 \\ 1 \end{matrix} \right\} + \left\{ \begin{matrix} 4 \\ 2 \end{matrix} \right\} + \left\{ \begin{matrix} 4 \\ 3 \end{matrix} \right\} + \left\{ \begin{matrix} 4 \\ 4 \end{matrix} \right\} = 1 + 7 + 6 + 1 = 15$.


## 12

На множестве $\mathbb{Z}$ задано отношение эквивалентности: $a \equiv b \pmod 5$. Сколько элементов содержит фактор-множество $\mathbb{Z} / \equiv$?

Ответ: 5
Формат: целое число

Пояснение:
**Ответ:** 5.

Классами эквивалентности являются классы вычетов по модулю 5: $[0], [1], [2], [3], [4]$. Их ровно 5.


## 13

Дано ЧУМ делителей числа 30: $D_{30} = \{1, 2, 3, 5, 6, 10, 15, 30\}$ с отношением делимости $a \mid b$. Найдите значение $\inf\{6, 15\}$.

Ответ: 3
Формат: целое число

Пояснение:
**Ответ:** 3.

Точная нижняя грань (инфимум) в отношении делимости — это наибольший общий делитель: $\inf(6, 15) = \text{НОД}(6, 15) = 3$.


## 14

Сколько различных биективных отображений существует между двумя множествами мощности 4?

Ответ: 24
Формат: целое число

Пояснение:
**Ответ:** 24.

Число биекций между множествами из $n$ элементов равно $n!$. Для $n = 4$: $4! = 4 \times 3 \times 2 \times 1 = 24$.


## 15

Сколько ребер содержит диаграмма Хассе для булеана двухэлементного множества $\mathcal{P}(\{a, b\})$ с отношением включения $\subseteq$?

Ответ: 4
Формат: целое число

Пояснение:
**Ответ:** 4.

Булеан содержит $2^2 = 4$ подмножества: $\varnothing, \{a\}, \{b\}, \{a, b\}$.
Пары непосредственного покрытия: $\varnothing \lessdot \{a\}$, $\varnothing \lessdot \{b\}$, $\{a\} \lessdot \{a, b\}$, $\{b\} \lessdot \{a, b\}$. Итого 4 ребра, образующих квадрат (ромб).


## 16

Какова длина максимальной цепи (количество элементов в цепи) в ЧУМ $\mathcal{P}(\{1, 2, 3\})$ по отношению $\subseteq$?

Ответ: 4
Формат: целое число

Пояснение:
**Ответ:** 4.

Максимальная цепь строится последовательным добавлением по одному элементу: $\varnothing \subset \{1\} \subset \{1, 2\} \subset \{1, 2, 3\}$. В этой цепи 4 элемента. Длина цепи в терминах числа элементов равна $n + 1 = 3 + 1 = 4$.


# Блок 3. Несколько верных вариантов

## 17

Какие из перечисленных отношений являются отношениями эквивалентности?

- [x] Отношение параллельности прямых на плоскости (считая, что прямая параллельна сама себе)
- [x] Отношение равенства остатков при делении на 7 на множестве целых чисел
- [ ] Отношение делимости $a \mid b$ на множестве натуральных чисел
- [ ] Отношение строгого неравенства $x < y$ на $\mathbb{R}$
- [x] Отношение равенства длин двух слов в алфавите $\{0, 1\}$

Пояснение:
**Ответ:** Параллельность прямых; равенство остатков по модулю 7; равенство длин слов.

Все три указанных отношения рефлексивны, симметричны и транзитивны. Делимость $a \mid b$ не является симметричной ($2 \mid 4$, но $4 \nmid 2$), а отношение $<$ антирефлексивно и асимметрично.


## 18

Какие из перечисленных отношений являются частичными порядками (нестрогими)?

- [x] Отношение включения множеств $A \subseteq B$ на булеане $\mathcal{P}(X)$
- [x] Отношение делимости $a \mid b$ на множестве натуральных чисел $\mathbb{N}$
- [ ] Отношение перпендикулярности прямых на плоскости
- [x] Отношение нестрогого неравенства $x \le y$ на $\mathbb{R}$
- [ ] Отношение сравнимости по модулю 3 на $\mathbb{Z}$

Пояснение:
**Ответ:** Включение множеств $A \subseteq B$; делимость на $\mathbb{N}$; $x \le y$ на $\mathbb{R}$.

Все три удовлетворяют рефлексивности, антисимметричности и транзитивности. Сравнимость по модулю 3 симметрична (эквивалентность), а перпендикулярность антирефлексивна и не транзитивна.


## 19

Какие свойства справедливы для диаграммы Хассе конечного ЧУМ?

- [x] Петли при вершинах не изображаются
- [x] Транзитивные ребра опускаются
- [x] Вершина $y$ размещается выше вершины $x$, если $x \lessdot y$
- [ ] Между любыми двумя несравнимыми элементами проводится горизонтальное ребро
- [x] Ребра диаграммы соединяют только пары непосредственного покрытия

Пояснение:
**Ответ:** Петли не изображаются; транзитивные ребра опускаются; $y$ выше $x$ при $x \lessdot y$; ребра соединяют только пары непосредственного покрытия.

Диаграмма Хассе минимизирует изображение, устраняя избыточные ребра (петли и транзитивные хорды). Несравнимые элементы ребрами не соединяются.


## 20

Какие утверждения о решётках являются верными?

- [x] Всякая линейно упорядоченная цепь является дистрибутивной решёткой
- [x] В любой решётке операции $\wedge$ и $\vee$ коммутативны, ассоциативны и идемпотентны
- [x] Булеан $\mathcal{P}(X)$ с операциями $\cap$ и $\cup$ образует булеву решётку
- [ ] В любой решётке обязательно существует наименьший и наибольший элемент
- [x] Операции $\wedge$ и $\vee$ удовлетворяют законам поглощения: $a \wedge (a \vee b) = a$

Пояснение:
**Ответ:** Всякая цепь — дистрибутивная решётка; операции коммутативны, ассоциативны, идемпотентны; булеан — булева решётка; выполнены законы поглощения.

Бесконечные решётки (например, $(\mathbb{Z}, \le)$) не обязательно имеют наименьший или наибольший элемент, поэтому общее утверждение о наличии 0 и 1 неверно. Все остальные свойства — классические теоремы алгебры решёток.


## 21

Дано множество $A = \{1, 2, 3\}$ и функция $f: A \to A$. В каких случаях функция $f$ является биекцией?

- [x] $f(1)=2, f(2)=3, f(3)=1$
- [ ] $f(1)=1, f(2)=1, f(3)=2$
- [x] $f(1)=3, f(2)=2, f(3)=1$
- [ ] $f(1)=2, f(2)=2, f(3)=3$
- [x] $f(1)=1, f(2)=2, f(3)=3$

Пояснение:
**Ответ:** $f = \{(1,2),(2,3),(3,1)\}$; $f = \{(1,3),(2,2),(3,1)\}$; $f = \{(1,1),(2,2),(3,3)\}$.

Для конечного множества функция из $A$ в $A$ биективна тогда и только тогда, когда все образы попарно различны (перестановка элементов). В двух других вариантах образ не содержит одного из элементов (отсутствуют сюръекция и инъекция).


## 22

Какие из следующих утверждений о разбиениях и эквивалентностях верны?

- [x] Блоки разбиения попарно не пересекаются
- [x] Объединение всех блоков разбиения совпадает с исходным множеством
- [ ] Один элемент может принадлежать двум различным классам эквивалентности
- [x] Отношение равенства на $A$ порождает разбиение на одноэлементные блоки
- [x] Универсальное отношение $A \times A$ порождает разбиение, состоящее из единственного блока $A$

Пояснение:
**Ответ:** Блоки попарно не пересекаются; их объединение дает все множество; равенство дает одноэлементные блоки; универсальное отношение дает один блок.

Классы эквивалентности никогда не пересекаются, если они различны: $[a] \cap [b] \ne \varnothing \implies [a] = [b]$. Поэтому элемент не может принадлежать двум разным классам.
