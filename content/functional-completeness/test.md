# Блок 1. Один верный вариант

## 1

Какой из векторов задаёт штрих Шеффера $A\mid B$?

- ( ) $1000$
  > Единица только на $00$ соответствует стрелке Пирса.
- (x) $1110$
- ( ) $1101$
  > Единственный ноль на $10$ соответствует прямой импликации.
- ( ) $0001$
  > Единица только на $11$ соответствует конъюнкции.

Подсказка: На каком наборе конъюнкция равна единице? Инвертируйте её значение в каждой строке.

Пояснение:
**Ответ:** $1110$.

> **ФП, слайд 2.**

Штрих Шеффера — отрицание конъюнкции. На $00$, $01$ и $10$ конъюнкция равна нулю, поэтому штрих даёт единицу. На $11$ он даёт ноль.


## 2

В функции $A\to B$ вместо $B$ записали $A$ и получили $A\to A$. Как называется выполненная операция?

- ( ) Отрицание функции
  > При отрицании поменялись бы значения во всех строках таблицы.
- ( ) Замыкание множества функций
  > Замыкание включает все функции, выразимые над множеством. Здесь выполнена одна операция с аргументами.
- ( ) Построение полинома Жегалкина
  > В записи по-прежнему стоит импликация.
- (x) Отождествление переменных

Подсказка: Сколько независимых аргументов осталось в записи?

Пояснение:
**Ответ:** Отождествление переменных.

> **ФП, слайды 2–4. Л10, слайды 51–55.**

На оба места подали один аргумент. Из таблицы импликации теперь используются только строки $00$ и $11$, в обеих результат равен единице.


## 3

В формуле $f(A,B)=A\land B$ на место второго аргумента подставляют значение $g(B,C)=B\lor C$. Какая запись получается до упрощений?

- (x) $A\land(B\lor C)$
- ( ) $(A\lor C)\land B$
  > Эта запись заменяет первый аргумент конъюнкции.
- ( ) $(A\land B)\lor C$
  > Здесь значение $f$ подставлено в дизъюнкцию. В условии задан обратный порядок.
- ( ) $A\land A$
  > Здесь переменные отождествлены, а значение $g$ вообще не используется.

Подсказка: Запишите $f(A,\square)$ и заполните свободное место значением $g$.

Пояснение:
**Ответ:** $A\land(B\lor C)$.

> **ФП, слайды 2–3. Л10, слайды 53–56.**

Внешняя функция остаётся конъюнкцией. Первый аргумент сохраняется, а второй целиком заменяется выражением $B\lor C$.


## 4

Как в лекции определяется ранг суперпозиции относительно исходного множества функций?

- ( ) Число различных переменных в полученной функции
  > Это характеристика аргументов. Одну и ту же переменную можно использовать несколько раз.
- ( ) Число строк таблицы истинности полученной функции
  > Число строк определяется количеством аргументов.
- (x) Минимальное число подстановок и отождествлений, достаточное для получения этой суперпозиции
- ( ) Число операций в любом выбранном способе её получения
  > Два способа могут иметь разную длину. Произвольная запись даёт лишь верхнюю границу ранга.

Подсказка: Как выбрать число, если одну суперпозицию удалось получить двумя разными способами?

Пояснение:
**Ответ:** Минимальное число подстановок и отождествлений.

> **Л10, слайды 56–57.**

Чтобы установить ранг, нужно указать способ получения и обосновать, почему меньшего числа шагов недостаточно.


## 5

Какое множество обозначают $[A]$?

- ( ) Только функции, полученные из $A$ ровно одной подстановкой
  > В формулах над $A$ подстановки разрешено повторять.
- (x) Множество всех функций, выразимых формулами над $A$
- ( ) Наибольшее замкнутое множество, содержащее $A$
  > Такое описание всегда подходило бы множеству всех булевых функций. Для $[A]$ существенно минимальное включение.
- ( ) Множество всех булевых функций при любом $A$
  > Такое равенство служит признаком полноты конкретной системы.

Подсказка: Если после одной подстановки получена новая функция, можно ли использовать результат в следующей формуле?

Пояснение:
**Ответ:** Все функции, выразимые над $A$.

> **ФП, слайды 6–8. Пост, слайды 2–3.**

Замкнутое множество, содержащее $A$, обязано содержать и каждую такую суперпозицию. Поэтому $[A]$ — наименьшее по включению замкнутое множество, содержащее $A$.


## 6

Установили, что система $F$ полна. Какое дополнительное условие означает, что она безызбыточна?

- ( ) Хотя бы одну функцию можно удалить с сохранением полноты
  > Именно такую функцию и называют лишней для полноты этой системы.
- ( ) В системе ровно одна функция
  > Одноэлементные базисы есть, но определение допускает и несколько необходимых функций.
- ( ) Хотя бы после одного удаления полнота теряется
  > В системе с лишней функцией тоже может найтись необходимая функция.
- (x) После удаления любой одной функции полнота теряется

Подсказка: Какой квантор нужен при проверке каждой функции системы?

Пояснение:
**Ответ:** Каждая функция должна быть необходима.

> **ФП, слайд 9. Л11, слайд 42.**

Для каждого $f\in F$ проверяют систему $F\setminus\{f\}$. Одного удаления, при котором полнота сохранилась, достаточно для вывода об избыточности.


## 7

На каком наблюдении основана проверка самодвойственности по таблице истинности?

- (x) На каждой паре покоординатно противоположных наборов значения функции противоположны
- ( ) На любых двух различных наборах значения функции противоположны
  > Например, для $A$ наборы $00$ и $01$ различны, но у них одинаковый первый аргумент. При этом функция $A$ самодвойственна.
- ( ) На нулевом наборе значение обязательно равно нулю
  > Отрицание переменной самодвойственно и на нуле даёт единицу.
- ( ) Достаточно проверить только первую и последнюю строки при любом числе аргументов
  > При двух аргументах остаётся ещё пара $01$ и $10$.

Подсказка: Для набора $010$ постройте пару, изменив каждую координату.

Пояснение:
**Ответ:** Для каждого $\alpha$ должно выполняться $f(\bar\alpha)=\overline{f(\alpha)}$.

> **ФП, слайд 10. Л11, слайды 10–13.**

Так, строку $010$ сравнивают со строкой $101$. Одна пара с одинаковыми значениями опровергает самодвойственность.


## 8

Какой признак по полиному Жегалкина показывает, что функция принадлежит классу $L$?

- ( ) Свободный коэффициент равен нулю
  > У конъюнкции свободный коэффициент тоже нулевой, хотя в полиноме есть произведение $AB$.
- ( ) Все коэффициенты равны нулю или единице
  > Это верно для любого полинома Жегалкина.
- (x) После приведения подобных слагаемых нет произведений двух и более различных переменных
- ( ) Каждая переменная встречается хотя бы в одном слагаемом
  > Конъюнкция $AB$ использует обе переменные и при этом нелинейна.

Подсказка: Сравните слагаемые $A$, $B$ и $AB$. Какое из них меняет степень полинома?

Пояснение:
**Ответ:** Степень каждого непостоянного слагаемого не выше единицы.

> **ФП, слайд 11. Л11, слайды 15–17. Л10, слайды 18–19.**

В обозначениях лекции свободный член $1$ допускается, поэтому $\neg A=1\oplus A$ принадлежит $L$.


## 9

В таблице для $f(A,B,C)$ дан вектор $10101001$. Какая пара строк доказывает, что $f$ немонотонна?

- ( ) $001$ и $010$
  > При переходе вторая координата растёт, а третья убывает. Эти наборы несравнимы.
- (x) $000$ и $001$
- ( ) $110$ и $111$
  > Значение растёт с $0$ до $1$. Это согласуется с монотонностью.
- ( ) $000$ и $111$
  > Значения равны единице на обоих концах. Равенство допускается.

Подсказка: Найдите переход, на котором увеличилась одна координата, а значение функции упало.

Пояснение:
**Ответ:** $000\leq001$, но $f(000)=1$ и $f(001)=0$.

> **Л11, слайды 19, 24, 33.**

Для монотонности нужно $f(\alpha)\leq f(\beta)$ при каждой паре $\alpha\leq\beta$. Одного нарушения достаточно.


## 10

Какой из признаков в КНФ гарантирует, что функция сохраняет единицу? Рассматриваются КНФ из дизъюнкций литералов.

- ( ) Хотя бы в одной дизъюнкции есть неинверсная переменная
  > На единичном наборе это даст единицу лишь в одной скобке. Остальные тоже должны дать единицу.
- ( ) Все переменные входят только с отрицанием
  > На единичном наборе каждый такой литерал равен нулю.
- ( ) В каждой дизъюнкции есть хотя бы одна инверсная переменная
  > Инверсный литерал на единичном наборе равен нулю и не обеспечивает истинность скобки.
- (x) В каждой дизъюнкции есть хотя бы одна неинверсная переменная

Подсказка: Подставьте единицы во все переменные. Когда конъюнкция скобок сохранит значение $1$?

Пояснение:
**Ответ:** В каждой скобке нужен хотя бы один положительный литерал.

> **ФП, слайд 14. Л11, слайд 29.**

Он принимает значение $1$ на единичном наборе, поэтому каждая скобка и вся КНФ равны $1$.


## 11

В таблице Поста «+» означает принадлежность функции классу, «−» — непринадлежность. Какой признак равносилен полноте системы?

- ( ) В каждой строке есть хотя бы один «−»
  > Так каждая функция нарушает какое-то свойство, но остальные могут все вместе сохранять, например, ноль.
- (x) В каждом из пяти столбцов есть хотя бы один «−»
- ( ) Есть строка из пяти «−»
  > Такая строка достаточна, но полная система может нарушать пять свойств разными функциями.
- ( ) В каждом столбце есть хотя бы один «+»
  > Знак «+» подтверждает принадлежность отдельной функции классу. Критерий требует найти выход системы из каждого класса.

Подсказка: Для каждого класса задайте вопрос «Все ли функции системы лежат в этом классе?».

Пояснение:
**Ответ:** В каждом столбце нужен хотя бы один «−».

> **Пост, слайды 7–9. Л11, слайды 31, 59–60.**

Все плюсы в одном столбце означали бы, что система целиком лежит в соответствующем замкнутом классе. Тогда любая суперпозиция тоже останется в нём.


## 12

В доказательстве достаточности критерия Поста уже получены константы $0$ и $1$. Какую функцию берут на следующем шаге, чтобы выразить отрицание?

- (x) Немонотонную
- ( ) Несамодвойственную
  > Это свойство используют при получении констант. Оно само по себе не обеспечивает убывания на сравнимых наборах.
- ( ) Нелинейную
  > Её используют на следующем этапе, когда отрицание уже получено.
- ( ) Любую сохраняющую ноль
  > В этом классе есть монотонная конъюнкция. Подстановка констант в неё не даёт отрицания.

Подсказка: Как ведёт себя отрицание при переходе от $0$ к $1$?

Пояснение:
**Ответ:** Немонотонную функцию.

> **Пост, слайды 10–12. Л11, слайды 70–74.**

Между сравнимыми наборами со значениями $1$ и $0$ найдётся шаг, на котором меняется одна координата и значение падает. Фиксируем остальные координаты константами. Остаётся функция одной переменной со значениями $1,0$, то есть отрицание.


## 13

У частично определённой функции $f(A,B,C)$ вектор $({*},{*},0,1,0,1,{*},1)$. Какое из доопределений совпадает с третьим аргументом $C$?

- ( ) $00010101$
  > Строка $001$ требует значения $C=1$, а здесь стоит $0$.
- ( ) $01010111$
  > На наборе $110$ получилось бы $1$, хотя $C=0$.
- ( ) $11010101$
  > На наборе $000$ получилось бы $1$, хотя $C=0$.
- (x) $01010101$

Подсказка: Выпишите третий бит каждого набора от $000$ до $111$.

Пояснение:
**Ответ:** $01010101$.

> **Л11, слайды 43, 48–52. Пост, слайд 14.**

Звёздочки стоят в строках $000$, $001$, $110$. Подставляем туда соответственно $0,1,0$. В остальных пяти строках заданные значения уже совпадают с $C$. Это даёт и простейшую ДНФ для такого доопределения: один литерал $C$. Строки $010$ и $011$ имеют разные заданные значения, поэтому заменить этот литерал константой нельзя.


# Блок 2. Краткий ответ

## 14

Если любая суперпозиция функций множества $A$ снова лежит в $A$, то $A$ называют ______ множеством.

Формат: Одно слово в творительном падеже.
Ответ: замкнутым
Если ответ полным: Для полноты нужно уметь выразить любую булеву функцию. В условии сказано только, что суперпозиции остаются в $A$.

Подсказка: Какое свойство записывают равенством $[A]=A$?

Пояснение:
**Ответ:** Замкнутым.

> **ФП, слайды 6–8. Пост, слайды 2–3.**

По определению $[A]$ содержит все суперпозиции над $A$. Если они уже принадлежат $A$, замыкание совпадает с исходным множеством.


## 15

Сколько самодвойственных функций трёх аргументов существует?

Формат: Целое число.
Ответ: 16
Если ответ 4: Четыре — число пар противоположных наборов. В каждой паре есть два выбора значения первой строки.
Если ответ 128: Столько функций получится, если зафиксировать одну строку. Самодвойственность связывает все четыре пары строк.

Подсказка: Если известно $f(010)$, сколько вариантов остаётся для $f(101)$?

Пояснение:
**Ответ:** $16$.

> **ФП, слайд 10. Л11, слайды 10–13.**

Восемь наборов образуют четыре пары: $000/111$, $001/110$, $010/101$, $011/100$. Один бит в каждой паре выбираем свободно, другой восстанавливаем. Для $n\geq1$ аргументов получается $2^{2^{n-1}}$ функций.


## 16

Сколько линейных функций трёх аргументов есть при принятом в лекции определении класса $L$?

Формат: Целое число.
Ответ: 16
Если ответ 8: Помимо коэффициентов при трёх переменных есть свободный коэффициент.

Подсказка: Запишите все возможные места для коэффициентов в линейном полиноме.

Пояснение:
**Ответ:** $16$.

> **ФП, слайд 11. Л11, слайды 15–17. Л10, слайд 27.**

Полином имеет вид $a_0\oplus a_1A\oplus a_2B\oplus a_3C$. Четыре независимых коэффициента дают $2^4$ вариантов. Разные наборы коэффициентов задают разные функции по единственности полинома. Для $n$ аргументов число равно $2^{n+1}$.


## 17

Сколько функций трёх аргументов сохраняют ноль? При подсчёте допускаются и те, которые одновременно сохраняют единицу.

Формат: Целое число.
Ответ: 128
Если ответ 64: При сохранении только нуля значение $f(111)$ остаётся свободным.

Подсказка: Сколько из восьми строк таблицы фиксирует условие $f(000)=0$?

Пояснение:
**Ответ:** $128$.

> **ФП, слайды 14–15. Л11, слайды 29–30.**

Одна строка фиксирована, в остальных семи значение выбирают независимо. По той же причине ровно $128$ функций сохраняют единицу. Для каждого из двух классов число функций от $n$ аргументов равно $2^{2^n-1}$.


## 18

Функция $f(A,B,C)$ сохраняет единицу. Каков индекс минтерма, который обязательно присутствует в её СДНФ? Нумерация начинается с нуля.

Формат: Целое число.
Ответ: 7
Если ответ 8: Строк всего восемь, но первая имеет индекс $0$.
Если ответ 0: Нулевой индекс соответствует набору $000$. Для сохранения единицы нужен набор $111$.

Подсказка: Запишите единичный набор как двоичное число.

Пояснение:
**Ответ:** $7$.

> **ФП, слайд 14. Л11, слайд 29.**

СДНФ содержит минтерм для каждой единичной строки. На наборе $111$ функция обязана принимать значение $1$, поэтому минтерм $ABC$ с индексом $2^3-1=7$ обязательно входит в СДНФ.


## 19

Вектор штриха Шеффера равен $1110$. Выпишите вектор функции $g(A)=A\mid A$ после отождествления аргументов.

Формат: Две цифры подряд в порядке $A=0,1$.
Ответ: 10
Если ответ 01: Это вектор самой переменной. Проверьте значение $0\mid0$.

## 27

Какие равенства верны в алгебре Жегалкина для любых булевых $A,B,C$?

- [x] $A\oplus A=0$
  > Одинаковые биты в сумме по модулю два дают ноль.
- [ ] $A\oplus(BC)=(A\oplus B)(A\oplus C)$
  > При $A=1,B=0,C=1$ слева единица, справа произведение $1\cdot0=0$.
- [x] $A(B\oplus C)=AB\oplus AC$
  > Это дистрибутивность конъюнкции относительно сложения по модулю два.
- [x] $1\oplus A=\neg A$
  > При $A=0$ получается $1$, а при $A=1$ получается $0$.

Подсказка: В двух равенствах со скобками раскрываются разные операции. Проверьте, какую дистрибутивность даёт лекция.

Пояснение:
**Ответ:** Первое, третье и четвёртое равенства.

> **Л10, слайды 11–13, 18.**

Конъюнкция распределяется относительно XOR. Обратное правило нарушается уже на наборе $101$. Равенство $A\oplus A=0$ позволяет сокращать одинаковые слагаемые при приведении полинома.


## 28

Какие утверждения о построении полинома Жегалкина верны?

- [ ] В любой ДНФ можно просто заменить все знаки дизъюнкции на $\oplus$
  > Если два терма одновременно дают единицу, дизъюнкция равна единице, а их XOR равен нулю. Например, это происходит для $A\lor B$ на $11$.
- [x] При преобразовании СДНФ дизъюнкцию разных минтермов можно заменить их суммой по модулю два
  > Два различных полных минтерма не могут одновременно дать единицу.
- [x] В методе неопределённых коэффициентов подстановка наборов из таблицы даёт уравнения для коэффициентов
  > Для каждого набора значение общего полинома приравнивают известному значению функции.
- [ ] Треугольник и метод Паскаля могут дать разные приведённые полиномы одной функции
  > Каждая булева функция имеет единственный полином Жегалкина после приведения подобных слагаемых.

Подсказка: Сравните ситуацию, когда могут одновременно сработать два терма, с ситуацией в СДНФ.

Пояснение:
**Ответ:** Верны утверждения о СДНФ и неопределённых коэффициентах.

> **Л10, слайды 12–13, 27–29, 37–49.**

При преобразовании произвольной ДНФ для двух выражений используют $u\lor v=u\oplus v\oplus uv$. Для разных минтермов СДНФ произведение $uv$ тождественно равно нулю. Все четыре метода лекции приводят к одному полиному.

Почему полином единственен? Если бы два приведённых полинома одной функции различались, их сумма по модулю два была бы тождественным нулём с ненулевыми коэффициентами. Возьмём в ней слагаемое с наименьшим числом переменных. Присвоим этим переменным единицы, остальным — нули. Выбранное слагаемое даст единицу, а каждое другое содержит хотя бы одну переменную, равную нулю. Получили противоречие.

Выберите утверждения, которые следуют из определения замыкания.

- [x] $A\subseteq[A]$

## 30

Какие утверждения о монотонных функциях верны?

- [ ] Из $01<10$ при сравнении как двоичных чисел следует $f(01)\leq f(10)$
  > Для монотонности сравнивают координаты. В паре $01$, $10$ одна координата растёт, другая убывает.

  > Любую сравнимую пару соединяет цепочка таких переходов. Если убывания нет на каждом шаге, его нет и между концами.

  > Именно так сформулирован признак для ДНФ в лекции. Аналогичное утверждение дано для КНФ.

**Ответ:** Верны проверка по всем одношаговым переходам и утверждение о минимальной ДНФ.

> **ФП, слайды 2, 12–13. Л11, слайды 19–27.**

Числовой порядок строк не заменяет покоординатный. Проверка только крайних значений может пропустить убывание внутри таблицы.


## 31

## 35

Какие утверждения объясняют необходимость и достаточность условий теоремы Поста?

- [x] В доказательстве достаточности константы получают с помощью функций, нарушающих сохранение нуля, сохранение единицы и самодвойственность
  > На этом этапе все аргументы функции можно отождествлять. Если получено отрицание, его используют для подстановки противоположных значений.

Подсказка: Для необходимости выясните, что сохраняют суперпозиции. Для достаточности вспомните, зачем строят булев базис.

Пояснение:
**Ответ:** Верны утверждения о замкнутости класса и о получении констант.

> **Пост, слайды 9–11. Л11, слайды 59–69.**

При нарушении сохранения нуля диагональ $f(x,\ldots,x)$ равна либо $1$, либо $\neg x$. При нарушении сохранения единицы получаются либо $0$, либо $\neg x$. Если обе диагонали дают отрицание, у несамодвойственной функции выбирают противоположные наборы с одинаковым значением. Подстановка $x$ и $\neg x$ в нужные позиции даёт одну константу, её отрицание — вторую.


## 36

Какие из перечисленных полиномов двух переменных можно превратить в $AB$, если разрешается только оставить результат как есть или один раз его инвертировать?

- [x] $AB$
  > Конъюнкция уже выражена.
- [ ] $A\oplus B$
  > У полинома нет произведения. При отрицании добавится только свободный член $1$.
- [x] $1\oplus AB$
  > Отрицание добавляет вторую единицу. Они сокращаются, и остаётся $AB$.
- [ ] $A\oplus B\oplus AB$
  > Это дизъюнкция. Отрицание результата оставит линейные слагаемые $A$ и $B$ в полиноме.

Подсказка: Какой коэффициент меняется при отрицании всего полинома?

Пояснение:
**Ответ:** Подходят $AB$ и $1\oplus AB$.

> **ФП, слайд 2. Л10, слайды 11–13, 18. Пост, слайд 13. Л11, слайды 75–79.**

Отрицание всего результата меняет только свободный коэффициент. Например, у штриха Шеффера полином $1\oplus AB$, поэтому отрицание результата даёт конъюнкцию. Для других нелинейных форм в общем доказательстве доступны и отрицания аргументов. Это видно из записи $h(x,y)=xy\oplus ax\oplus by\oplus c$, где $a,b,c$ — биты. Раскрывая скобки, получаем $h(x,y)=(x\oplus b)(y\oplus a)\oplus ab\oplus c$. Поэтому достаточно инвертировать первый вход при $b=1$, второй при $a=1$ и результат при $ab\oplus c=1$, чтобы получить $xy$.


## 37

Дан вектор $({*},{*},0,1,0,1,{*},1)$ в порядке $000,\ldots,111$. Доопределения в разных вариантах можно выбирать независимо. Какие утверждения верны?

- [x] Функцию можно доопределить до монотонной
  > Если заполнить строки $000,001,110$ значениями $0,1,0$, получится проекция $C$.
- [ ] Каждое доопределение сохраняет ноль
  > Первая строка свободна. В неё разрешено поставить единицу.
- [x] Каждое доопределение сохраняет единицу
  > Значение в последней строке задано изначально и равно $1$.
- [ ] Любое доопределение самодвойственно
  > Если поставить $1$ в строку $000$, то на противоположных наборах $000$ и $111$ будут две единицы.

Подсказка: Различайте «можно подобрать заполнение» и «верно при каждом заполнении». Какие строки уже зафиксированы?

Пояснение:
**Ответ:** Существует монотонное доопределение, и все доопределения сохраняют единицу.

> **Л11, слайды 10–13, 24, 29–30, 43, 48–52.**

Свободная первая строка позволяет как сохранить ноль, так и нарушить его сохранение. Один и тот же выбор $f(000)=1$ опровергает обязательную самодвойственность.


## 38

Система состоит из одной импликации $A\to B$. Какие функции можно добавить по одной, чтобы получить полную систему?

- [x] Константу $0$
  > При $B=0$ получаем $A\to0=\neg A$. Тогда $(A\to0)\to B=A\lor B$, а из отрицания и дизъюнкции выражается конъюнкция.
- [ ] Константу $1$
  > Обе функции сохраняют единицу. Поэтому вся система лежит в $T_1$.
- [ ] Конъюнкцию $A\land B$
  > На наборе $11$ обе функции дают единицу. Их суперпозиции тоже сохраняют единицу.
- [x] Отрицание $\neg A$
  > Импликация и отрицание выражают дизъюнкцию по формуле $(\neg A)\to B=A\lor B$. Этого достаточно для получения булева базиса.

Подсказка: Заполните строку импликации в таблице Поста. Какое из пяти свойств должна нарушать добавленная функция?

Пояснение:
**Ответ:** константу $0$ или отрицание.

> **ФП, слайды 2, 10–15. Пост, слайды 7–9.**

Вектор импликации $1101$. Функция выходит из $T_0$ на наборе $00$, из $S$ — на паре $00/11$, из $M$ — на переходе $00\to10$. Её полином $1\oplus A\oplus AB$ показывает выход из $L$. Остаётся только $T_1$. Поэтому для полноты достаточно добавить любую функцию, которая на единичном наборе даёт ноль.

## 39

Пусть $F=\{f,\neg\}$, где $f(A,B,C)$ задана вектором $10101001$. Какие выводы о системе и её подсистемах верны?

- [ ] $\{f\}$ полна
  > $f(111)=1$, поэтому вся одноэлементная система лежит в $T_1$.
- [x] $F$ полна
  > Функция $f$ выходит из $S,L,M,T_0$, а отрицание выходит из $T_1$.
- [x] После удаления $f$ полнота теряется
  > Остаётся отрицание с линейным полиномом $1\oplus A$. Все его суперпозиции лежат в $L$.
- [ ] После удаления отрицания полнота сохраняется, поскольку $f$ нелинейна
  > Нелинейность выводит систему только из $L$. Оставшаяся функция сохраняет единицу.
- [x] $F$ безызбыточна
  > Исходная пара полна. При удалении любой из двух функций возникает класс, содержащий всю оставшуюся систему.

Подсказка: Заполните строки $f$ и $\neg$ в таблице Поста. Затем закройте по одной строке и повторите проверку.

Пояснение:
**Ответ:** Система полна и безызбыточна. Без $f$ полнота теряется.

> **Л11, слайды 10–17, 24, 29–33, 42. ФП, слайд 9. Пост, слайды 7–9.**

| Функция | $S$ | $L$ | $M$ | $T_0$ | $T_1$ |
|---|---|---|---|---|---|
| $f$ | − | − | − | − | + |
| $\neg$ | + | + | − | − | − |

Функция $f$ несамодвойственна на паре $000/111$, немонотонна на переходе $000\to001$, не сохраняет ноль, а в её полиноме есть $AB$. Единственное из пяти свойств, которое она сохраняет, — единицу. Отрицание нарушает и это свойство. При удалении $f$ остаётся линейная функция, при удалении отрицания — функция из $T_1$.
