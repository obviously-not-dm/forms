# Блок 1. Один верный вариант

## 1

Каков порядок рекуррентного соотношения $a_n = 5a_{n-1} - 6a_{n-3} + n^2$?

- ( ) 1
- ( ) 2
- (x) 3
- ( ) 4

Пояснение:
**Ответ:** 3.

Порядок рекуррентного соотношения определяется максимальной разностью индексов между выражаемым членом $a_n$ и самым ранним предшествующим членом в правой части. Здесь самым ранним является $a_{n-3}$, следовательно, порядок $p = n - (n - 3) = 3$.


## 2

Какое характеристическое уравнение соответствует линейному однородному рекуррентному соотношению $a_n - 5a_{n-1} + 6a_{n-2} = 0$?

- ( ) $r^2 + 5r - 6 = 0$
- (x) $r^2 - 5r + 6 = 0$
- ( ) $r^2 - 6r + 5 = 0$
- ( ) $r^3 - 5r^2 + 6r = 0$

Пояснение:
**Ответ:** $r^2 - 5r + 6 = 0$.

При замене $a_n = r^n$ получаем $r^n - 5r^{n-1} + 6r^{n-2} = 0$. Деля обе части на $r^{n-2}$, приходим к квадратному характеристическому уравнению $r^2 - 5r + 6 = 0$.


## 3

Характеристическое уравнение имеет корни $r_1 = 2$ и $r_2 = 3$. Каков общий вид решения $a_n$?

- ( ) $a_n = \lambda_1 \cdot 2 + \lambda_2 \cdot 3$
- ( ) $a_n = (\lambda_1 + \lambda_2 n) \cdot 6^n$
- (x) $a_n = \lambda_1 \cdot 2^n + \lambda_2 \cdot 3^n$
- ( ) $a_n = 2 \lambda_1^n + 3 \lambda_2^n$

Пояснение:
**Ответ:** $a_n = \lambda_1 \cdot 2^n + \lambda_2 \cdot 3^n$.

Для попарно различных корней характеристического уравнения общее решение представляется в виде линейной комбинации геометрических прогрессий от корней: $a_n = \sum \lambda_i r_i^n$.


## 4

Характеристическое уравнение второго порядка имеет единственный кратный корень $r_1 = r_2 = 4$ кратности 2. Как выглядит общее решение $a_n$?

- ( ) $a_n = \lambda_1 \cdot 4^n + \lambda_2 \cdot 4^n$
- ( ) $a_n = \lambda_1 \cdot 4^n + \lambda_2 \cdot n^4$
- (x) $a_n = (\lambda_1 + \lambda_2 n) \cdot 4^n$
- ( ) $a_n = \lambda_1 \cdot 4^n + \lambda_2 \cdot 4^{n-1}$

Пояснение:
**Ответ:** $a_n = (\lambda_1 + \lambda_2 n) \cdot 4^n$.

При наличии кратного корня $r_0$ кратности $m=2$ базис решений состоит из $r_0^n$ и $n r_0^n$. Их линейная комбинация дает $(\lambda_1 + \lambda_2 n) r_0^n$.


## 5

В каком случае при решении линейного неоднородного рекуррентного уравнения с правой частью $f(n) = P(n) s^n$ возникает явление резонанса?

- ( ) Когда степень многочлена $P(n)$ больше 2
- (x) Когда основание $s$ является корнем характеристического уравнения соответствующего однородного уравнения
- ( ) Когда начальные условия равны нулю
- ( ) Когда все корни характеристического уравнения действительные

Пояснение:
**Ответ:** Когда основание $s$ является корнем характеристического уравнения.

Если число $s$ совпадает с корнем характеристического уравнения кратности $m$, частное решение ищется в виде $a_n^* = n^m Q(n) s^n$. Домножение на $n^m$ устраняет линейную зависимость с общим решением однородного уравнения (резонанс).


## 6

Дано рекуррентное уравнение $T(n) = 2 T(n/2) + \Theta(n)$, описывающее сортировку слиянием (MergeSort). Какова его асимптотическая сложность по Мастер-теореме?

- ( ) $\Theta(n)$
- (x) $\Theta(n \log n)$
- ( ) $\Theta(n^2)$
- ( ) $\Theta(\log n)$

Пояснение:
**Ответ:** $\Theta(n \log n)$.

В соотношении $T(n) = a T(n/b) + f(n)$: $a = 2, b = 2$.
Критический показатель: $\log_b a = \log_2 2 = 1$, поэтому $n^{\log_b a} = n^1 = n$.
Так как $f(n) = \Theta(n) = \Theta(n^{\log_b a} \log^0 n)$, применим случай 2 Мастер-теоремы ($k=0$):
$T(n) = \Theta(n^{\log_b a} \log^{k+1} n) = \Theta(n \log n)$.


## 7

Дано рекуррентное соотношение $T(n) = T(n/2) + \Theta(1)$, соответствующее бинарному поиску. Какова его сложность?

- ( ) $\Theta(1)$
- (x) $\Theta(\log n)$
- ( ) $\Theta(n)$
- ( ) $\Theta(\sqrt{n})$

Пояснение:
**Ответ:** $\Theta(\log n)$.

Здесь $a = 1, b = 2 \implies \log_b a = \log_2 1 = 0 \implies n^0 = 1$.
$f(n) = \Theta(1) = \Theta(n^0)$, это случай 2 Мастер-теоремы при $k=0$, откуда $T(n) = \Theta(1 \cdot \log^1 n) = \Theta(\log n)$.


## 8

В алгоритме умножения матриц Штрассена задача размера $n \times n$ сводится к 7 подзадачам размера $(n/2) \times (n/2)$ с объединением за время $\Theta(n^2)$: $T(n) = 7 T(n/2) + \Theta(n^2)$. Какой случай Мастер-теоремы применяется?

- (x) Случай 1 ($f(n) = O(n^{\log_b a - \varepsilon})$)
- ( ) Случай 2 ($f(n) = \Theta(n^{\log_b a})$)
- ( ) Случай 3 ($f(n) = \Omega(n^{\log_b a + \varepsilon})$)
- ( ) Мастер-теорема неприменима

Пояснение:
**Ответ:** Случай 1.

$a = 7, b = 2 \implies \log_2 7 \approx 2.807$.
Функция $f(n) = n^2$. Поскольку $2 < 2.807$, выполнено $f(n) = O(n^{\log_2 7 - \varepsilon})$, где $\varepsilon \approx 0.807 > 0$.
Следовательно, работает случай 1: $T(n) = \Theta(n^{\log_2 7}) \approx \Theta(n^{2.807})$.


## 9

Какое условие регулярности необходимо проверить в случае 3 Мастер-теоремы для соотношения $T(n) = a T(n/b) + f(n)$?

- ( ) $a f(n/b) \ge f(n)$
- (x) $a f(n/b) \le c f(n)$ для некоторой константы $c < 1$ при достаточно больших $n$
- ( ) $f(n) = O(n)$
- ( ) $a \cdot b = 1$

Пояснение:
**Ответ:** $a f(n/b) \le c f(n)$ для некоторой константы $c < 1$.

В случае 3 основное время тратится на деление и склеивание на верхнем уровне дерева рекурсии. Чтобы гарантировать сходимость геометрической прогрессии затрат вниз по уровням, требуется $a f(n/b) \le c f(n)$ с $c < 1$.


## 10

Чему равно $a_2$, если последовательность задана соотношением $a_n = 3a_{n-1} - 2a_{n-2}$ при начальных условиях $a_0 = 1, a_1 = 4$?

- ( ) 7
- (x) 10
- ( ) 12
- ( ) 14

Пояснение:
**Ответ:** 10.

Подставляем $n = 2$:
$a_2 = 3 a_1 - 2 a_0 = 3 \cdot 4 - 2 \cdot 1 = 12 - 2 = 10$.


# Блок 2. Краткий ответ

## 11

Дано ЛОРС: $a_n - 4a_{n-1} + 3a_{n-2} = 0$. Корни характеристического уравнения $r_1 = 1, r_2 = 3$. При начальных условиях $a_0 = 10, a_1 = 16$, решение имеет вид $a_n = \lambda_1 + \lambda_2 \cdot 3^n$. Найдите значение константы $\lambda_2$.

Ответ: 3
Формат: целое число

Пояснение:
**Ответ:** 3.

Система начальных условий:
$\begin{cases} a_0 = \lambda_1 + \lambda_2 = 10 \\ a_1 = \lambda_1 + 3\lambda_2 = 16 \end{cases}$
Вычитая первое уравнение из второго: $2\lambda_2 = 6 \implies \lambda_2 = 3$. Тогда $\lambda_1 = 7$.
Формула общего члена: $a_n = 7 + 3 \cdot 3^n = 7 + 3^{n+1}$.


## 12

Найдите шестое число Фибоначчи $F_6$, если $F_0 = 0, F_1 = 1, F_2 = 1, F_3 = 2, F_4 = 3, F_5 = 5$.

Ответ: 8
Формат: целое число

Пояснение:
**Ответ:** 8.

$F_6 = F_5 + F_4 = 5 + 3 = 8$.


## 13

Дано уравнение $a_n = 2a_{n-1} + 1$ с начальным условием $a_0 = 0$. Вычислите $a_5$.

Ответ: 31
Формат: целое число

Пояснение:
**Ответ:** 31.

Последовательность задает задачу о Ханойских башнях: $a_n = 2^n - 1$.
Для $n = 5$: $a_5 = 2^5 - 1 = 32 - 1 = 31$.
Проверка по шагам: $a_0 = 0, a_1 = 1, a_2 = 3, a_3 = 7, a_4 = 15, a_5 = 31$.


## 14

Характеристическое уравнение имеет вид $r^2 - 6r + 9 = 0$. Какова кратность корня $r = 3$?

Ответ: 2
Формат: целое число

Пояснение:
**Ответ:** 2.

$r^2 - 6r + 9 = (r - 3)^2 = 0$. Единственный корень $r = 3$ имеет кратность 2.


## 15

Для соотношения $T(n) = 4 T(n/2) + n$ найдите критический показатель $\log_b a$.

Ответ: 2
Формат: целое число

Пояснение:
**Ответ:** 2.

Здесь $a = 4, b = 2$. Критический показатель равен $\log_2 4 = 2$.
Сравниваем $f(n) = n^1$ с $n^{\log_b a} = n^2$. Поскольку $1 < 2$, работает случай 1 Мастер-теоремы, давая $T(n) = \Theta(n^2)$.


## 16

Найдите корень характеристического уравнения для соотношения первого порядка $a_n = 5 a_{n-1}$.

Ответ: 5
Формат: целое число

Пояснение:
**Ответ:** 5.

Уравнение: $r - 5 = 0 \implies r = 5$. Решение имеет вид геометрической прогрессии $a_n = a_0 \cdot 5^n$.


# Блок 3. Несколько верных вариантов

## 17

Какие из следующих рекуррентных соотношений являются линейными однородными с постоянными коэффициентами?

- [x] $a_n = 3a_{n-1} - 2a_{n-2}$
- [ ] $a_n = a_{n-1} \cdot a_{n-2}$
- [x] $F_n = F_{n-1} + F_{n-2}$
- [ ] $a_n = n a_{n-1}$
- [x] $a_n = 7a_{n-1}$

Пояснение:
**Ответ:** $a_n = 3a_{n-1} - 2a_{n-2}$; $F_n = F_{n-1} + F_{n-2}$; $a_n = 7a_{n-1}$.

Первые три указанных соотношения линейны (нет произведений или степеней членов) и имеют постоянные коэффициенты. Соотношение $a_n = a_{n-1} a_{n-2}$ нелинейно, а $a_n = n a_{n-1}$ содержит переменный коэффициент $n$.


## 18

Какие утверждения о корнях характеристического уравнения $r^2 - c_1 r - c_2 = 0$ верны?

- [x] Если корни вещественны и различны ($D > 0$), общее решение имеет вид $a_n = \lambda_1 r_1^n + \lambda_2 r_2^n$
- [x] Если дискриминант $D = 0$, корень кратный и решение имеет вид $a_n = (\lambda_1 + \lambda_2 n) r_0^n$
- [x] Комплексно-сопряженные корни $r = \rho e^{\pm i \varphi}$ порождают колебательные решения вида $\rho^n (A \cos(n\varphi) + B \sin(n\varphi))$
- [ ] Число корней характеристического уравнения всегда больше порядка рекуррентного уравнения
- [x] Константы $\lambda_i$ однозначно находятся из начальных условий

Пояснение:
**Ответ:** Вещественные различные корни дают сумму прогрессий; кратный корень дает домножение на $(\lambda_1 + \lambda_2 n)$; комплексные корни дают гармоники; константы находятся из начальных условий.

Число корней характеристического уравнения в точности равно степени многочлена, то есть порядку $k$ рекуррентного соотношения (по основной теореме алгебры).


## 19

В каких из приведенных алгоритмов время работы описывается вторым случаем Мастер-теоремы ($T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$)?

- [x] Сортировка слиянием (MergeSort): $T(n) = 2T(n/2) + \Theta(n)$
- [x] Бинарный поиск (Binary Search): $T(n) = T(n/2) + \Theta(1)$
- [ ] Алгоритм Карацубы: $T(n) = 3T(n/2) + \Theta(n)$
- [ ] Алгоритм Штрассена: $T(n) = 7T(n/2) + \Theta(n^2)$
- [x] Рекурсивный поиск медианы с разбиением на две равные части и линейной склейкой: $T(n) = 2T(n/2) + O(n)$

Пояснение:
**Ответ:** MergeSort; Binary Search; рекурсивный поиск с 2 подзадачами и $O(n)$ склейкой.

В алгоритме Карацубы $\log_2 3 \approx 1.585 > 1$ (случай 1). В алгоритме Штрассена $\log_2 7 \approx 2.807 > 2$ (случай 1). В MergeSort и бинарном поиске $f(n)$ точно балансирует с $n^{\log_b a}$ (случай 2).


## 20

Какие методы применяются для нахождения замкнутой формулы рекуррентных соотношений?

- [x] Метод характеристического уравнения для линейных соотношений
- [x] Метод развёртывания (итераций)
- [x] Метод производящих функций
- [x] Метод математической индукции для проверки гипотезы
- [ ] Метод карт Карно

Пояснение:
**Ответ:** Характеристическое уравнение; итерации (развёртывание); производящие функции; математическая индукция.

Карты Карно применяются для минимизации булевых функций в булевой алгебре и не имеют отношения к решению разностных уравнений.


## 21

Дано рекуррентное уравнение $a_n = 2a_{n-1} + 3^n$. Какие утверждения о его решении верны?

- [x] Соответствующее однородное уравнение имеет вид $a_n - 2a_{n-1} = 0$
- [x] Корень характеристического уравнения равен $r = 2$
- [x] Число $s = 3$ не является корнем характеристического уравнения, поэтому резонанса нет
- [x] Частное решение неоднородного уравнения можно искать в виде $a_n^* = C \cdot 3^n$
- [ ] Частное решение обязано иметь вид $C \cdot n \cdot 3^n$

Пояснение:
**Ответ:** Однородное уравнение $a_n - 2a_{n-1} = 0$; корень $r = 2$; резонанса нет (так как $3 \ne 2$); частное решение $a_n^* = C \cdot 3^n$.

Резонанс возникает только при совпадении основания $s$ с корнем $r$. Здесь $s=3 \ne 2$, поэтому домножение на $n$ не требуется.


## 22

Какие свойства асимптотических оценок справедливы при анализе рекурсий?

- [x] $O(g(n))$ задает асимптотическую верхнюю грань
- [x] $\Omega(g(n))$ задает асимптотическую нижнюю грань
- [x] $\Theta(g(n))$ означает одновременное выполнение $O(g(n))$ и $\Omega(g(n))$
- [ ] $\log_2 n$ и $\ln n$ имеют разный асимптотический порядок роста
- [x] Для любых $a, b > 1$ выполнено $\log_a n = \Theta(\log_b n)$

Пояснение:
**Ответ:** $O$ — верхняя грань; $\Omega$ — нижняя грань; $\Theta$ — точная грань; логарифмы по разным основаниям эквивалентны по $\Theta$.

Основание логарифма при асимптотическом анализе несущественно, так как $\log_a n = \frac{\log_b n}{\log_b a}$, а $\frac{1}{\log_b a}$ — константа.
