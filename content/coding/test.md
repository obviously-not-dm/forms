# Блок 1. Один верный вариант

## 1

Какое множество в лекции называют алфавитом?

- ( ) Множество всех слов любой длины
  > Это множество слов над алфавитом.
- (x) Конечное непустое множество символов
- ( ) Одно слово фиксированной длины
  > Слово составляют из элементов алфавита.

Подсказка: Что обозначает $A$, а что — $A^*$?

Пояснение:
**Ответ:** Конечное непустое множество символов.

Из элементов $A$ составляют слова. В $A^*$ входят все конечные слова над $A$, включая пустое слово.

> «13 Кодирование. Энтропия, Хаффман, Шеннона–Фано, арифметический код», слайды 3.

## 2

Когда две исходные строки опровергают однозначную декодируемость кода?

- ( ) У строк одинаковая длина
  > Равенство длин допускает разные кодовые записи.
- ( ) Одна кодовая запись длиннее другой
  > Условие однозначности касается совпадения записей.
- (x) Строки различны, а их кодовые записи совпадают

Подсказка: Можно ли по полученной записи выбрать одну исходную строку?

Пояснение:
**Ответ:** Строки различны, а их кодовые записи совпадают.

Однозначное декодирование требует инъективности на множестве сообщений. Две разные строки с одним образом нарушают это условие.

> «13 Кодирование. Энтропия, Хаффман, Шеннона–Фано, арифметический код», слайды 4. «Лекция 12 — Кодирование», слайды 24–28.

## 3

Как декодировать слева направо поток, записанный префиксным кодом?

- (x) Как только прочитано кодовое слово, выдать его символ и начать чтение следующего
- ( ) Всегда читать одинаковое число разрядов
  > У префиксного кода длины могут различаться.
- ( ) Прочитав кодовое слово, искать более длинное с тем же началом
  > Условие Фано исключает такое продолжение.

Подсказка: Вспомни, что запрещено для начала другого кодового слова.

Пояснение:
**Ответ:** Как только прочитано кодовое слово, выдать его символ и начать чтение следующего.

Первое найденное кодовое слово уже задаёт границу символа. Повторение этого шага даёт единственное разбиение всего потока.

> «13 Кодирование. Энтропия, Хаффман, Шеннона–Фано, арифметический код», слайды 12–13. «Лекция 12 — Кодирование», слайды 31–32.

## 4

Для заданных длин двоичных слов сумма Крафта меньше единицы. Что установлено?

- ( ) Любой набор слов этих длин префиксен
  > Слова всё ещё можно выбрать так, что одно окажется началом другого.
- (x) Существует префиксный двоичный код с такими длинами
- ( ) Средняя длина меньше одного бита
  > В сумме Крафта нет вероятностей символов.

Подсказка: Проверяли конкретные битовые строки или только длины?

Пояснение:
**Ответ:** Существует префиксный двоичный код с такими длинами.

Неравенство проверяет возможность построения кода. Чтобы оценить конкретное назначение слов, нужно проверить сами слова.

> «13 Кодирование. Энтропия, Хаффман, Шеннона–Фано, арифметический код», слайды 15. «Лекция 12 — Кодирование», слайды 33.

## 5

Что измеряет двоичная энтропия Шеннона в вероятностной модели источника?

- ( ) Длину самого длинного кодового слова
  > Она зависит от выбранного кода.
- ( ) Количество символов в сообщении
  > Это длина самого сообщения.
- (x) Среднее количество информации на символ

Подсказка: Какую роль играют вероятности в сумме Шеннона?

Пояснение:
**Ответ:** Среднее количество информации на символ.

Величина $-\log_2 p_i$ усредняется с весами $p_i$. Результат измеряется в битах на символ.

> «13 Кодирование. Энтропия, Хаффман, Шеннона–Фано, арифметический код», слайды 8–11.

## 6

В списке свободных узлов Хаффмана веса 1, 1, 1, 2, 2, 3. Какие веса объединяют на первом шаге?

- (x) 1 и 1
- ( ) 1 и 3
  > Выбранный узел веса 3 не минимален.
- ( ) 2 и 3
  > Это два наиболее тяжёлых узла списка.

Подсказка: Используй частоты букв слова «МАТЕМАТИКА».

Пояснение:
**Ответ:** 1 и 1.

Два узла минимального веса снимают со списка и возвращают один узел веса 2. При равных весах выбор конкретных букв может различаться.

> «13 Кодирование. Энтропия, Хаффман, Шеннона–Фано, арифметический код», слайды 16–18.

## 7

Как метод Шеннона–Фано выбирает первое разбиение упорядоченного списка символов?

- ( ) Делит список строго пополам по числу букв
  > При разных вероятностях массы половин могут сильно различаться.
- (x) Делит список на две части с максимально близкими суммами вероятностей
- ( ) Объединяет два последних символа в один узел
  > Так строится дерево Хаффмана снизу вверх.

Подсказка: Что складывают внутри каждой из двух частей?

Пояснение:
**Ответ:** Делит список на две части с максимально близкими суммами вероятностей.

Символы выписывают по убыванию вероятностей. Частям назначают разные биты и рекурсивно повторяют разбиение внутри каждой части.

> «13 Кодирование. Энтропия, Хаффман, Шеннона–Фано, арифметический код», слайды 19–20.

## 8

Что передаёт арифметический код для всего сообщения в модели из лекции?

- ( ) Только ширину итогового полуинтервала
  > Ширина не указывает, где расположен полуинтервал.
- ( ) Конкатенацию путей к отдельным листьям дерева Хаффмана
  > Это другой способ представить последовательность символов.
- (x) Число из итогового полуинтервала сообщения

Подсказка: Что происходит с рабочим полуинтервалом после каждого символа?

Пояснение:
**Ответ:** Число из итогового полуинтервала сообщения.

Каждый очередной символ сужает рабочий полуинтервал. Любая точка, принадлежащая последнему полуинтервалу, согласуется со всеми сделанными выборами.

> «13 Кодирование. Энтропия, Хаффман, Шеннона–Фано, арифметический код», слайды 22–24.

## 9

Какой метод соответствует записи «100 А, 100 Б» для текста из двух длинных серий?

- (x) RLE
- ( ) LZW
  > В LZW числовые коды назначаются цепочкам в словаре.
- ( ) Хаффман
  > У Хаффмана коды строятся по весам символов или блоков.

Пояснение:

Число задаёт длину серии. При распаковке букву повторяют указанное число раз.

## 10

В табличной схеме биты расположены в строках $(a,b)$ и $(c,d)$. Не сошлись только проверки $a\oplus b$ и $b\oplus d$. Какой информационный бит искажён при одиночной ошибке?

- ( ) $a$
  > Он участвует в первой сумме, но не во второй.
- (x) $b$
- ( ) $d$
  > Он участвует во второй сумме, но не в первой.

Подсказка: Найди пересечение строки и столбца.

Пояснение:
**Ответ:** $b$.

У двух неудачных проверок один общий информационный бит. Его инверсия восстанавливает обе суммы.

> «Лекция 13, 14 — Кодирование», слайды 49–54.

## 11

Что указывает ненулевой синдром обычного кода Хэмминга при одной ошибке?

- ( ) Количество искажённых разрядов
  > В этом условии количество уже известно и равно одному.
- ( ) Число единиц в принятом слове
  > Проверки относятся к разным множествам позиций.
- (x) Номер искажённого разряда

Подсказка: Запиши номера позиций в двоичной системе.

Пояснение:
**Ответ:** Номер искажённого разряда.

Набор неудачных проверок совпадает с единичными разрядами двоичного номера ошибки. На указанной позиции бит инвертируют.

> «14 Кодирование Хэмминга», слайды 9–14.

## 12

В примере «МАМА МЫЛА РАМУ» ключ «БАЙТ» задаёт новый порядок букв. Какой это тип преобразования?

- (x) Перестановка
- ( ) Замена
  > При замене по правилу меняют саму букву.
- ( ) Дробление
  > При дроблении букву сначала представляют несколькими символами.

Подсказка: Что именно меняет ключ в этом примере?

Пояснение:
**Ответ:** Перестановка.

При перестановке буквы открытого текста сохраняются и меняют позиции. В примере порядок задаёт ключевое слово.

> «Лекция 13, 14 — Кодирование», слайды 92–96.

## 13

Какое требование отличает сжатие без потерь?

- ( ) Можно восстановить только алфавит и частоты букв
  > Две разные строки могут иметь одинаковые частоты.
- (x) После распаковки восстанавливается исходная последовательность символов целиком
- ( ) Достаточно сохранить приблизительный вид сообщения
  > Это допускает потерю исходных данных.

Подсказка: Что должно получиться при распаковке?

Пояснение:
**Ответ:** После распаковки восстанавливается исходная последовательность символов целиком.

Обратимое сжатие использует избыточность данных. Декодер должен восстановить и сами символы, и их порядок.

> «Лекция 12 — Кодирование», слайды 58–61. «Лекция 13, 14 — Кодирование», слайды 21–28.

## 18

У кода Хаффмана для «МАТЕМАТИКА» длины слов Е, И, К, М, Т, А равны 4, 4, 3, 2, 2, 2. Сколько битов занимает всё сообщение без таблицы кода?

## 21

## 22

Арифметический декодер восстанавливает три символа по числу 0,41. В порядке a, b, c доли интервала равны $4/7,2/7,1/7$. Восстанови текст.

Формат: три строчные латинские буквы.
Ответ: aba

Подсказка: После выбора части переведи точку в координаты этой части: вычти её левую границу и раздели на ширину.

Пояснение:
**Ответ:** aba.

Сначала $0{,}41<4/7$, получаем a. После пересчёта точка равна 0,7175 и лежит между $4/7$ и $6/7$, получаем b. Новый пересчёт даёт 0,51125, что снова меньше $4/7$.
